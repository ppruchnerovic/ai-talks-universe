## Description

Do you run mission critical applications across distributed locations? Join us to learn the best practices to deploy Azure’s distributed hybrid infrastructure solutions – from the public cloud to customer operated locations. Discover how legacy workloads and cloud-native and AI applications run on hybrid infrastructure while leveraging the advantages of Azure’s ecosystem of services like security or centralized cloud-management.
