## Description

GitHub Copilot started as an AI-powered autocomplete tool. Since its release, Copilot's capabilities have grown and made their way into the entire software development lifecycle. Learn how GitHub Copilot is becoming an AI-powered thought partner able to help you not just with code, but with ideas, prototypes, delivery process, and even security. Plus, get a sneak peek into what's next for AI developer tooling.
