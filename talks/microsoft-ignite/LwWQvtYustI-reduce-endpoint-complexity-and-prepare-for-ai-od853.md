## Description

Cloud endpoint virtualization continues to grow, but customers need the help of partners to decide what solution best fits their needs. In this session, we review how we're bringing Windows 365 and Azure Virtual Desktop closer together as part of the Cloud Endpoints solution play, focusing on the needs of various user personas and reducing organizational TCO.
