## Description

Learn how organizations are using Copilot Studio to extend M365 Copilot. In this session, we will cover top Copilot agents you should build and deploy org-wide, best practices for enabling anyone to build Copilot Agents with the Copilot Studio agent builder, and rules to live by for IT governance and management.
