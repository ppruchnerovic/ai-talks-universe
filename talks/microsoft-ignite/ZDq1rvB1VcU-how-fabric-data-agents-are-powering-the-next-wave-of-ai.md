## Description

Unlock the next level of enterprise AI with Fabric data agents—now featuring integration with M365 Copilot, managed MCP server endpoints, and reasoning across structured and unstructured data in OneLake. Learn how these innovations empower your teams to unify data sources and deploy intelligent, interoperable AI solutions faster and more securely. With MCP support, Fabric data agents can streamline governance and connectivity across the enterprise, enabling data-driven decision-making at scale.
