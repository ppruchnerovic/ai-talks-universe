## Description

Data security and privacy are the top concerns for 80% of security leaders when adopting AI. This session will explore how Microsoft can help secure and govern data in AI applications like Microsoft 365 Copilot and other third-party SaaS applications. We will introduce new capabilities that address primary AI challenges, such as data oversharing, leakage, compliance, and safety. After this session, you will gain the confidence and tools needed to accelerate AI adoption.
