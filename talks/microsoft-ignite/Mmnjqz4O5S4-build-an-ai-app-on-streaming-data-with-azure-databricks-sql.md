## Description

This session will demonstrate how Azure Databricks SQL, Genie APIs, and Power BI can be seamlessly integrated to create efficient, low-code data workflows. Attendees will learn how to:
Connect data from Salesforce and Azure SQL using Lakeflow Connect
Govern data with Unity Catalog and apply AI-driven insights
Leverage Genie Spaces and Lakehouse Apps to ask natural language questions of your governed data and integrate it into your applications
Query data using Azure Databricks SQL and Databricks
