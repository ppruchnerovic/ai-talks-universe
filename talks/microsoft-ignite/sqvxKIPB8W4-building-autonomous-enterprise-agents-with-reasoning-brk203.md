## Description

This session will highlight autonomous agents powered by reasoning models. These agents can plan, execute, and adapt across tasks like lead scoring, content generation, and customer support. We’ll demo agentic workflows using these models and you will learn to build agents in Microsoft Foundry that are aligned with enterprise goals.
