## Description

Join us for a deep dive into Azure AI Foundry with a focus on security and IT governance. This session is tailored for IT admins, security pros, and developers committed to shifting left in their security practices. We'll explore enterprise security promises in Azure AI, including capabilities and controls for network security, data encryption, and identity management to ensure your GenAI projects remain secure and compliant throughout the GenAI development lifecycle.
