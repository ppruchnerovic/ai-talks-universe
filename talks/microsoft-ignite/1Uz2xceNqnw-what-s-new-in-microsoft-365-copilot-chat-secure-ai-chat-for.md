## Description

Discover how Microsoft 365 Copilot Chat makes Copilot the AI built for work. Join this session to learn about how we’ve enhanced core chat value for all with GPT-5, experience improvements, and new ways to access chat in your favorite apps. Additionally, we’ll cover how Copilot Chat transforms your day when combined with your work context and agents through new chat-first workflows, interaction modes, and ways to create files right from chat.
