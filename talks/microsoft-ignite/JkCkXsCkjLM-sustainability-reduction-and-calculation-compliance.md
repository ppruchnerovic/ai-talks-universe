## Description

In this presentation, we showcase the powerful combination of Large Language Models (LLM) and data aligned with the Cloud for Sustainability schema through the creation of Copilot Studio templates. These templates are designed to bring sustainability standards, such as the EU Carbon Border Adjustment Mechanism (CBAM), to life by assisting practitioners in estimating carbon adjustment fees. Additionally, the templates can help set goals using the Science Based Target (SBTi) methodology, which can then be seamlessly imported into Microsoft Sustainability Manager for tracking.
