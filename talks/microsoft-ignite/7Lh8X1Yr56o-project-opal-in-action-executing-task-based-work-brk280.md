## Description

Discover how Project Opal unlocks a new way to work by executing task-based processes – freeing teams from routine busywork and time-consuming tasks. In this session, you’ll see first-hand how Project Opal is helping get work done using practical, real-world scenarios. We’ll share actionable guidance and best practices so you can start to securely deploy Project Opal in your organization.
Delivered in a silent stage breakout.
