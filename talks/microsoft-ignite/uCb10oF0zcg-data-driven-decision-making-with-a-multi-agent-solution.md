## Description

Agents come in all shapes and sizes. This session will showcase a multi-agent solution built using Azure OpenAI Service by Capgemini for Unilever to boost sales through more effective interactions. The GenAI solution, developed with Azure AI Foundry, integrates seamlessly with a communications platforms for personalized responses and Microsoft Teams integration for enhanced collaboration. Join this technical session to learn how to build an innovative multi-agent system.
