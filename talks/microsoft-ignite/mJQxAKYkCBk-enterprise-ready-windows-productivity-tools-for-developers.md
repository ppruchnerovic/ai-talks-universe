## Description

Windows 11 offers a suite of developer productivity tools designed to accelerate coding workflows and to align with enterprise IT priorities. In this session, you will learn about new experiences coming to WSL, Windows Terminal, and PowerToys boosting productivity.  We’ll also cover how these tools are built with security and enterprise-grade manageability in mind—making Windows an enterprise-friendly platform.

Delivered in a silent stage breakout.
