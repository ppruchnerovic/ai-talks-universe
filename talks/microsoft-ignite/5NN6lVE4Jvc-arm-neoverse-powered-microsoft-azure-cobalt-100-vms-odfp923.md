## Description

Cloud users and developers are constantly seeking efficient and sustainable compute solutions that can scale for modern, cloud-native applications, including AI. Microsoft has been addressing these needs through system-to-software optimization across their Azure offerings, including the new Azure Cobalt 100 processor, powered by Arm Neoverse. In this session, we give an overview of the Cobalt 100 VM series and how it delivers unmatched efficiency, scalability and performance for cloud developers.
