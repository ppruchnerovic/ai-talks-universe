## Description

Game development is some of the most challenging (and most fun!) software engineering out there. Azure has been battle-tested to help enable highly complex and bleeding edge scenarios for cloud-focused game development. In this session, we'll cover the most common use cases for Azure & AI in game development and the end-to-end vision for cloud-focused game dev with Azure.
