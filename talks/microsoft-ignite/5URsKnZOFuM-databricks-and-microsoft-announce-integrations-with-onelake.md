## Description

Ali Ghodsi, CEO of Databricks, and Scott Guthrie, EVP of Cloud and AI at Microsoft, discuss the plans for deep integration between Azure Databricks and Microsoft OneLake. Learn how unified data access, seamless interoperability, and trusted governance empower organizations to break silos, accelerate AI, and innovate across the Microsoft ecosystem. They’ll also discuss new Azure Databricks integrations being featured at Ignite including SAP Databricks on Azure, Microsoft Copilot Studio, and Microsoft Foundry.
