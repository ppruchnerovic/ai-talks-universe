## Description

To build the agentic web at scale, people, agents, websites, apps, and more will need to communicate in approximately the same language. NLWeb is our open-source protocol that enables this communication layer using natural language—and now, through Microsoft Foundry, can be deployed as a managed service. Find out more about NLWeb, discover new capabilities (TBA), and learn how to enhance site engagement while enabling your site to be discoverable and transactable on the agentic web.
