## Description

Learn about all the new (and planned) ways we are making it easier to acquire and use Azure DevOps and GitHub together. Hear about the new features we are launching within GHE, with updates to Issues and data residency. Use GitHub repositories, Copilot, Codespaces, and Advanced Security to improve your developer’s productivity while leveraging your existing assets in Azure Boards, Pipelines, and Test Plans to keep your enterprise development teams moving forward.
