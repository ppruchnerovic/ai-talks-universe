## Description

See how Microsoft Foundry on Windows makes enabling local AI easy on Copilot+ PCs with Windows AI APIs — no cloud, hosting, or ML expertise needed. Use built-in models on Copilot+ PCs like Phi Silica to integrate built-in language and vision capabilities. Enable turnkey features like summarization, rewriting, and image understanding with minimal code. Customize AI models with own proprietary data using LoRA (low rank adapter) fine-tuning and app content search.
