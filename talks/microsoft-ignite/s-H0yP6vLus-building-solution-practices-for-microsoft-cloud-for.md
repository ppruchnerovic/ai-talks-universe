## Description

This session highlights how Microsoft Cloud for Sustainability partners leverage Microsoft technologies to implement and build solutions to solve sustainability challenges. You will hear firsthand from KPMG and the business they are building around sustainability.  Sustainability is a global challenge, and partners play a key role in data collection, understanding opportunities, and implementing solutions to drive sustainable alternatives.
