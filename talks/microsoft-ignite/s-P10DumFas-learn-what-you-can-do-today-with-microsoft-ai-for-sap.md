## Description

Join us and learn how to architect, set-up and deploy workflows combining AI technologies from Microsoft and SAP. We’ll share how you can use Azure AI with SAP, integrate Copilot for Microsoft 365 with SAP Joule for improved productivity and streamline SAP workflows by building your own Copilot with Microsoft Copilot Studio. This session also includes best practices and real-world examples.
