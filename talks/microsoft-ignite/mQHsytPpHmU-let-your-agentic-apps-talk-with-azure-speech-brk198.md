## Description

Experience next generation of Azure Speech. Whether you’re building voice-enabled apps, intelligent customer-service AI Agents, or multimodal translation tools, these new capabilities will empower you to create voice experiences that are faster, smarter, and more engaging than ever. We will spotlight Voice Live API (now generally available) which helps you build real-time voice agents. We will also unveil new APIs that leverage large language models to unlock new capabilities.
