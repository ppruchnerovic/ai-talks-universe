## Description

Over the past year, we saw a 2.75x rise in ransomware attacks, but a 3x decline in the number of Defender for Endpoint customers that were encrypted. Discover a key secret to this success, automatic attack disruption, which stops attacks at machine speed using industry-leading machine learning and threat intelligence. Since servers are a key target in ransomware attacks, we'll also discuss disruption on servers. Discover how to make the most of new features and UI.
