# Devoxx Greece 2025 : How Simple Should Your LLM Integration Be? by Efstratios Marinos

**Efstratios Marinos**

`Devoxx` · `Devoxx` · `2025` · `40 min`

[Watch the recording](https://www.youtube.com/watch?v=br2Mo2JS-xA) · [Conference site](https://devoxx.com/)

## Description

In the race to build AI-powered applications, we often overlook the power of simplicity. Through working examples, we'll explore how effective LLM integrations can be built using basic, composable patterns rather than complex frameworks. We'll demonstrate real-world implementations using minimal dependencies, showing how to create reliable systems while avoiding common pitfalls.

What you'll learn? When to use different patterns (workflows vs. agents), how to design clean interfaces, and most importantly, when to keep it simple versus when to add complexity. By the end, you'll have a clear understanding of how to build LLM-powered systems that are maintainable, scalable, and actually work in production.
