## Description

OverviewBacklog.md is a CLI tool for managing project collaboration between humans and AI Agents in a git ecosystem - 100% offline tasks in your repo, optimized for AI Agents using Markdown files. Think Kanban but in your terminal. No MCP, no database, no hosting needed. Works on Mac, Windows and Linux!DescriptionBacklog.md began as a way to tackle side projects with AI Agents like Claude‑Code, OpenAI Codex, and Google Jules. Today it’s a lightweight project‑management tool for solo devs and small teams.Because each task is just a Markdown file in the repo, an agent can ingest the spec, understand full project context, and start implementing without any extra APIs or MCP servers required.Key features:Git‑native storage - tasks travel with your branches; merges keep boards in sync between local and remote branches.backlog board - a TUI that shows To Do • In Progress • Done, plus requirements and implementation plans.backlog browser - fires up a local web server so you can drag‑and‑drop cards in a slick offline UI; all changes are still plain Markdown.The talk targets developers and “vibe coders” who want the structure of Linear or Jira without the overhead—or the internet connection.Agenda1) Backlog.md Presentation2) Vibe code an app app requirements -&gt; Voice to PRD
