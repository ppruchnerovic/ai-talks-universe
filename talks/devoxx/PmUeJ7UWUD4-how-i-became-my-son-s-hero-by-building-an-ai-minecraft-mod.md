# How I became my son's hero by building an AI Minecraft Mod with LangChain4J by Dominique Broeglin

**Speaker not identified**

## Description

Let's double the fun by exploring Generative AI application and applying it to MineCraft Mod development! We will explore how easy it is to build an AI app with LangChain4J starting with simple content generation. We will move on to chatbot interaction by finally giving those NPCs some real conversation! Finally, because I'm a noob at Minecraft, we will build an assistant to help me on my path from zero to hero. Along the way we will learn about AI concepts like large language models, prompt engineering, retrieval augmented generation, LLM function calling and more. All in a fun way!

Surrendering to the fact that Generative AI is now ubiquitous in our work as developers, we will use GitHub Copilot to assist our live coding. We will also showcase how AI Apps can be tested by leveraging... Generative AI.

You will leave this session equipped with all the tools you need to show your kids/nephews/grandma how cool development can be in the age of AI!
