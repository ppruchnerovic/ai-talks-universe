## Description

Let&#39;s be honest: every developer loves writing tests, right? Meaning that we&#39;re all diligently practicing Test-Driven Development (TDD), not just preaching it. Or... are we? Maybe that&#39;s why we keep asking our AI coding assistants to write tests for us. Just prompt ChatGPT to generate a test for your latest class and voilà: &quot;Of course I can help you write your tests. Here&#39;s a complete test suite that achieves 100% line and branch coverage.&quot;But does that really mean the tests are any good?In this session, Laurens and Frederieke will push AI-generated tests to their limits using mutation testing and the PI-Test framework. Together, we&#39;ll explore whether these tests truly hold up under scrutiny, or if they just look good on paper.By the end, you&#39;ll know when to say to your coding assistant, &quot;Thanks, ChatGPT, that was helpful,&quot; and when to say, &quot;Thanks, but no thanks. I&#39;ll write my own test this time.&quot;
