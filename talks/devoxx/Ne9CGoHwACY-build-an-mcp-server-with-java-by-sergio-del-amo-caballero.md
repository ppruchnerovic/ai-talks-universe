# Build an MCP Server with Java by Sergio del Amo Caballero

**Sergio del Amo Caballero**

`Devoxx` · `Devoxx` · `2025` · `158 min`

[Watch the recording](https://www.youtube.com/watch?v=Ne9CGoHwACY) · [Conference site](https://devoxx.com/)

## Description

This session shows how to build an MCP (Model Context Protocol) Server in Java.We first discuss how to build an MCP Server with Java without any framework, and then compare what frameworks (Spring Boot, Micronaut, and Quarkus) offer.We will implement an MCP Server with each framework. The MCP Server will expose custom tools that can be accessed by MCP clients.You will learn how to test your implementation using the MCP Inspector tool and connect to your MCP server with Claude as a client.Target AudienceDevelopers interested in creating an MCP (Model Context Protocol) Server in Java.
