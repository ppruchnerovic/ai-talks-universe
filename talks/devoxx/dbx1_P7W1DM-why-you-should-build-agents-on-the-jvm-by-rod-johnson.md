# Why You Should Build Agents on the JVM by Rod Johnson

**Rod Johnson**

`Devoxx` · `Devoxx` · `2025` · `22 min`

[Watch the recording](https://www.youtube.com/watch?v=dbx1_P7W1DM) · [Conference site](https://devoxx.com/)

## Description

This keynote explores the rise of Java AI Agents, with a focus on Embabel - an innovative JVM-based agent framework designed for Java and Kotlin developers. Seamlessly integrated with Spring, Embabel empowers developers to build safe, manageable, and type-safe AI agents while leveraging advanced planning capabilities.
