## Description

Claude Code is an excellent coding assistant, but that’s not what this talk is about.This talk is about using a frontier LLM, strapped to your terminal, to do things its creators probably never imagined… and living to tell the tale.You’ll see real examples where I gave Claude vague, high-level instructions like:“Set up a dev cluster”“Debug this broken networking setup”“Run these scripts for each user in this Excel sheet, but skip the management types”“Figure out how to comply with a government-mandated power-saving law and prove it”That last one? It generated config scripts, created audit reports, and helped cut our power bill by 15%.No prompt engineering. No debates about hallucinations. Not even a mention of MCP.Just practical, repeatable use cases from someone who wanted to spend less time clicking around and more time shipping (or avoiding tickets entirely).You’ll walk away with:Tips for using Claude on the Ops side of DevOps (and how to avoid Oops)Ideas and prompts that go beyond code, like compliance and reportingA few hard boundaries I hit when pushing it too farSome questionable decisions I don’t fully endorse… but hey, they workedA glimpse of what’s possible as open models like Mistral become more capableIf you’ve ever wished your terminal could just figure it out, this talk is for you.
