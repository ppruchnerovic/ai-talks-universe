## Description

Please subscribe to our YouTube channel @ https://www.youtube.com/@DevoxxForever

This deep-dive session introduces the essential foundations of Playwright for UI and API testing, focusing only on the core principles needed to build clean, reliable tests such as effective selectors, basic test structure, and simple API validation. Rather than dwelling on fundamentals, this brief groundwork sets the stage for a deeper exploration into Playwright’s emerging agentic capabilities.

The session then shifts focus to the evolving Playwright ecosystem, unpacking the differences between Playwright CLI and Playwright MCP (Model Context Protocol). Attendees will learn how MCP enables AI-assisted workflows, how it differs from traditional CLI-based execution, and when to use each in modern testing environments.

From there, the deep dive explores Playwright’s agentic toolkit -Plan, Generator, and Healer agents, showing how they can transform the way tests are designed, generated, and maintained. The session demystifies how these agents operate, how they collaborate, and how they can be guided effectively to reduce manual effort while avoiding common pitfalls like over-generation or brittle outputs.

A key highlight is prompt engineering for test automation, with a strong emphasis on crafting an effective Skill.md. Participants will learn how to encode domain knowledge, define guardrails, and structure prompts to make Playwright agents more accurate and token-efficient.
