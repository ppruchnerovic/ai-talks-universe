# Building reporting services using Quarkus and AI by Alexis Panousis and Kostas Sidiropoulos

**Alexis Panousis, Kostas Sidiropoulos**

`Devoxx` · `Devoxx` · `2024` · `42 min`

[Watch the recording](https://www.youtube.com/watch?v=aZzkoz0Ykac) · [Conference site](https://devoxx.com/)

## Description

For nearly all platforms, it is essential to provide end users with access to meaningful insights from the data store. Traditionally, developing these services involves creating APIs that expose data in a specific format, which clients then use to visualize the data in a predetermined way.
We will harness the power of large language models (LLMs) to create a reporting service that transforms our approach to application development in the LLM era. This innovative service will not only offer data insights but also redefine how we interact with and interpret data within applications.
