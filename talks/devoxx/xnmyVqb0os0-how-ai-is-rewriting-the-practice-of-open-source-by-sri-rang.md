## Description

Please subscribe to our YouTube channel @ https://www.youtube.com/@DevoxxForever

Nature of open source human collaboration is shifting as agents step in.

Key changes:
• Contributions: pull prompt requests → agent actions
• Workflows: CI/CD → continuous agent loops
• Trust: human review → auditing agent behavior
• Developers: coding → specifying and supervising

This talk outlines what’s changing, why it matters, and how to build in an AI-native open source world.
