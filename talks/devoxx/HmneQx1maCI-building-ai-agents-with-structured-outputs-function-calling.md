# Building AI agents with Structured Outputs, Function Calling, and MCP by Julien Dubois

**Julien Dubois**

`Devoxx` · `Devoxx` · `2025` · `49 min`

[Watch the recording](https://www.youtube.com/watch?v=HmneQx1maCI) · [Conference site](https://devoxx.com/)

## Description

AI agents are programs that can act autonomously: to do this, they must be able to communicate programmatically with an LLM and perform actions.In this session, we will explore:The new &quot;agentic&quot; module from LangChain4j: how to build AI agents in Java and orchestrate them with a nice APIStructured Outputs: how to require an LLM to respond following a JSON schema, allowing to map the result to Java objectsFunction Calling: how to define and call Java functions from within an AI modelMCP: the new protocol that standardizes how LLMs communicate with different data sources and toolsWe will use the code, demos, and documentation I created to implement these features in LangChain4j using OpenAI’s brand-new Java SDK.
