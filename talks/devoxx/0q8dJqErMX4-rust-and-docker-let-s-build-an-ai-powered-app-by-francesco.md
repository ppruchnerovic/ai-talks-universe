# Rust and Docker: Let's build an AI-powered App! by Francesco Ciulla

**Francesco Ciulla**

`Devoxx` · `Devoxx` · `2024` · `31 min`

[Watch the recording](https://www.youtube.com/watch?v=0q8dJqErMX4) · [Conference site](https://devoxx.com/)

## Description

Everyone is talking about AI, but what about solving our problems using AI? In this talk, I will dive deep into two technologies I am passionate about: Rust and Docker. We will also try to answer the question: "How to get an idea for a new project?"
To start, I will provide a brief introduction to both Rust and Docker. Rust is not only a systems programming language but also highly effective for web development and creating services. Docker, on the other hand, is essential for containerizing applications, ensuring they run smoothly in any environment.
We will explore the capabilities of Rust in web development and service creation, showcasing practical examples. Together, we will write the Dockerfile and Docker Compose file, demonstrating how to containerize our Rust project.
Throughout the session, I will show the code of the project and explain it line by line, ensuring a clear understanding of each step.
And finally, there's a little surprise at the end for you—a funny demo that you won't want to miss. 🙂
Join us to discover how Rust and Docker can be powerful tools in your development toolkit and how they can help turn your project ideas into reality.
