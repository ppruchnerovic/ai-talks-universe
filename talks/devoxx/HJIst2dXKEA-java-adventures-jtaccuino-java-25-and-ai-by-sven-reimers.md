# Java Adventures JTaccuino, Java 25 and AI by Sven Reimers

`Devoxx` · `Devoxx` · `2025` · `31 min`

## Description

A demo packed session awaits you showing you the latest Java 25 features using JTacccuino notebooks.JTaccuino is a pure Java and JavaFX notebook solution, which allows for easy exploration in Java by leveraging JShell, dependency resolution, custom extensions and more. The aim is to reduce typical existing ceremony in API&#39;s for simpler and more scripting style interaction.From new language features in Java 25 (JEP 502, 507, 508) to more infrastructure related innovations (JEP 520) and enhancements in former Java versions - buckle up for a roller coaster ride through the Java world of innovation.As a companion on this ride JTaccuino will support you with interactive experimenting and AI augmented Java feature discovery - using local and open LLM&#39;s by leveraging LangChain4j and Ollama.
