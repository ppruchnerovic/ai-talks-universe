## Description

Please subscribe to our YouTube channel @ https://www.youtube.com/@DevoxxForever

Ever wondered how you would write code if you were a seasoned hacker?
In this hands-on session, you’ll learn how to adopt that mindset to build secure Java applications with confidence in the AI era. Every year, thousands of organizations are breached, and billions of records are exposed. Only in 2024, cyberattacks compromised 1.7 billion individuals, and millions of applications were targeted daily. Through "live demos" of real-world attacks and defenses, we’ll cover the essentials every modern Java developer needs in 2026.

Key takeaways:
A quick look at the OWASP Top 10 (2025) and practical solutions for the newest risks.
How to implement supply chain security strategies to defend against threats like Shai-Hulud or Log4Shell.
Ways to integrate essential security checks (SAST/SCA) into your CI/CD pipeline for continuous protection.
Practical threat modeling techniques to identify and prioritize risks early in the design phase and later in incident response.
How to set up security monitoring and logging to detect and respond to attacks in production.
Practical strategies to use AI assistants securely in your development workflow.
And finally, why using hardened container images is a simple yet highly effective strategy for runtime security.
