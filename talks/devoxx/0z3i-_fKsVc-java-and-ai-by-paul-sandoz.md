# Java and AI by Paul Sandoz

**Paul Sandoz**

`Devoxx` · `Devoxx` · `2025` · `18 min`

[Watch the recording](https://www.youtube.com/watch?v=0z3i-_fKsVc) · [Conference site](https://devoxx.com/)

## Description

Java is commonly found where AI needs to be. We shall describe how Java features can and will meet the needs of AI. Existing features include the Foreign Function and Memory API of Project Panama. Future features include those proposed by Project Babylon. We shall present how such features combine and empower developers to meet the needs of AI.
