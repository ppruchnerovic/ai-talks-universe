## Description

Brokk is a new tool written with Java Swing for supervising code-writing AI assistants.It is a standalone application because effective context engineering for software development requires a different paradigm than the 40 year old IDE design optimized for reading and writing code at human speeds.This talk will cover the principles behind Brokk&#39;s design, how Brokk leverages static analysis to help LLMs understand your code at a level deeper than raw text, and Java-specific optimizations like dependency decompilation to avoid hallucinations.We&#39;ll also take a brief look at the JVM tech powering Brokk, including Joern (the static analysis engine) and Jlama (pure Java LLM inference).
