## Description

This presentation will explore the innovative features introduced in Oracle 23ai, focusing on how natural language querying and vector search capabilities might enhance data accessibility, analysis, and insights. Attendees will gain an understanding of the practical applications, benefits, and implementation strategies of these features in their data-driven operations.

The presentation includes demos of:

- Select AI feature, which allows you to query your data without using SQL language
- Embedding data using a model stored inside the database
- Vector search for running a simple similarity search
