# Java as an AI development Platform by Zoran Sevarac

**Zoran Sevarac**

`Devoxx` · `Devoxx` · `2025` · `48 min`

[Watch the recording](https://www.youtube.com/watch?v=5DKwBUwbsUc) · [Conference site](https://devoxx.com/)

## Description

As artificial intelligence continues to redefine the technological landscape, developers are increasingly seeking robust,  scalable, and interoperable platforms for AI development.Java is emerging as a powerful and production-ready platform for building, deploying, and maintaining AI applications at scale. This talk explores Java&#39;s evolving role in the AI ecosystem, driven by recent innovations such as Project Panama and the Vector API, which significantly enhance performance, interoperability, and hardware-level optimization.We will showcase modern Java-based tools and libraries, including Deep Netts that provide native support for deep learning, model training, inference, and integration with enterprise systems. By leveraging the Java Virtual Machine (JVM), developers gain access to high-performance computing, cross-platform compatibility, and mature tooling for large-scale system integration.This session will demonstrate how Java can serve not only as a reliable backend for AI-powered services but also as a full-stack AI development platform suitable for mission-critical applications in finance, manufacturing, and telecommunications. Attendees will leave with a clearer understanding of Java’s unique advantages in AI development and practical strategies for adopting Java-based AI solutions in real-world projects.
