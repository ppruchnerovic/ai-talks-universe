# From Zero to AI: Building Smart Java or Kotlin Applications with Spring AI by Christian Tzolov

**Christian Tzolov**

`Devoxx` · `Devoxx` · `2025` · `106 min`

[Watch the recording](https://www.youtube.com/watch?v=4a7hdNCQgTo) · [Conference site](https://devoxx.com/)

## Description

Start integrating powerful AI capabilities into your Java and Kotlin applications today.
Spring AI helps you solve the core challenge of connecting your enterprise Data and APIs with AI models, opening the path to building practical multi-agent automations.

In this session, led by the project lead, we will demonstrate practical use cases through live coding demos.
You'll learn to implement key Generative AI patterns including Conversation Memory, Tool/Function calling, and Modular RAG (Retrieval Augmented Generation).

We'll explore approaches for building multi-agent systems and leveraging observability through metrics, tracing, and logging to understanding how your systems perform.

The session will also cover techniques for managing AI hallucinations using relevancy and fact-checking evaluators.

By the end of this session, you'll have everything you need to start integrating generative AI into your existing Java and Kotlin applications using Spring AI.
