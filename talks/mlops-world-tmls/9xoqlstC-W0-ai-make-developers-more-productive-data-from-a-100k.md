## Description

🎥 Recorded live at the MLOps World | GenAI Summit 2025 — Austin, TX (October 8, 2025)

Session Title: Does AI Make Developers More Productive? Data from a 100k-Engineer Stanford Study
Speaker: Yegor Denisov-Blanch, Researcher, Stanford University
Talk Track: AI Agents for Developer Productivity

Abstract:
Does AI truly make developers more productive—or just busier? In this fast-paced, data-driven session, Yegor Denisov-Blanch from Stanford University shares insights from a groundbreaking 100,000-engineer study that measures how AI agents and coding assistants impact developer productivity at scale.

The session also includes a live demo showing how to build a tool-powered AI agent from scratch using the Agent Development Kit (ADK)—orchestrating models, tools, and APIs into a functioning system that can solve real-world engineering tasks.

By combining large-scale research data with practical engineering demonstrations, Yegor demystifies when and how AI agents actually accelerate developer output—and where human expertise still matters most.

What you’ll learn:
• What real-world data reveals about AI’s impact on developer productivity
• How and when AI agents improve (or hurt) software engineering efficiency
• How to build an AI agent with the Agent Development Kit (ADK)
• Key patterns for orchestrating models, tools, and APIs in production
• The future of AI-assisted development for teams at scale
