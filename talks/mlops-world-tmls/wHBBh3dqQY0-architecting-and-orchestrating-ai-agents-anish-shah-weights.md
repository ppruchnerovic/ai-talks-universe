## Description

🎥 From the MLOps World | GenAI Summit 2025 — Virtual Session (October 6, 2025)

Session Title: Architecting and Orchestrating AI Agents
Speaker: Anish Shah, AI Engineer, Weights & Biases
Talk Track: Agents in Production

Abstract:
In this developer-focused session, Anish Shah explores the fastest and most reliable ways to make large language models (LLMs) solve real-world business problems. Attendees will gain practical insights into LLM orchestration, agent frameworks, and the design of effective AI agents that work reliably in production.

What Attendees Can Expect:

• Learn the latest agentic AI architectures and frameworks, informed by both research and real-world applications.
• Gain hands-on experience constructing generative AI systems using modern agentic techniques.
• Discover best practices for improving agent performance—covering evaluation protocols, prompt engineering, and latency reduction.

What You’ll Learn:

• Design Principles: Core principles for building AI agents—reflection (self-evaluation), tool use (API integration), planning (task decomposition), and multi-agent collaboration.
• Orchestration Best Practices: How to manage multi-step workflows and integrate multiple models into cohesive systems.
• Evaluation Techniques: Automated evaluation methods for continuous agent improvement.

Whether you’re an AI engineer, developer, or technical leader, this session provides practical strategies and tools to overcome common challenges in building agentic systems for production environments.
