## Description

🎥 PART 1: Recorded live at the MLOps World | GenAI Summit 2025 — Austin, TX (October 8, 2025)

Session Type: Workshop
Session Title: Vibe-Coding Your First LLM End-to-End Application
Speakers:
• Greg Loughnane, Co-Founder & CEO, AI Makerspace
• Chris Alexiuk, Co-Founder & CTO, AI Makerspace
Talk Track: AI Agents for Developer Productivity

Abstract:
Forget prompt engineering — it’s all about context engineering.

In this hands-on workshop, Greg Loughnane and Chris Alexiuk from AI Makerspace guide attendees through building their first end-to-end LLM application using the latest AI-assisted development stack. You’ll learn how “vibe-coding” combines the principles of context engineering, RAG, and AI code editors like Cursor and Claude CLI to accelerate modern development.

This session covers the practical frameworks and tools needed to build, ship, and share production-ready LLM applications, with a focus on Context Engineering Best Practices — the evolution beyond traditional prompt engineering.

Live coding demos include real examples of wrapping LLMs with production frameworks, managing context dynamically, and deploying via Vercel.

What you’ll learn:
• Why Context Engineering is the next evolution of Prompt Engineering
• How to build, ship, and share your first end-to-end LLM app
• Best practices for AI-assisted coding with Cursor and Claude CLI
• A breakdown of the modern LLM developer stack (OpenAI, uv, Vercel, React)
• Live examples of building agentic RAG-optimized applications
