## Description

Speaker: Tamara Fingerlin, Developer Advocate, Astronomer

Imagine you just completed a new Generative AI application prototype and it exceeded all expectations!

Now you need to move your model to production: automate fine-tuning, make sure the data remains up-to-date, manage changes in data formats, monitor model quality, don’t forget about lineage and governance requirements, make the pipeline robust in the face of ongoing changes to the APIs and tooling...It turns out that moving Generative AI applications to production is much more complex than you anticipated! More than ever, you need to borrow best practices from data engineering and MLOps. What you need is an orchestrator!

Apache Airflow is the leading workflow management and data orchestration framework, and the platform on which data and machine learning engineers can unify their workflows, directly integrating data engineering with Generative AI pipelines using custom Python scripts or pre-built modules for many popular data tools.
Additionally, Airflow is designed to be extensible so you can customize it for the needs of your organization. Everything you can do in Python, you can do in Airflow!

In this session we will explore the structure of production-quality Generative AI pipeline in Airflow using the fully open-source LLM application Ask Astro (ask.astronomer.io) as an example. This reference architecture shows best practices in using Airflow as well key Airflow features for day 2 Generative AI operations.
