## Description

Speaker: Garrett Wang: Co-Founder and CEO, Cerbrec

No doubt that the transformer model architecture has revolutionized AI, but working on these models has an ever expanding set of technical challenges and long learning curves. In this talk, we'll compare debugging a GPT model with PyTorch to working in Graphbook, the diagramming platform that allows data scientists to focus on model architecture. We'll do a quick dive into three transformer architectures, BERT, GPT, and T5, and talk about the R&D that went behind this novel, fully interactive user interface. This talk is suitable for all audiences.
