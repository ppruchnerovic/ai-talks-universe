## Description

Speaker: Varun Kumar Khare: CEO, NimbleEdge

The talk focusses on overcoming the de-facto trade-offs on privacy to personalization, latency to throughputs and scale to infrastructure costs. How over-reliance on cloud infrastructure has been a challenge for major applications hindering their revenue streams, complicated deployment cycles and session-aware ML capabilities. The talk will also be exploring the current state of edge computing infrastructure and the path ahead for MLOps.
