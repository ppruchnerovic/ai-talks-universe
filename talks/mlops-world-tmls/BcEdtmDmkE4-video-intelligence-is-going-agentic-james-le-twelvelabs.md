## Description

🎥 From GenAI World: Tools, Infra & Open Source Stack — Virtual Session (July 29, 2025)

Session Title: Video Intelligence Is Going Agentic
Speaker: James Le, Head of Developer Experience, TwelveLabs
Category: Human-Agent Interaction – UX, Prompt Design, and Agent Interfaces

Abstract:
While 90% of the world’s data exists in video format, most AI systems still treat video as static images or text overlooking critical temporal and multimodal relationships. This session explores the paradigm shift toward agentic video intelligence, where AI agents not only analyze video but reason about its content, plan workflows, and execute complex operations.

Drawing from real-world implementations, James Le demonstrates how video agents merge multimodal foundation models with agent architectures to tackle problems previously deemed impossible. Attendees will gain insights into:

• Architecting video agent systems using planner–worker–reflector patterns
• Handling high-dimensional temporal data while maintaining context
• Building multimodal interfaces that bridge natural language and visual media manipulation

Discover how this emerging class of video agents is transforming media, entertainment, and enterprise video processing—bringing AI closer to true multimodal reasoning.
