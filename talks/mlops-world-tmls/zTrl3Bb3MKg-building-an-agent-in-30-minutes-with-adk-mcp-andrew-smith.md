## Description

🎥 Recorded live at the MLOps World | GenAI Summit 2025 — Austin, TX (October 8, 2025)

Session Title: Building an Agent in 30 Minutes with ADK and MCP
Speaker: Andrew Smith, Customer Engineer for Startups, Google Cloud
Talk Track: Agents in Production

Abstract:
AI agents are changing the way we interact with software and data — but building them doesn’t have to be intimidating.

In this hands-on session, Andrew Smith from Google Cloud demonstrates how to quickly bridge the gap between large language models and your own tools, data, and APIs using ADK and the Model Context Protocol (MCP).

Through practical examples and live demos, attendees learn how to go from concept to a functioning, real-world agent in just 30 minutes — no proprietary complexity required.

What you’ll learn:
• How to connect LLMs to your tools, APIs, and data using ADK & MCP
• How to build a simple yet powerful agent from scratch in minutes
• Why AI agents are easier to implement than most teams expect
• Practical steps to turn AI theory into production-ready capability
