## Description

🎥 Recorded live at the MLOps World | GenAI Summit 2025 — Austin, TX (October 9, 2025)

Session Title: Agent Name Service (ANS) in Action – A DNS-like Trust Layer for Secure, Scalable AI-Agent Deployments on Kubernetes
Speaker: Akshay Mittal, Staff Software Engineer, PayPal
Talk Track: Agents in Production

Abstract:
Enterprise MLOps is rapidly evolving from model-centric pipelines to agent-centric ecosystems, where autonomous AI agents continuously retrain models, validate data, and remediate incidents — all with minimal human intervention.

Yet, production systems still lack a standardized way to discover, authenticate, and govern these agents securely at scale.

In this session, Akshay Mittal from PayPal introduces the Agent Name Service (ANS) — an open, DNS-inspired protocol that brings trust, verification, and governance to AI-agent deployments on Kubernetes.

Through live demonstrations and real-world architectures, Akshay shows how ANS enables end-to-end trust across the ML lifecycle — from validation and deployment to automated policy enforcement — using integrations with GitOps, Open Policy Agent (OPA), Sigstore, and open-source orchestration frameworks.

What you’ll learn:
• Why identity and capability verification are essential for agentic MLOps
• How to deploy ANS on Kubernetes using GitOps, OPA, and Sigstore
• Patterns for chaining validation, remediation, and notification agents with least-privilege access
• Performance and security benchmarks from a production pilot managing 1,000+ daily agent interactions
• Practical templates and GitHub references for implementing ANS in your own stack
