## Description

🎥 Recorded live at the MLOps World | GenAI Summit 2025 — Austin, TX (October 9, 2025)

Session Title: Multilingual ML in Action: Building & Deploying Continental R&D’s First Predictive ML Model
Speaker: Claudia Peñaloza, Data Scientist, Continental Tires
Talk Track: ML Training Lifecycle

Abstract:
What began as a simple proof of concept evolved into Continental’s first predictive machine learning model for R&D — a breakthrough designed to forecast tire performance and accelerate innovation cycles.

In this session, Claudia Peñaloza, Data Scientist at Continental Tires, shares how her team built and deployed this multilingual, production-grade ML model using a language-agnostic MLOps platform. The system enabled global collaboration across teams, high-performance distributed runs, and a seamless path from experimentation to deployment.

Now fully integrated into Continental’s ecosystem — connected to PostgreSQL databases and Tableau dashboards — the model has become a daily tool for tire developers and a repeatable framework for scaling ML success across the company.

What you’ll learn:
• How Continental’s R&D built its first predictive ML model from proof of concept to production
• The role of language-agnostic MLOps platforms in enabling cross-team, multilingual collaboration
• How to design scalable, repeatable ML workflows that bridge experimentation and deployment
• Practical lessons on integrating ML outputs into existing business systems and dashboards
• How to turn individual ML projects into a foundation for company-wide innovation
