Abstract:
Acerta Analytics builds machine learning solutions for automotive manufactures that help increase assembly/production line efficiency, provide actionable insights and reduce the operational costs.

With a growing customer base :-
- we have to keep up with increasing Data volume
- ensure ML models in production are robust
- handle Data Drift

Deploying and maintaining machine learning in production is hard but reproducibility and explainability of results is even harder. ML model development lifecycle (MDLC)/MLOps is critical in creating a production grade system that scales when deploying hundreds of models at customer’s assembly lines.
We designed and built an ML platform from scratch using concepts of MLOps that orchestrated the complete workflow of training/deploying/monitoring/updating machine learning models scalable across different environments. This was critical in achieving traceability and reproducibility of ML models deployed at customer sites. Building this platform involved containerizing each step in the model lifecycle starting from data ingestion, preprocessing, training, validation, deployment, and performance monitoring.

Implementing this system in production facilitated the following deliverables:
1 Reusable infrastructure for different ML projects
2 End-to-end testing and performance checks
3 Robust codebase with versioning to ensure reproducibility
4 Model metadata store for traceability
5 Ability to auto-retrain based on thresholds and feedback loop
6 Reduced development and deployment lifecycle
7 Real-time Alerting/monitoring dashboards
8 Platform scalability and resilience to failure
