🎥 From GenAI World: Tools, Infra & Open Source Stack — Virtual Session (July 29, 2025)

Session Title: Mission: Data Possible – Rethinking Data Architecture for GenAI
Speaker: Jörg Schad, PhD, Head of Engineering, Nextdata
Category: Data Pipelines & Preprocessing for GenAI

Abstract:
As enterprises move from GenAI prototypes to production systems, one core limitation is becoming clear—it’s not the models, it’s the data infrastructure. Most existing stacks were built for dashboards and reports, not for autonomous agents that continuously consume, reason over, and act on data in real time.

The autonomous consumption of data by LLMs introduces new challenges in data management:

• Task-specific data discovery and access—providing relevant context without unnecessary noise
• Safe data access—delivering high-quality information without exposing sensitive content
• Supporting autonomous speed and frequency of access

In this session, Jörg Schad presents a developer-centric framework for building AI-native data infrastructure, designed from the ground up to support GenAI and autonomous workflows. By using standardized interfaces for autonomous data products, this approach enables faster, more flexible productionization of GenAI prototypes.

Whether you’re building internal copilots or automating workflows with agents, this talk shows how to bridge the gap between GenAI models and the robust data infrastructure they need to thrive.
