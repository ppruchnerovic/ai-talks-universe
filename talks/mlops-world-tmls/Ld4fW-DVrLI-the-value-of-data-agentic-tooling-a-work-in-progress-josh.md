Session Title: The Value of Data Agentic Tooling: A Work in Progress
Speaker: Josh Goldstein, Solutions Architect, Weaviate
Category: Vector Databases & Retrieval Infrastructure

Abstract:
As enterprises rapidly embrace AI agents to automate workflows, augment decision-making, and transform customer experiences, these agentic systems continue to grow in complexity—along with the overhead for users and developers.

In this session, Josh Goldstein demonstrates how bespoke data agents can help developers build faster and get use cases into production efficiently. He explores how purpose-built data agents solve critical challenges in data discovery, integration, and governance that limit enterprise AI effectiveness.

Through real-world case studies, Josh illustrates how data agents deliver faster customer value and empower teams to unlock the true potential of AI-driven systems.
