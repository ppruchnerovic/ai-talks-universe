## Description

Speaker Bio:
Ihab Ilyas, Professor
University of Waterloo

Abstract:
Data owners often desire to publish a synthetic data instance that ensures the privacy of individual records, but is similarly useful as the original sensitive data. Existing differentially private data synthesis methods usually fail in preserving one of the most fundamental data properties: the underlying correlations and dependencies among tuples and attributes (i.e., the structure of the data), compromising the utility of the output to downstream tasks.

With probabilistic database models and show how to: (i) privately learn a probabilistic model based on the original private data (how data was generated); and (ii) sample a new synthetic private instance based on the learned model. We leverage the HoloClean framework to learn the underlying data distribution, and we show that learning this model privately is technically challenging.

In this talk I briefly describe the HoloClean framework for structured data prediction, and Kamino a system that learns HoloClean models privately and use them to synthesize "useful" private data instances.
