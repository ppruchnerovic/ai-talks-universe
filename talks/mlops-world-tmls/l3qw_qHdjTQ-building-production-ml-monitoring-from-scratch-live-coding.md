## Description

Speaker:
Alon Gubkin, CTO, Aporia
Alon Gubkin is the VP R&D of Aporia, a customizable monitoring platform that enables data science teams to build their own monitoring solution for ML models in production.

Writing code from the age of seven, Alon is passionate about programming, machine learning, biology, video games, and software architecture. He created his first successful open source project, a video chat platform for mobile, and Spider, a new programming language, when he was 17.

Before joining Aporia, Alon served as an R&D lead in the elite 81 intelligence unit of the Israel Defense Forces. While in the IDF, he worked on multiple machine learning projects including a CNN-based head pose estimation and video game bots.

Abstract:
In this session, together we will build a cloud-native ML Monitoring stack using open-source tools.

We’ll start from explaining the basic principles of Machine Learning monitoring in production, and then create a live web dashboard to measure model drift (training compared to prediction), feature statistics, and performance metrics in production. This monitoring stack will also enable us to integrate Python-based custom metrics which will be displayed on the dashboard.

The code will be available on GitHub after the workshop.
