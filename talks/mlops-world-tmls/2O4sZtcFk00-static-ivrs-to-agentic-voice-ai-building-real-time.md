## Description

🎥 Recorded live at the MLOps World | GenAI Summit 2025 — Austin, TX (October 8, 2025)

Session Title: From Static IVRs to Agentic Voice AI: Building Real-Time Intelligent Conversations
Speaker: Pablo Salvador Lopez, Principal AI Application Development Architect – AI Solution Engineering Global Black Belt Team, Microsoft
Talk Track: Agents in Production

Abstract:
The era of static IVRs is coming to an end. In this talk, Pablo Salvador Lopez demonstrates how to design and deploy real-time intelligent voice agents that move beyond pre-scripted menus toward dynamic, human-like interactions.

Using agentic architectures, Pablo explores how multiple specialized agents can collaborate to understand context, reason dynamically, leverage memory, and deliver seamless voice AI experiences with optimized speech latency.

This session provides a roadmap for teams building the next generation of voice-driven AI systems — from design principles and architecture patterns to latency optimization and conversational flow orchestration.

What you’ll learn:
• The fundamentals of agentic architecture for real-time voice applications
• How to orchestrate specialized agents for dynamic, natural conversations
• Practical strategies to reduce speech latency and improve responsiveness
• Techniques to integrate memory and contextual reasoning into voice AI systems
• How to evolve static IVRs into fully autonomous, intelligent voice agents
