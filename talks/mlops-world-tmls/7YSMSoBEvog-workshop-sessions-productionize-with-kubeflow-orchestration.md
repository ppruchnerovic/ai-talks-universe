## Description

He has worked for Wells Fargo, on various financial products, and AI solutions on various lines of business.

Abstract:
In this workshop, attendees will get to set up a framework for machine learning with a classification problem using Kubeflow, Feast, and Kafka, and build the pipeline with Kubernetes and Docker in GCP.

Participants will also learn about the data feature store management using Feast and serve the endpoint with KF serving. With the use of Grafana, the model performance will be checked and attendees will learn how to perform the API call for prediction endpoint for real-time Kafka data and batch data.
