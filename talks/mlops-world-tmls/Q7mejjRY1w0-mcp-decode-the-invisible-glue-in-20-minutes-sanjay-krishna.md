Session Title: MCP: Not Another Build Guider – Decode MCP’s Invisible Glue in 20 Minutes
Speaker: Sanjay Krishna Anbalagan, Front End Engineer, AWS
Category: Tool Use and Chaining

Abstract:
Most talks on the Model Context Protocol (MCP) dive straight into SDK snippets and server diagrams. This one does the opposite—it peels back the layers to reveal what MCP actually removes from your plate and why that abstraction matters once large-language models start calling real tools in production.

Attendees won’t just learn how to spin up an MCP server—they’ll understand why the abstraction exists, what complexities it hides, and how recognizing those hidden layers can help design more resilient agent pipelines.

If you’ve ever wondered what makes MCP the invisible glue of modern agentic architectures, this talk decodes it all—in just 20 minutes.
