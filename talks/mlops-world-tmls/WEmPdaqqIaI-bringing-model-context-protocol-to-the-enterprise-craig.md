## Description

🎥 From GenAI World: Tools, Infra & Open Source Stack — Virtual Session (July 29, 2025)

Session Title: Bringing Model Context Protocol to the Enterprise: From Chaos to Catalog
Speaker: Craig Jellick, Director of Engineering & Co-founder, Obot.ai
Category: Model Context Protocol (MCP)

Abstract:
What if you could plug cutting-edge open-source tools directly into your enterprise AI applications and workflows—without compromising on security or governance?
In this session, Craig Jellick introduces the Model Context Protocol (MCP), explaining how it works and why it has become the standard for integrating LLMs with the tools and applications enterprises already rely on. He walks through the practical constraints of adopting MCP in enterprise environments—where open-ended access isn’t an option—and demonstrates how to build a centralized, OAuth-secured MCP catalog that scales.
You’ll see how to consume MCPs safely across clients, applications, and internal tools, and how to use them to build a real, useful AI chat assistant. Leave with a clear path to leveraging MCP in your organization—securely, productively, and fast.
