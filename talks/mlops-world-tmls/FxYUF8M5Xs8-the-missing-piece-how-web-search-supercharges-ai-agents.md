## Description

Recorded live during the Lightning Talks at the MLOps World | GenAI Summit 2025 — Virtual Sessions (October 8, 2025)

Session Title: The Missing Piece: How Web Search Supercharges AI Agents
Speaker: Noah Nefsky, Forward Deployed Engineer, Tavily
Talk Track: Agents in Production

Abstract:
Why haven’t AI agents advanced as fast as we hoped? One major reason: limited access to live, reliable knowledge.

In this lightning talk, Noah Nefsky, Forward Deployed Engineer at Tavily, explains how giving agents web search capabilities changes everything — transforming them from isolated systems into dynamic, context-aware problem solvers.

Noah shares real-world use cases from Tavily’s enterprise deployments, showing how connecting agents to the web as a knowledge base can supercharge accuracy, scalability, and business impact. He also walks through practical design strategies for building production-ready, measurable, and enterprise-aligned AI agents that go beyond demos and deliver tangible value.

What you’ll learn:
• Why AI agents stagnate without reliable access to real-world data
• How to integrate web search as a core component of agent design
• Strategies for building scalable, production-ready AI agents
• How to align agent architectures with enterprise priorities and KPIs
• Real lessons from Tavily’s enterprise implementations
