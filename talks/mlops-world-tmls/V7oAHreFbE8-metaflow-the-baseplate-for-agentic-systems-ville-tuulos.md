## Description

🎥 Recorded live at the MLOps World | GenAI Summit 2025 — Austin, TX (October 8, 2025)

Session Title: Metaflow: The Baseplate for Agentic Systems
Speaker: Ville Tuulos, Co-Founder & CEO, Outerbounds
Talk Track: Agents in Production

Abstract:
Frameworks like LangChain or OpenAI’s Agent SDK make it easy to build agent prototypes—but getting them into production requires more than just a few scripts. True deployment demands resilience, memory, runtime orchestration, and secure service access—a full infrastructure baseplate.

In this session, Ville Tuulos introduces the newly released open-source Metaflow 2.18, built specifically to serve as that baseplate for agentic systems. Building on years of battle-tested production use, Metaflow now supports agent workflows, orchestration, and integration with the Model Context Protocol (MCP), enabling robust access to external tools and data.

Ville demonstrates how Metaflow pairs seamlessly with agent frameworks to create a complete, production-ready stack for real-world AI agents—and shows a practical implementation you can adapt to your own use cases.

What you’ll learn:
• The full stack needed for production-grade agentic systems
• How open-source Metaflow supports agent orchestration and integration
• How to pair agent frameworks with resilient MLOps infrastructure
• A practical example of deploying agents with Metaflow 2.18
