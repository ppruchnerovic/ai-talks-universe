## Description

🎥 From the MLOps World | GenAI Summit 2025 — Virtual Session (October 7, 2025)

Session Title: Gradio: The Web Framework for Humans and Machines
Speaker: Freddy Boulton, Open Source Software Engineer, Hugging Face
Talk Track: Augmenting Workforces with Agents

Abstract:
The Model Context Protocol (MCP) has enabled AI agents to interact seamlessly with applications—but shouldn’t these same applications be just as accessible to humans?
In this talk, Freddy Boulton introduces Gradio as “The Web Framework for Humans and Machines.” He explores how developers can build performant, user-friendly web interfaces that serve both human users and AI agents—simultaneously.

Thanks to automatic MCP integration, every Gradio app can become a fully compliant, feature-rich interface for AI systems, complete with built-in file handling, authentication, and real-time progress tracking. Freddy also highlights how the Hugging Face Hub acts as the world’s largest open-source MCP “App Store”, offering an ecosystem of Gradio-powered Spaces for developers and agents alike.

What you’ll learn:
• How to build performant, feature-rich UIs for AI models entirely in Python using Gradio
• How these apps can be shared with humans or plugged into any MCP-compliant AI agent
• How Hugging Face Spaces serve as an open ecosystem for AI tools and interfaces
• How Gradio simplifies MCP integration with a “write once, deploy everywhere” philosophy
