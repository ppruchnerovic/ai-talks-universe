Abstract:
Machine learning models are never done. The world is always changing and models rely on data to learn useful information about this world. In ML systems we need to be able to embrace change without sacrificing reliability. But how do we do it? MLOps.

MLOps, the process of operationalizing your machine learning technology, is fundamental to any organization leveraging AI. However, the complexities of machine learning require managing two lifecycles: the code and the data. Pachyderm is a platform that provides the foundation for unifying these two lifecycles.
