## Description

🎥 From GenAI World: Tools, Infra & Open Source Stack — Virtual Session (July 29, 2025)

Session Title: Go to Prod With AI Automated Workflow at Work: A Case Study from Microsoft Teams Agent
Speaker: Pratik Verma, Founder & CEO, Okahu.ai
Category: Agentic Logging & Observability

Abstract:
Agentic applications can automate a lot of tedious work through bots in platforms like Microsoft Teams, Slack, and more. But understanding where these bots fail is essential to confidently move them into production.
In this session, Pratik Verma walks through a case study of a simple Microsoft Teams bot, showing how open telemetry–based AI observability techniques can identify issues and bottlenecks, whether they occur at the message, bot, LLM, or interaction level. He demonstrates how to quickly fix them by adjusting prompts or code in VS Code.

The demo is built using the open-source tool Monocle, with a sample available on GitHub. Learn how to use observability tools to make AI agents more reliable, debuggable, and production-ready.
