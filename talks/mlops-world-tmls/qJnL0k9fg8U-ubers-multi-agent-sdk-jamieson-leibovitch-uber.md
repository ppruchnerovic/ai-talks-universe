## Description

🎥 From the MLOps World | GenAI Summit 2025 — Virtual Session (October 7, 2025)

Session Title: Uber’s Multi-Agent SDK
Speaker: Jamieson Leibovitch, Senior Software Engineer, Uber
Talk Track: Agents in Production

Abstract:
How does Uber leverage multi-agent systems to power its global operations?
In this session, Jamieson Leibovitch takes us behind the scenes of Uber’s Agent Platform and its in-house SDK, AgentFx, designed to enable enterprise-ready agentic use cases at massive scale.

Learn how Uber approaches agent orchestration, coordination, and integration across complex workflows — from data pipelines to customer-facing applications — and how these technologies are helping shape the company’s next generation of AI-driven systems.
What you’ll learn:

• How Uber designs, deploys, and scales agents across its internal ecosystem
• Key architectural principles behind Uber’s Agent Platform and AgentFx SDK
• How agents power core business processes at enterprise scale
• Practical lessons from real-world production implementations
