## Description

Building AI agents is easy — but making them production-ready is hard. AI agents in production face infrastructure failures, API timeouts, and rate limits that demos never show.

This talk by Temporal's Melissa Herrera demonstrates how durable execution transforms fragile agent prototypes into production-ready systems. Through live demos and real-world examples, attendees learned how Temporal's Workflow orchestration handles crash recovery, automatic retries, long-running tasks, and state management — letting you write simple code while getting enterprise-grade reliability for your AI agents.
