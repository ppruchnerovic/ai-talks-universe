# AI Dev 25 x NYC | Christoph Meyer, Lars Heling: Improving AI Agent Discovery with a Knowledge Graph

**Christoph Meyer**

`AI Dev (DeepLearning.AI)` · `DeepLearning.AI` · `2025` · `36 min`

[Watch the recording](https://www.youtube.com/watch?v=XrYwFUdu2lk) · [Conference site](https://ai-dev.deeplearning.ai/)

## Description

Christoph Meyer, Principal AI Scientist and Lars Heling Senior Knowledge Engineer at SAP SE, discussed at AI Dev 25 x NYC how to improve AI agent discovery and execution using a knowledge graph.

LLMs make agents fluent; knowledge graphs make them effective. This session showed how a knowledge graph gives AI agents the semantic and process context to discover and safely invoke the right tools and APIs across complex enterprise systems.

They covered key techniques—semantic retrieval, process-aware API connectivity, and how they align with the Model Context Protocol (MCP) and run a demo where an agent applied these methods.
