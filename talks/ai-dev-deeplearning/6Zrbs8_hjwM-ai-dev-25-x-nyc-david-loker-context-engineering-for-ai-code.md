## Description

David Loker, Director of AI at CodeRabbit, discussed context engineering. As AI-generated code becomes commonplace, the bottleneck in developer productivity has shifted from code generation to code review.

CodeRabbit addresses this with a context-engineered AI code review platform that fuses data from multiple sources—AST-based dependency graphs, MCP, 40+ open-source linters, repository history, coding agent guidelines, and custom rules—with advanced LLM reasoning.

This AI Dev 25 x NYC session demonstrated how CodeRabbit orchestrates these context signals into precise LLM prompts, powering agent-to-agent reviews across the CLI, IDE, and pull requests. Attendees left with a blueprint for building context-rich AI review systems that integrate multi-source data and carefully engineered prompts to detect hard-to-find bugs like race conditions, architectural flaws, missing tests, and concurrency bugs that go beyond simple linting.
