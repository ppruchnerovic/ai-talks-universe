## Description

Every serious agent will eventually need to buy tools, data or resources. Today, that means hardcoded API keys, shared credit cards, or looping in a human. x402, Coinbase's open protocol built on HTTP 402, claims to be one of the strongest candidates to fix this. This talk covers what Ondra Urban's team at Apify learned shipping x402 to Apify's 25,000 Actors: why the "exact" payment scheme breaks on usage-based pricing, the refund-based workaround we run in production, why handing an agent your private key is a terrible idea, and how mcpc, the open-source MCP CLI we built, keeps wallets out of LLM context.
