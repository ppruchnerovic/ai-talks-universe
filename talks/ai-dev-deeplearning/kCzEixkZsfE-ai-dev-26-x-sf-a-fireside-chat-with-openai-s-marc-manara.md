## Description

In this fireside chat with Marc Manara from OpenAI during AI Dev 26 x San Francisco, he discussed the evolving landscape of AI-driven software development and how OpenAI collaborates with startups.

While Manara believes software engineering is not dying, he predicts the abstraction layer is moving up. Engineers may increasingly function as managers for multiple autonomous agents, and the definition of an "engineer" may expand to include anyone who can produce software using these advanced tools.
