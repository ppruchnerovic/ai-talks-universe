## Description

Devs spend more time fixing agent mistakes than shipping features.

On this episode of AI Native Dev, Guy Podjarny, founder & CEO at Tessl, and Simon Maple, Head of Developer Relations, announce two new products, the Tessl Framework and the Tessl Spec Registry, built to make specs the source of truth, keeping agents aligned with intent and code dependable.

On the docket:
• Why agent development needs its own dependency system
• Using specs to create tests that validate agent outputs
• How Tessl’s 10,000 usage specs prevent agent mistakes with open-source
• Into Tessl’s concept of “vibe speccing”
• The long term bet on spec-centric software
