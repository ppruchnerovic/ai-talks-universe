## Description

Did an agent write that? Know you can know. Git AI is an open source git extension that tracks every line of AI code that gets added to a repo. You can reset, rebase, reformat, copy/paste, cherry-pick -- Git AI won't lose track. You get accurate AI attribution from your laptop to production.

Come by for a live demo and hear stories about how measuring AI and tracking AI code has helped teams large and small ship better code, faster.

Takeaways
1. There's an emerging standard for tracking AI code (adopt it!)
2. The new SBOM is knowing which code is AI and tying incidents back to it.
3. Saving prompts will make agents smarter. Start today!
