# ​MCP Mayhem: Fun Ways AI Agents Write Bad Code - Andrew Oates

**Andrew Oates**

`AI DevCon (Tessl)` · `Tessl` · `2025` · `16 min`

## Description

​AI coding agents are often compared to junior developers --- but they're not!  AI Agents are better than humans at some things, and worse at others.  Let's discuss the unique security challenges of coding with AI, and how to maximize the quality and security of AI-generated code while improving your productivity.

​Andrew Oates is a Distinguished Engineer at Snyk, where he leads the Open Source Security and Agentic Development organizations.  Before Snyk, Andrew worked at Google, where he led infrastructure and security teams for Google Distributed Cloud and Stadia.
