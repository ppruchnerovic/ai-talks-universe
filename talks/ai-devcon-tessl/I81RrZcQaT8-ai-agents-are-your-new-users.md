## Description

Coding agents now read your docs, call your CLIs and APIs, and even react to your error messages, but you can't grab a coffee with them and ask for feedback. Patrick Chanezon, VP of Developer Relations at Microsoft, and Jay Gordon, Senior Program Manager on Azure Cosmos DB, show how Microsoft measures agent experience with Scope, its open-source evaluation system built on scenarios, criteria, profiles and gates, and how the Cosmos DB team used it to improve its agent kit and docs. Recorded at AI DevCon New York 2026.

What we cover:
– Why coding agents are a new kind of user for your APIs, CLIs and docs
– Propensity vs efficacy: will agents pick your product, and use it well?
– The agent experience playbook: scenario, criteria, profile and gates
– Measuring lift, drag and cost across harnesses, models, MCP servers and skills
– A demo comparing curl, the GitHub MCP server and the GitHub CLI
– How Azure Cosmos DB used Scope to improve its agent kit and docs
