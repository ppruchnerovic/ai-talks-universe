## Description

What if your coding agent's output had to pass a mechanical verifier before it ever reached the context window? Fernanda Graciolli and Nada Amin, co-founders of Midspiral, share a verification-aware process for agentic programming: contracts checked by an external verifier, a tight agent–verifier loop, functional-core patterns that maximize what can be verified, and ways to stop specs drifting as software evolves. Recorded at AI DevCon New York 2026.

What we cover:
– What verification means when it escapes LLM judgment
– How errors compound in an agent's context window
– Turning agent output into candidates with a mechanical verifier
– Contracts: reviewing a few lines of spec instead of the whole diff
– Functional core, state invariants and the interpreter pattern
– Freezing specs so they don't drift as software evolves
