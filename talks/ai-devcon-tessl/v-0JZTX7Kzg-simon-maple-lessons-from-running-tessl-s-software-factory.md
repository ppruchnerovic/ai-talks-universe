## Description

Tessl's software factory opens around 1,200 agent-written pull requests a week, and 75% merge without a human needing to step in. Simon Maple from Tessl shares what it took to get there, from agent loops and feedback loops to the runaway review loop that taught the team to cap every run.

What we cover:
– What a software factory actually is: agent loops, feedback loops and review lenses
– Why every agent loop needs a run cap and a spend cap
– Giving operational changes separate authority, and tests an independent source of truth
– How good agent skills let Sonnet match Opus on review at roughly 39 cents on the dollar
– A live build of a software factory with Tessl, from Linear ticket to merged pull request
– Why owning your context and staying model-agnostic matters
