## Description

One engineer at This Dot Labs merged 231 pull requests in 30 days with 99.6% of the code written by AI, and none have been reverted. Tracy Lee, CEO of This Dot Labs, and Coston Perkins, Engineering Lead II, argue that if that sounds out of reach, the problem is usually code base readiness. Borrowing the strangler pattern, they show how to hand each step to workflows that mix scripts and agents: one-command app setup, deterministic standards, LLM judges, local CI, evidence-rich pull requests and responding to production signals. Recorded at AI DevCon New York 2026.

What we cover:
– Why developer-in-the-loop AI is becoming the new legacy process
– Using the strangler pattern to move work into workflows
– One command to run your app, for agents and new hires
– Deterministic team standards, with scripts outside the model
– LLM judges, local CI and pull requests that carry their own evidence
– Responding to production signals, and what's left for engineers
