## Description

Dreaming, a unique approach to memory in AI, is transforming how agents learn and operate over time. This process continuously refreshes and refines what an agent knows, leading to significant performance improvements. Imagine a system that doesn't just retain information, but actively curates and enriches it, turning learning into a dynamic growth engine.

Lamis Mukta, from Anthropic and part of the applied AI team, explores this concept further. With her experience in working directly with startups and founders, Lamish is at the forefront of pushing AI boundaries. Her insights help navigate the complex balance of integrating advanced AI functionalities like dreaming with practical, production-ready systems.

What we cover:
• The bottlenecks in current memory management strategies
• How does memory pruning enhance agent capabilities?
• Designing a dreaming service for practical applications
• Handling multiple agents in shared memory systems
• Ensuring memory accuracy with versioning and concurrency
