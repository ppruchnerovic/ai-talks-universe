# Memory Without Deterministic Coordinates Is Just Hearsay

## Description

As coding agents work across repos, engineers and weeks, their findings need to be shared, but can you trust which code a memory is actually about? Veljko Kovac, Head of Forward Deployed Engineering at Cognee, the open-source memory platform for agents, explains why memory files, CLAUDE.md, shared folders and skills all fall short, and why every finding needs deterministic coordinates: a function ID and version that are the same on every machine. He shows how linking a code graph to a memory graph enables trustworthy sharing, conflict detection and analysis. Recorded at AI DevCon New York 2026.

What we cover:
– Why agents in a software factory need to share what they learn
– The limits of MEMORY.md, CLAUDE.md, shared folders and skills
– Why a finding is a fact that should be looked up, not decided
– Deterministic coordinates: function IDs and versions that match on every machine
– Connecting a code graph to a memory graph
– An experiment comparing LLM-attributed and deterministic memory
