## Description

Rewriting your Java applications in Python? According to Rod Johnson, that's a monumental misstep. Many developers today are chasing the trend of switching languages, but Rod insists that enterprise applications thrive on leveraging their existing Java stack. It's as simple as making an HTTP call, yet the simplicity is often overlooked. This isn't about language wars, but about making the right technical decisions that align with business needs.

Rod Johnson, the creator of the Spring Framework and founder of Embabel, lends his insights on the future of enterprise AI. As a pioneer in Java development, Rod underscores the often ignored pitfalls of integrating AI. He reveals how improper use of AI coding agents can spiral into chaos if not managed correctly, sharing his vision for Embabel, a JVM-native agentic framework, and why he's skeptical about the Model Context Protocol despite its growing popularity.

What we cover:
• Why rewriting Java apps in Python is a critical mistake
• The importance of using Java for enterprise AI tasks
• What is the #1 AI failure pattern in large enterprises?
• Rod Johnson's perspective on vibe coding and its risks
• How Embabel's planning algorithm is inspired by video game NPCs
