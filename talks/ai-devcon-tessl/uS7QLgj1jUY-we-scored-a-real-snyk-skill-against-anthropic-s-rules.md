## Description

AI skills often miss the mark on security, even as they optimize functionality. Simon Maple demonstrates how Tessl's review process can push a real Snyk skill from an impressive 87% to an even stronger 90% score, identifying key areas for improvement in real time. For many, it's not about knowing if a skill works, but if it's the right one—and if it's safe to use.

Simon Maple joins forces with Krzysztof Huszcza, who heads product strategy at Snyk. With Snyk's expertise, they delve into how progressive disclosure and Snyk's own Agent Scan tool reveal hidden security vulnerabilities in AI skills, ensuring every skill meets high-security standards before going live.

What we cover:
• Live-reviewing a real Snyk skill against Anthropic's skill-writing best practices
• How do Tessl's review run and review fix commands auto-improve a SKILL.md?
• The significance of progressive disclosure and reference files for skill quality
• Standardizing and sharing skills within Snyk, from personal to platform-level
• Snyk's 'Toxic Skills' report and identifying security risks in poorly written skills
• Using Snyk's Agent Scan tool to catch prompt injection and other vulnerabilities
