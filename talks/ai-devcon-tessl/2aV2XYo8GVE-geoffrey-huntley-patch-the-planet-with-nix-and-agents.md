## Description

With AI finding security vulnerabilities faster than teams can patch them, the answer is engineering: a hardened harness for your coding agents and the ability to patch anything, fast. Geoffrey Huntley, creator of the Ralph loop and field CTO at Antithesis, shows how one Nix source of truth covers laptops, CI, agent sandboxes and production, how to remove risky capabilities from agents entirely, and how to build loops with real back pressure. Recorded at AI DevCon New York 2026.

What we cover:
– Why security takeoff is the new normal for open source
– Do you still need third-party libraries when agents can write them?
– Patch the Planet: monkey-patching any dependency with Nix
– One source of truth for laptops, CI, agent sandboxes and production
– Removing capabilities like git force push from your agent harness
– Loop engineering with deterministic checks and property-based testing
