## Description

GitHub Agentic Workflows let you hand the toil of maintaining a repo, from docs and tests to refactoring and dependency updates, to agents that run continuously in GitHub Actions. Landon Cox, Senior Principal Researcher at GitHub Next and Microsoft Research, who leads security for the project, explains the model that keeps them safe: agents never touch secrets, untrusted content is filtered, and every write passes through deterministic safe outputs. He also previews enclave agents with information budgets for cross-repo workflows that touch private code. Recorded at AI DevCon New York 2026.

What we cover:
– What GitHub Agentic Workflows are and why they took off
– Continuous automation for the toil in your repo
– Three security principles: secrets, untrusted reads and safe outputs
– Keeping auth tokens away from agents with proxies and gateways
– Logging everything for security, debugging and token efficiency
– Enclave agents and information budgets for cross-repo workflows
