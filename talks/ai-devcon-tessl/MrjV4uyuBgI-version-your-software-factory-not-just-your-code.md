## Description

If a factory built everything in production, which factory is responsible when production breaks? Daniel Meppiel, Director of Agent & Dev Platforms at Microsoft, argues we should treat a software factory as software: define agent contracts, version and package them, and rebuild the fabric of trust we already rely on for classic software. He shows how APM, an open-source package manager for agents, fits in. Recorded at AI DevCon New York 2026.

What we cover:
– What large enterprises ask for, starting with verification
– The fabric of trust behind classic software
– Treating a software factory as an agent program
– Agent contracts: defining what an agent should do
– Packaging and versioning agent primitives with APM
– Answering 'which factory broke production?'
