## Description

Inside SpaceXAI's software factory, most engineers now work almost entirely through cloud coding agents, and fixes can go from feedback to merged PR with little human intervention. Shivam Jindal, Field Engineering Leader at SpaceXAI, shows how the team uses Grok Bots, Cursor Projects, cloud agents and Cursor Automations, live-builds an app from audience feedback, and explains how they encode trust into the system. Recorded at AI DevCon New York 2026.

– Why your attention becomes the bottleneck, and how to encode trust instead
– Making your code base agent-friendly with verification, skills and linters
