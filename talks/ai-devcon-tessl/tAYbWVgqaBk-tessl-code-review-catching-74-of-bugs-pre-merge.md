## Description

Coding agent reliability is the real bottleneck in a software factory — your agent can open the PR, but can you trust what's in it? Tessl Code Review is Tessl's answer: an AI code reviewer that catches real defects in agent-generated pull requests, and gets sharper the more your team uses it.

In this walkthrough, Tessl's Marc Sloan and Colin Hallett show how Tessl Code Review works, how to set it up, and how to build review rules tuned to your own codebase.

What we cover:
– Why coding agent reliability is the hard part of a software factory
– How Tessl Code Review plugs into GitHub as an automated reviewer
– The four default review lenses (and the three Tessl added for itself)
– Building and tuning a custom review lens with Tessl's own agent
– Configuring enforcement, effort level, and per-path lens scoping
– Running Tessl Code Review locally, before you even open a PR
