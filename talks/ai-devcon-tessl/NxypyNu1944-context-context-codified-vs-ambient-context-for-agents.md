# Context != Context: Codified vs Ambient Context for Agents

## Description

Everyone agrees context matters, but context isn't one thing. Birgitta Boeckeler, Principal Engineer & Developer Relations at Unblocked, separates codified context, like the AGENTS.md files and skills you deliberately author and reuse, from ambient context assembled at task time from Slack, wikis, tickets and PRs. She walks through what it takes to build a context engine that ingests, evaluates, assembles and observes ambient context, including how it resolves conflicting information using code as the source of reality. Recorded at AI DevCon New York 2026.

What we cover:
– Why 'context' needs more precise categories
– Codified vs ambient context, and why they're delivered differently
– A framework for what good-quality context looks like
– The limits of wiring agents to many MCP servers
– Building a context engine: ingest, evaluate, assemble, observe
– Resolving conflicting information, with code as the source of reality
