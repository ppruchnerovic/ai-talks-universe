## Description

Your AI coding agent learned from millions of lines of code, including insecure ones. It can therefore write vulnerable code by default. How do you fix that? Introducing a security skills layer that teaches coding agents how to write and review code securely. The result: a remarkable 84% success rate versus a 47% baseline. It sounds improbable. It works.

John Groetzinger, Principal Engineer at Cisco, brings his groundbreaking work on CodeGuard to light. As a key player in a team focused on enhancing AI's impact in enterprise environments, John shares how he spearheaded the development of this security layer. His insights reveal the meticulous balancing act between creativity and security that defines AI development at Cisco.

• How CodeGuard works to secure AI-generated code
• Why Cisco decided to open source CodeGuard
• How to get agents to fix their own mistakes using a surprisingly simple method
• What is the Tessl Evaluation Journey in measuring success?
