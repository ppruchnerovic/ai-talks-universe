## Description

What gives you speed in engineering, if every pull request slows you down?

Merrill Lutsky, Co-founder and CEO of Graphite, joins Guy Podjarny to show how engineers transform review slowdowns into rapid delivery with AI agents and stacked PRs.

They unpack:
• how stacked PRs turn agent generated code into clear, digestible chunks.
• by automating repetitive checks, AI agents free humans to focus on architecture and strategy.
• how engineers are moving from coding line by line to orchestrating complex multi-agent workflows.
• reviews evolve into continuous feedback loops that sharpen both code and team skills.
