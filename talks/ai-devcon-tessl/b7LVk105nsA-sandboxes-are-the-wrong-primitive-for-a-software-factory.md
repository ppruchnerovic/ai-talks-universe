## Description

Every improvement to a software factory is a trade-off, and the hottest take here is that sandboxes are the wrong primitive for running coding agents. Chris Poulter, founder of usenucleus.dev, shares what he learned building a workflow engine for agentic coding: an evidence-based lifecycle for factory improvements, a decomposed agent harness, and a code graph that runs only the checks each edit needs. Recorded at AI DevCon New York 2026.

What we cover:
– Why every software factory improvement is a trade-off
– How a retrospective fix can overfit and make things worse
– A separate, evidence-based lifecycle for factory improvements
– Why sandboxes are the wrong primitive for coding agents
– Decomposing the agent harness: agent loop, tools, file system and execution
– Using a code graph to cut per-edit checks to about 15 seconds
