## Description

With code mode, agents stop picking from a fixed list of tools and start writing and running their own programs, often from untrusted inputs and with no human checkpoint. Cornelia Davis, Developer Advocate at Temporal, explains why that calls for more than a sandbox: governance sandboxes that inherit the harness's permissions and policies, and never exceed them. She compares OS sandboxes and egress gateways with interpreter sandboxes like Pydantic Monty, and live-demos a travel agent where a policy engine blocks a prompt injection. Recorded at AI DevCon New York 2026.

What we cover:
– Why code mode changes the security model for agents
– The spectrum from no sandbox to fully locked down
– Governance sandboxes: inherit permissions and policies, never exceed them
– OS sandboxes with egress gateways vs interpreter sandboxes like Monty
– Live demo: approvals and a policy engine blocking a prompt injection
– Keep credentials out, deny by default and record everything
