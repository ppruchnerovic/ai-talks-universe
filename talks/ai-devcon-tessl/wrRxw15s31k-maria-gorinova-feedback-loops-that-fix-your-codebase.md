## Description

Agent feedback loops are how a software factory maintains itself: agents mining their own session logs, PR comments and production signals, then fixing what they find. Maria Gorinova, member of technical staff at Tessl, explains how to build them, and why vague intent turns a loop into a mess.

What we cover:
– What a software factory is: repeatable workflows, a shared execution environment and agent feedback loops
– Why agent context alone isn't enough, and where harness engineering comes in
– The three stages of a feedback loop: analyze a data stream, find the problem, request the fix
– Inner, middle and outer loops, from verifiers on every PR to self-healing in production
– How Tessl's "comment diet" loop catches drift that no single PR causes
– Operators and stewards: the human roles in a software factory
