## Description

Building your own coding agent is rarely worth it, but orchestrating many of them is harder than it looks. George Fahmy, Member of Technical Staff at Vercel, shares why models and harnesses are converging, why workflows like code review, evals and security scanning benefit from mixing harnesses, and what he learned from three failed attempts to abstract them. He then shows Harness SDK, a minimal Python abstraction for harnesses and workspaces, with a live demo of handing a Claude Code session off to a remote sandbox. Recorded at AI DevCon New York 2026.

What we cover:
– Why you shouldn't build your own coding agent
– Models and harnesses are becoming more tightly coupled
– Why mixing harnesses gets better results, from code review to deepsec
– ACP and the hard parts: releases, approvals, process models and workspaces
– Three failed attempts, and a minimal harness and workspace abstraction
– Live demo: moving a Claude Code session to a remote sandbox
