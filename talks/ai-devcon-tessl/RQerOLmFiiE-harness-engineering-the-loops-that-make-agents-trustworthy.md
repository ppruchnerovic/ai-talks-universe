## Description

At its most basic, a software factory is ticket to PR. Dru Knox, Head of Product & Design at Tessl, walks through what it takes to run one well: the metrics that tell you when it's breaking, why cost per PR is a useful health signal, and the first five problems almost every team hits, from agent IT and code quality to repetition and test quality. The fix each time is to improve the process, not the code. Recorded at AI DevCon New York 2026.

What we cover:
– What a software factory is: ticket to PR
– Why engineering still matters in a factory
– The metrics to watch, including cost per PR
– The first five problems, starting with agent IT
– Shifting repeated PR comments left, and making test quality visible
– Scaling up to orchestrate larger amounts of work
