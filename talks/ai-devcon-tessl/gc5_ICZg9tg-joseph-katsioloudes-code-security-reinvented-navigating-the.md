## Description

With only 1 security specialist for every 100 developers, AI offers a transformative promise: embedding security expertise into everyday workflows. But while it scales expertise, AI's limitations and hallucinations present unique challenges, especially in creating truly secure software. Can it close the gap or will it widen it?

Joseph Katsioloudes, a senior developer advocate at GitHub, brings his extensive experience to the stage, presenting insights from the GitHub Security Lab. With a history of securing open source software and fixing over a thousand vulnerabilities, Joseph breaks down how AI can be integrated responsibly into security processes. His talk underscores the potential of AI in minimizing the security gap without replacing the human element, emphasizing a human-in-the-loop approach to secure development.

What we cover:
• Using AI to write safer code and understanding when not to
• How to benefit from MCP servers and agentic workflows for security
• Methods to expedite the remediation of security alerts
• Why nondeterminism and hallucinations in AI matter in cybersecurity
• How does the GitHub Security Lab improve open source security?
