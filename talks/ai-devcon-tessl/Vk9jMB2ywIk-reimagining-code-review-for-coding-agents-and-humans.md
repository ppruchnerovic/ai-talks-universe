## Description

Code review breaks down when a coding agent hands you a 7,000-line PR with none of the intent behind it. Entire's answer is per-commit agent evals, deterministic gates and memories that travel with the code. Joseph Katsioloudes and Peyton Montei of Entire demo Trails and show how reviewers can arrive knowing what was intended, decided and verified. Recorded at AI DevCon New York 2026.

What we cover:
– Why code review doesn't scale with coding agents, in numbers
– Coding agents are capable but forgetful: intent, decisions and verification
– Trails: agent sessions and evals on every commit
– Building custom review agents, from intent match to UI quality control
– Gates: adding deterministic checks to agent code review
– Repo memories so agents don't forget past decisions
