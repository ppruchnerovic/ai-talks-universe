## Description

A system that uses itself to build itself sounds like a paradox. Yet in summer 2026, a platform running entirely on local machines achieves it, blending Claude Code, Codex, and Qwen Code with local models. This approach not only provides a first-class background agent experience but also opens up new avenues for agent-human collaboration in non-engineering tasks. The next strategic move? Crafting a self-improving company.

Luke Marsden, the CEO of Helix ML, leads this innovative journey. With a background in Kubernetes and DevOps, Luke brings valuable insights into building systems that enhance agent autonomy and collaboration. His push toward running multiple agents on dedicated desktops stems from his extensive experimentation and experience in the field.

What we cover:
• The transition to centralized agent infrastructures
• Why each agent should have its own desktop
• How fast agent execution impacts workflow efficiency
• Could spec-driven development be the solution to agent inefficiency?
• Leveraging GPU technology for agent desktops
