## Description

Harness engineering is the new name for everything around the model: tools, context, guardrails, telemetry. Carly Richmond, Senior Manager of Developer Advocacy at Elastic, shows what's genuinely new about building agents, and why most of the harness still rests on software engineering fundamentals you already know.

What we cover:
– What harness engineering is, and how it builds on prompt, context and loop engineering
– What's genuinely new: non-determinism, tool calling and models that change under your feet
– Why TDD evolves into AI agent evals, and when LLM-as-a-judge is the wrong tool
– Writing tool descriptions for agents the way you'd write an OpenAPI spec
– Telemetry, guardrails and security for an agent harness
