## Description

Agentic coding has outgrown the text box. Maggie Appleton, staff research engineer at GitHub Next, argues that walls of CLI output and AGENTS.md files serve coding agents far better than the humans steering them. She walks through Chopin, the GitHub Next prototype where background agents turn a team's planning chat into a structured plan, and makes the case for agents that prompt you instead of waiting to be prompted.

What we cover:
– Why text-heavy agentic coding tools favor agents over humans
– Boundary objects: what AGENTS.md, skill files and MCP servers get right and wrong
– Multiplayer planning with coding agents in GitHub Next's Chopin
– Human-to-agent handoffs, formal verification and spec-driven development
– Why software quality is rising, not falling, with coding agents
– Which roles still matter: PMs, designers and engineers
