## Description

At System Initiative, the code isn't written by humans. It sounds wrong, but it's intentional. Every line for our project, swamp, is generated by a large language model operating under strict human-crafted design guidelines. Vague instructions lead to vague code, but sharp constraints produce code that works. This is not just a theory but our core approach in action.

Paul Stack leads this transformative approach at System Initiative. In his talk at AI Native DevCon 2026, he delves into how they've successfully shifted the coding process. By focusing on rigorous design practices, Paul highlights the discipline required to maintain a trustworthy supply chain and showcases what has been learned in the process of building swamp, an AI-native automation CLI.

What we cover:
• Running an engineering team where AI generates all code
• The role of strict design guidelines in successful AI coding
• The discipline required to maintain a trustworthy code supply chain
• Insights from building swamp, an AI-native CLI for operations teams
• How does AI code generation change traditional pull request processes?
