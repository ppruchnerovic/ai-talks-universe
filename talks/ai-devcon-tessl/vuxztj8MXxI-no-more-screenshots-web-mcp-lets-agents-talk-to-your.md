## Description

An agent cannot read your website. And that needs to change. Current solutions involve costly and inefficient techniques like taking and analyzing screenshots. But there's a new way forward: Web MCP. This experimental API gives agents direct access to web services, bypassing the traditional methods that fall short in dynamic environments. It's not a replacement for the web but a transformation of how agents interact with it. No more reverse engineering. Just straight-to-the-point interactions that save time and resources. Web MCP changes everything.

Maximiliano Firtman, a 30-year veteran in web development and author of 14 books, joins Guy Podjarny to discuss this revolutionary approach. Firtman's experience spans from the early days of web development to the cutting-edge AI-integrated web landscape. His insights shed light on the inefficiencies of current practices and how Web MCP proposes to solve them. Together, they unravel why our current methods are outdated and how a new API can change the very fabric of web browsing for agents.

What we cover:
• Why AI agents taking screenshots of websites is inefficient and costly
• What is Web MCP and how does it offer direct API access to agents
• How a 200MB Apple model running offline opens new web app possibilities
• Why every vibe coded app is essentially a web app and its future implications
• How does exposing JavaScript to agents streamline interactions
