## Description

Drop an agent into an unknown library and it won’t hesitate to make things up.

Maria Gorinova, Member of Technical Staff at Tessl, joins Simon Maple to unpack how evals measure the boundary between knowledge and guesswork when agents interact with unfamiliar libraries.

On the docket:
- why deterministic expectations break down with LLMs
- the fragility of agent reasoning when documentation isn’t explicit
- how to design reliability bars for production-grade agent systems
