## Description

Verification is the new development. As AI agents increasingly handle coding, the challenge shifts from writing code to ensuring it aligns with design and requirements. This shift redefines the bottleneck, placing verification at the forefront of AI-native development. It sounds surprising, but verification dictates future coding practices. Verification is the frontier.

Shachar Azriel introduces a spec-driven verification architecture tailored for AI-native development, leveraging insights from real-world implementations. He emphasizes the transformation of specifications into consumable, verifiable context for machines. By presenting solutions for common failures in AI-generated code, Shachar offers a roadmap for scalability and precision.

What we cover:
• How to retrieve and structure specifications from ticketing systems like Jira for machine readability
• Design verification using Figma MCP integrations to check constraints on spacing and layout
• Why does design token drift matter?
• Securing agent output with isolated sandboxes using AWS Agent Core
• Lessons from scaling verification in real-world scenarios
• Handling vague specifications
