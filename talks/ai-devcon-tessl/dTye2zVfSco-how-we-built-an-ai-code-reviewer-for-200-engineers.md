## Description

One developer. One bot. A pull request merged to production with zero human reviewers.
That's not a hypothetical — it's a real merge.

Serhii spent a year building an AI-powered code review system on top of open-source PR-Agent. In this talk he walks through the six decisions that made it work at scale across 200 engineers.

What we cover:
– Why they chose open-source PR-Agent over CodeRabbit and Greptile
– The two-stage context retrieval system that made prompts actually useful
– How they used Gemini Flash to filter 5,000-token documents down to 40 relevant sections
– Why feedback loops from day one caught a silent Gemini model degradation
– The "self review done" command that lets bots approve PRs autonomously
– A practical playbook you can run in your own company next week
