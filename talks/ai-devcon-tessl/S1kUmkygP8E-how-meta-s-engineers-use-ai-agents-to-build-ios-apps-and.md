## Description

Meta iOS engineer Vivian Qu breaks down how AI agents are being used to build iOS apps — and why mobile development presents unique challenges that web developers often don't anticipate.

In this talk from Tessl, Vivian covers the key reasons mobile AI development lags behind web (closed ecosystems, slow verification loops, platform fragmentation), what the latest benchmarks actually reveal about model performance on mobile tasks, and the practical patterns and tools Meta uses to make agents more effective.
You'll also get a walkthrough of her open-source SwiftUI Agent Toolkit, including two custom tools she built specifically for this talk.

Whether you're an indie developer just getting started or an engineer at scale, this is one of the most grounded, practical perspectives on AI-assisted mobile development available right now.
