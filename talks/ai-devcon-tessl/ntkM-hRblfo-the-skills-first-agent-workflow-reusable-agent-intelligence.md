## Description

One skill transformed coding success from 28% to 71%, while another skill decreased performance. Anecdotal evidence is no longer sufficient. Understanding which agent skills truly enhance performance is essential. Explore why some popular skills might actually harm your agents and how to evaluate their effectiveness. Get the details on Tessl's innovations in skills evaluation and lifecycle management. It's crucial knowledge for leveraging reusable agent intelligence effectively. Simon Maple and Guy Podjarny delve into the developments and challenges of agent skills. Simon Maple is your co-host, while Guy Podjarny, as the CEO and founder of Tessl, brings deep insights into the skill dynamics. Together they share revelations from testing over 1000 agent skills, discussing the role and impact of evaluations, as well as the revolutionary approach of the Tessl Skills Registry.

What we cover:
• Which skills increase agent performance and which cause a decline
• How the Tessl Skills Registry introduces lifecycle management to skills
• Why some popular agent skills actually decrease performance
• What is the role of package managers in skill implementation
