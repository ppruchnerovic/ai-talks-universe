## Description

Skills and MCP servers are the new npm, and AI coding agents are pulling them into enterprise codebases faster than security can keep up. Manoj Nair, Chief Innovation Officer at Snyk, joins Guy Podjarny at the Snyk AI Security Summit to map where enterprise agentic coding really stands.

They get into why a 50,000-agent Claude Code rollout was pulled forward by weeks, why the autonomous attacker has some CISOs ready to accept an outage to patch faster, and how security is moving into the agent loop of the software factory.

What we cover:
– Why leadership and culture, not tooling, decide how fast enterprises adopt AI coding agents
– The three risks of agentic coding: insecure output, the skills and MCP server supply chain, and agent behavior
– Running coding agents locked down: sandboxes, agent identities and no open internet
– Who owns the code an agent writes, and why AI-native organizations treat it as shared risk
– Securing the software factory: security context in the agent loop and agentic remediation of the backlog
– What still has to be solved before enterprises trust agents: identity, intent and behavior
