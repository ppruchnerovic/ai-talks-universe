## Description

Slice 'em. Dice 'em. Put 'em in an omelet.

Wait, we weren't talking about tomatoes? Well, you can also do a lot of strange things to agents to stretch your token budget, juice agent performance, and get your agents to run longer and more independently. In this talk, we'll learn how to:
- Tee up agents with agents … agentically!
- Fork, roll back … even "shadow clone" your agents!
- Have agents edit their own memory … and have them forget they did it!
- Hot swap frontier model providers … in mid-conversation!
- Make an agent out of your own interactions with agents … using an agent!
- Put your agents in a little organization and force them to use Slack … BECAUSE AGENTS!

Plus other forbidden techniques!  :scroll::test_tube:

In this talk, Patrick will show examples of getting real work done with the above techniques. We'll hear Patrick's hot takes about agent special-casing (not subagents, just agents) and how you should keep the smarts in the model, not in the heuristics. We'll internalize the deep truth that agents are just, like, stateless context, man, and how knowing that can take your agentic workflows to the next level. We might even cook some agents into an omelet!  🍅✨
