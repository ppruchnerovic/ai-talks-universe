## Description

Your coding agent should never hold a credential, and in a software factory that rule is only the start. Recorded live at the AI Security Summit in San Francisco, Simon Maple sits down with Eli Aleyner (Docker), Marcelo Sousa (Snyk) and Ian Livingstone (Keycard), co-authors of Agent Baseline, a security reference architecture for the AI software factory.

The panel unpacks why agents have to be treated as fundamentally unpredictable actors, why sandboxing alone is not enough when skills and MCP servers make the supply chain dynamic, and why approval prompts collapse into fatigue. Marcelo's verdict: sometimes these are kids with chainsaws.

What we cover:
– The three levels of autonomy, from coding agents to fully agent-directed workflows
– Sandboxing coding agents and injecting secrets at the egress point
– Why the agent supply chain is dynamic: skills, MCP servers and cloned repos
– Prompt injection, least privilege and agents monitoring other agents in the harness
– Approval fatigue: YOLO mode vs CYA mode
– Where to start securing your software factory on Monday morning
