## Description

Join us to take a hands-on journey using the tools we've built to scale our security team using large language models. We've streamlined our software development lifecycle and access management, and developed new ways to handle bug bounty reports and detect attackers through log analysis. This talk will be practical and to the point. We're excited to be open-sourcing most of these tools! You'll gain insights into how to use these models to not only automate tasks but also provide deeper understanding and decision support in complex security environments. Explore new ways to enhance your security workflows and scale your security attention!
