## Description

In this presentation from Summit 2025, Nicole Edwards, a Data Architecture Manager for the City of Tacoma, shares details about a Streamlit app that she developed that allows non-technical users to generate the code needed to create other Streamlit apps. The app even allows users  to choose if they want to create a table edit or a form collection app. With a table edit app, users have the ability to select the source table, columns to filter on, and whether to disable editing. With a form collection app, they define the form fields. The Streamlit generator app provides SQL to create the target tables, if needed, as well as the Python to create the new Streamlit app.
