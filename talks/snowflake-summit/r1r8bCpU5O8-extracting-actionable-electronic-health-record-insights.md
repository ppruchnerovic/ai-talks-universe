## Description

In this session recorded at Summit 2025, Corewell Health presents a flexible data processing and display framework it developed that makes it possible to extract any intelligent insight desired from the organization's EHR using AI. The backend features a recomposable pipeline builder, allowing users to select patient populations, attach additional records, filter out irrelevant patients, and most importantly, achieve intelligent processing with AI. This system works in harmony with the front end, providing quick access to trustworthy, traceable, AI-generated insights.
