## Description

Working within open storage with Iceberg Tables, Doris Lee shows you an end-to-end feature engineering pipeline using features that streamline development with pandas on Snowflake, Dynamic Tables, and Cortex LLM Functions.

In this demo, Doris shows you how to:
-- Connect to open storage: Connect Apache Iceberg Table with pandas on Snowflake
-- Profile and clean data: Exploratory analysis to profile data characteristics
-- Feature engineering: Perform feature engineering tasks with pandas on Snowflake and Cortex LLM
-- Build a pipeline: Save as Dynamic Iceberg Table
-- Automatic pipeline refresh: Automatic pipeline refresh when source data updates
