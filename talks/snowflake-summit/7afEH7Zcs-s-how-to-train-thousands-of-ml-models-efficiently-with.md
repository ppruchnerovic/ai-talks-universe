## Description

Many-model training is a common use case across industries where there is a need to build hyper-personalized models based on geography or customer. This type of training can be challenging to orchestrate and scale while maximizing resource utilization or trying to stay within budget. In this talk recorded at Summit 2025, the presenters demonstrate how to leverage Snowflake ML’s distributed training capabilities to achieve the best price performance for many-model training from Container Runtime for Snowflake Notebooks. Learn how customer Les Schwab uses Snowflake ML to train and generate inferences on a large-series time series neural network to forecast a promotion’s success.
