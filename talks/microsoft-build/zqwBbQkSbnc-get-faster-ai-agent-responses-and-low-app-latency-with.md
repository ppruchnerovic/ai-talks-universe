## Description

Low latency and fast response times are key to the performance of AI agents. In this session, we'll dive into how Azure Managed Redis can dramatically improve the performance of your AI applications, including those built on Azure SQL. Learn how to pick the right configurations to boost performance and how to use the latest .NET abstractions to easily add caching layers.
