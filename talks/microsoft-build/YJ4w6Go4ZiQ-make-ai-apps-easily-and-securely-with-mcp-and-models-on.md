## Description

This is one of many innovative Featured Partner sessions from Microsoft Build 2025.  View more information from this partner at https://aka.ms/MSBuild25_Docker

Building AI apps is messy — fragmented tools, complex configs, and security hurdles slow you down. In this session, we’ll introduce Docker’s Model Runner, MCP Catalog, and Toolkit, built to help you move faster with tools you already know. Learn how Model Runner delivers fast, GPU-accelerated inference on your local machine. We’ll also show how the MCP Catalog simplifies MCP tools discovery and how the MCP Toolkit handles config, auth, and security, so you can stay focused on building.
