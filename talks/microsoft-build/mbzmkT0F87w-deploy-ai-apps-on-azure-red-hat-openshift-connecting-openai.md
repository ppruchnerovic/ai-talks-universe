## Description

Learn how to deploy AI applications on Azure Red Hat OpenShift by connecting Azure OpenAI services. This demo walks through setting up Azure OpenAI, configuring ARO environments, and establishing the connections to create functional AI applications. See how to navigate the Azure AI Foundry portal, explore available models, and deploy a working example.
