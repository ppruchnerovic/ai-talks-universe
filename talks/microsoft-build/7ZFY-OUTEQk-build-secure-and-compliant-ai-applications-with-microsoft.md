## Description

Microsoft is releasing Microsoft Purview SDK, a set of REST APIs, documentation, and code samples that enable developers to integrate their AI apps with Microsoft Purview. These APIs allow security admins to apply enterprise-grade data security and compliance controls to secure and govern AI application usage.
