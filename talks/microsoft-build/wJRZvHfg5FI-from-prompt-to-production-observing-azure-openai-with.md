## Description

This is one of many innovative Featured Partner sessions from Microsoft Build 2025.  View more information from this partner at https://aka.ms/Build25_Elastic

Learn how to monitor and troubleshoot LLM-powered apps on Azure using Elasticsearch and Elastic Observability. We’ll cover how to ingest and analyze prompts, completions, latencies, token counts, and errors via SDKs or OpenTelemetry. See how Elastic’s search, correlation, and ML tools detect drift, surface anomalies, and trace interactions—giving you full-stack GenAI visibility to optimize cost, speed, and reliability.
