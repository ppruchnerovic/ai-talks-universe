## Description

This is one of many innovative Featured Partner sessions from Microsoft Build 2025.  View more information from this partner at https://aka.ms/Build25_Confluent

Building a great VS Code extension brings a product closer to where developers are. In this session, we’ll share how we brought Apache Kafka and Flink into VS Code with the Confluent for VS Code extension, as well as copilot support. Hear lessons learned, design insights, and how we’re making real-time data development feel native inside VS Code.
