## Description

In this session, you will get a deep dive into how SQL Server 2025 brings new features to redefine the database developer experience. This includes vector search with AI models, a new JSON type and index, RegEx and other T-SQL enhancements, Change Event Streaming (CES), and built-in REST API support. Developers can deploy databases on Windows, Linux, containers, k8s, or Azure SQL VM. Copilot assistance is available through SSMS and GitHub. Come see the new path forward for developers using SQL.
