## Description

The SRE Agent is now in public preview! Learn how to use natural language to describe intent, which is then translated by the AI agent into a series of tasks that the agent can execute with developer approval. It iterates through target applications and carries out the requested task(s), all without the need for developers to remember myriad CLI commands and syntaxes.
