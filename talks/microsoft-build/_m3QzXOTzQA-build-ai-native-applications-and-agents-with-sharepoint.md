## Description

SharePoint Embedded (SPE), an API-only SharePoint platform, powers AI-native apps like Loop and Copilot Pages. SPE offers full AI stack, including a semantic index, vector db, RAG, LLM and orchestration for your business apps and agents. SPE also enables collaboration, Microsoft 365 Security, and Compliance for apps and agents. Join this session to discover how Microsoft and leading enterprises and ISVs are building AI native applications using SPE.
