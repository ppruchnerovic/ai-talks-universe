## Description

Join this session for a live demo of Signvrse, an AI-powered platform breaking communication barriers for the Deaf community. Using Azure AI Speech, it translates spoken language into text and 3D avatar-driven sign language in real time, making communication more accessible anywhere. As a finalist in the Imagine Cup—the premier global A startup competition for student founders—Signvrse is redefining inclusive technology through innovative uses of AI.
