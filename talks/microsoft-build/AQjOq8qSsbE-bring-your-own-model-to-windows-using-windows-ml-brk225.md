## Description

Join us to learn about the all-new Windows ML, the definitive performance-oriented AI inferencing framework built into Windows! Windows ML empowers you to bring your own model, or pick from our growing Foundry catalog, and helps you optimize your AI workload across CPU/GPU/NPU, all while streamlining model & runtime dependency management. Come see it in action!
