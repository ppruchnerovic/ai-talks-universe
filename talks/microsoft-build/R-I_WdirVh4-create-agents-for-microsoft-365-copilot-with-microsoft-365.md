## Description

Learn about the latest features you can use to build advanced agents using your custom orchestrator and foundation models leveraging the Microsoft 365 Agents SDK that allows developers to choose their AI models, orchestration and knowledge to deploy agents to a number of different channels. In this session, we will cover the two ways to build custom engine agents, when to use them, different multi-agent patterns and how to get started.
