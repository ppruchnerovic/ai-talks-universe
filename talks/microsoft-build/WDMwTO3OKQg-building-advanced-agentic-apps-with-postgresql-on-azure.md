## Description

What benefits do agentic architectures bring compared to traditional RAG patterns? In this session we explore advanced agentic capabilities offered by popular GenAI frameworks (LangChain, LlamaIndex, Semantic Kernel) on top of Azure Database for PostgreSQL. Learn how to improve agentic apps by making vector search faster with DiskANN, and more accurate with Semantic Ranking, GraphRAG, and new powerful Semantic Operators. We also introduce new highly productive PostgreSQL extension for VSCode.
