## Description

In this session, you will learn how to build AI Agents for external-facing apps using the OpenAI SDK with Assistants and Function Calling for APIs secured by Microsoft Entra External ID ensuring adherence to Zero Trust principles. We will cover the essential steps to use OpenAI SDK in an external-facing app and demonstrate how to leverage Microsoft Entra External ID for secure authentication and authorization.
