## Description

In this session, dive deep into building intelligent, agent-based AI solutions using Azure Logic Apps. Learn how to create agents that autonomously interact with your data, processes, and external systems using large language models (LLMs) to drive dynamic orchestration across multiple AI services and workflows.Experience new developer capabilities in VS Code that simplify integrating AI tools, managing workflows, and adding human oversight where needed. Through hands-on demonstrations and real-world use cases, you'll discover how to develop, monitor, and scale AI agents to automate intelligent workflows, enabling smarter, more efficient application development.
