## Description

Live Preview, Hot Reload, and other UI tools are now available at design time, allowing real-time visualization of changes in your .NET MAUI apps in Visual Studio. The flexibility to use these tools when detached from the debugger allows for uninterrupted experimentation and refinement of your designs so you can deliver high-quality applications faster and with greater confidence. Swing by and see the tools in action!
