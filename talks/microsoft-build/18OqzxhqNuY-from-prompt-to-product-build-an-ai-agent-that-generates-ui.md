## Description

This is one of many innovative Featured Partner sessions from Microsoft Build 2025.  View more information from this partner at https://aka.ms/Build25_Syncfusion

Learn how to build and deploy an agent-based solution using AutoGen that turns natural language input into functional HTML and JavaScript.
