## Description

Join us to explore the Fabric Workload Development Kit (WDK) to build, integrate, and publish custom workloads within Microsoft Fabric where we will showcase platform’s flexibility, scalability, and AI-driven capabilities. Learn how to leverage Fabric’s open platform, interfaces and APIs to create seamless, innovative solutions—and extend your application’s reach across the Fabric ecosystem.
