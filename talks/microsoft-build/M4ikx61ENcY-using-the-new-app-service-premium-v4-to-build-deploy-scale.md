## Description

Join us to learn what's new in Azure App Service Premium v4. Learn how to run a local SLM in a sidecar container with extensions like Redis and DataDog. Discover how to invoke an OpenAPI App Service web app from Azure AI Agent Service. Explore the latest Availability Zone support and integrate App Service best practices into your Azure ARM/Bicep templates using GitHub Copilot. This session will enhance your cloud application deployment and management skills.
