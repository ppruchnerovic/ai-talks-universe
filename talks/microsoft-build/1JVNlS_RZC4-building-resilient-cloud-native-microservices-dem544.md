## Description

Learn how to build resilient cloud-native microservices using Dapr and modern Azure hosting solutions like AKS and ACA. This session will demonstrate strategies for managing distributed transactions using the Saga pattern and ensuring data consistency through eventual consistency. It will focus on practical demos and actionable insights for building robust cloud-native systems.
