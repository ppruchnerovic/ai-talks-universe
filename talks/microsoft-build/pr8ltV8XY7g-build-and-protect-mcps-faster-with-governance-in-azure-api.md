## Description

With the increasing adoption of MCPs, the need for robust management of remote MCPs is intensifying. By treating MCP server endpoints as other backend APIs, organizations can apply familiar governance, security, and operational controls with Azure API Management. Join us as we walk through a practical example of hosting and protecting a remote MCP server behind Azure API Management.
