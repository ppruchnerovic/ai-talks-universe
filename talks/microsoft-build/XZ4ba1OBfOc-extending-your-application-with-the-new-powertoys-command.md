## Description

With the new extensibility model for PowerToys Command Palette, the next generation of PowerToys Run, you can quickly add your own spin to this new launcher.  We’ll show you step-by-step how to leverage the Command Palette SDK to extend your application as an entry point into the palette.  We’ll discuss best practices while we build one live, show how to deal with latency, extending rich UIs, sending input back and forth, as well as adding changes back into the Command Palette.
