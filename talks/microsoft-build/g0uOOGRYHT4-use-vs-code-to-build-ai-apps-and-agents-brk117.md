## Description

Developing AI models and intelligent applications shouldn’t mean jumping between tools. In this session, learn how to explore different models, iterate on prompts, run evaluations, and build and deploy agents—all within VS Code—using the AI Toolkit, Azure AI Foundry, the Azure SDK, and Model Context Protocol (MCP). Streamline your workflow and bring AI-powered solutions to life faster.
