## Description

You're a Java developer, but every AI example you find is in Python. It's time to build AI solutions in the language you know and love. In this talk, Loiane Groner reveals how Spring AI makes integrating AI into your Java applications a seamless process.

She explains how Spring AI leverages the power of the Spring framework you already trust, allowing you to easily build modern AI solutions with familiar concepts like clean architecture, observability, and even testing. She demonstrates practical use cases, from implementing a simple chat function to building sophisticated AI agents with function calling and RAG (Retrieval-Augmented Generation).

Stop feeling like you have to learn Python to keep up. Learn how to build production-ready AI applications in Java with Spring AI.
