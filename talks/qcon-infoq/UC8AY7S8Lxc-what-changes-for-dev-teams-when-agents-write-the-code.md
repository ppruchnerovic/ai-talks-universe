## Description

AI agents can now write, test and ship code faster than most teams can decide what to build. Hannah Foxwell argues the hard part is not the agents but the team around them.

Hannah Foxwell has spent more than a decade in platform engineering building high-performing engineering organizations. She recently built and shipped a base image management platform with one other person in two weeks, using agentic tools. She now works as an independent consultant on platform engineering, security and agentic AI.

Recorded at QCon London 2026. QCon conferences are practitioner-driven events where senior engineers share real production experience. The original talk title is “The Reinvention of the Dev Team.”
