## Description

75% of executives know AI is critical, but few understand how to run it reliably in production. LLM-powered applications are non-uniform, expensive, and behave differently than traditional microservices. This #InfoQ talk, by Sally O’Malley, gives senior software developers, architects, and engineering leaders the exact open-source observability stack they need to run business-critical AI workloads with full transparency.

Dive into a live demo where we build an end-to-end monitoring solution using vLLM, Llama Stack, Prometheus, Tempo, and Grafana on Kubernetes. Learn what unique signals (cost, performance, quality) you must track for RAG, agentic, and multi-turn applications.
