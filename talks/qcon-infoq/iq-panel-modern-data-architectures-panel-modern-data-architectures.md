# Panel: Modern Data Architectures

**Fabiane Nardon, Matthias Niehoff, Adi Polak, Sarah Usher**

`QCon / InfoQ Dev Summit` · `QCon London 2025` · `2025` · `53 min`

[Watch the recording](https://www.infoq.com/presentations/panel-modern-data-architectures/) · [Conference site](https://qconferences.com/)

## Description

The panelists emphasize that data engineering is no longer just about "click-and-drag" UI tools; it is software engineering applied to data.

Fabiane Nardon is Data Expert, Java Champion & Data Platform Director @totvs. Matthias Niehoff is Head of Data and Data Architecture @codecentric AG. Adi Polak is Director, Advocacy and Developer Experience Engineering @Confluent, Author of "Scaling Machine Learning with Spark" and "High Performance Spark 2nd Edition". Sarah Usher is Data & Backend Engineer, Community Director, Mentor.
