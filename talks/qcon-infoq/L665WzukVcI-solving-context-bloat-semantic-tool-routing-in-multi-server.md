## Description

One MCP server. Five times the tokens. Two more servers? 3,500 tokens for a 20-token prompt.

This talk shows how a gateway-based semantic routing layer solves context bloat by delivering only relevant tools at runtime - cutting cost, reducing hallucinations, and bringing battle-tested microservices patterns to the agentic era.
