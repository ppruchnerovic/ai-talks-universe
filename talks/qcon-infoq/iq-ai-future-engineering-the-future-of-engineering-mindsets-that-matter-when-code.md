# The Future of Engineering: Mindsets That Matter When Code Isn’t Enough

**Ben Greene**

`QCon / InfoQ Dev Summit` · `QCon San Francisco 2025` · `2025` · `45 min`

[Watch the recording](https://www.infoq.com/presentations/ai-future-engineering/) · [Conference site](https://qconferences.com/)

## Description

Ben Greene discusses how software engineers can adapt and thrive in an era of rapid AI code automation. Drawing on his startup experience, he explains key mindsets like starting simple, maintaining code comprehension, attacking hard problems first, and focusing on customer impact. He shares why human empathy, agency, and practical problem-solving remain irreplaceable when code is automated.

Ben Greene is Co-Founder and CTO of Tessi, a mission-driven startup that is using AI and automation to make home restoration after disasters faster, easier and safer. He is also the co-creator of FreeFormula.Exchange. He is a 4x founding CTO, including: Outcomes4Me, Windshield, and NextLot.
