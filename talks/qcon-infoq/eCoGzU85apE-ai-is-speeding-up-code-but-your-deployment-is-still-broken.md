## Description

AI can generate code in seconds, but if your deployment still takes months, you don’t have a productivity tool - you have a bottleneck.

In thisInfoQ video, Dr. Nicole Forsgren (author of Accelerate and DORA co-founder) reveals why the AI revolution is exposing deep-seated friction in the software delivery lifecycle. While "vibe coding" speeds up the inner loop, it is putting unprecedented pressure on code reviews, build pipelines, and security gates.

Dr. Forsgren shares a data-driven framework for identifying the "toil" that costs the industry trillions in technical debt and provides a 7-step roadmap for engineering leaders to reclaim developer flow state.
