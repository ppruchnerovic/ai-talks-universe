# Platform Engineering Patterns for Scalable Software Delivery

**Cat Morris, Martin Reynolds, Mike Fiedler, Boyan Dimitrov, Renato Losio**

`QCon / InfoQ Dev Summit` · `InfoQ Live - August 2025` · `2025` · `62 min`

## Description

Building a successful Internal Developer Platform (IDP) requires balancing standardization with developer autonomy. The panelists discuss the core components of modern platforms, the role of platform teams, and strategies for driving adoption across diverse teams. They also share key patterns, anti-patterns, and lessons learned.

Cat Morris is the Product Manager @Syntasso. Martin Reynolds is Field CTO @Harness. Mike Fiedler is Code Gardener. Boyan Dimitrov is CTO @Sixt Boyan Dimitrov is Chief Technology Officer (CTO) of SIXT. Renato Losio is InfoQ Editor.
