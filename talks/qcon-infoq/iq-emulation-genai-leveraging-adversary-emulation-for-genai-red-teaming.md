# Leveraging Adversary Emulation for GenAI Red Teaming

**Kennedy Torkura**

`QCon / InfoQ Dev Summit` · `InfoQ Dev Summit Munich 2025` · `2025` · `36 min`

[Watch the recording](https://www.infoq.com/presentations/emulation-genai/) · [Conference site](https://qconferences.com/)

## Description

Kennedy Torkura discusses practical GenAI red teaming techniques to safeguard LLMs and knowledge bases against security threats like data poisoning and LLMjacking on AWS. He explains how engineering leaders and architects can bridge traditional cloud security with MITRE ATLAS frameworks to proactively identify vulnerabilities, implement guardrails, and secure production AI applications.

Kennedy Torkura is the CTO/Co-Founder at Mitigant, an innovative cloud security startup based in Germany. Kennedy has spent over 12 years in cybersecurity and passionately explores the intersection of security chaos engineering, cyber resilience, incident response, and risk analysis for cloud security. Kennedy has published over 20 academic papers about cloud security.
