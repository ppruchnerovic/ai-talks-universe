## Description

Marketing messages are one-way. Klaviyo's Customer Agent changes that - turning outreach into real-time, bi-directional commerce conversations across web, SMS, and email.

This talk shares the engineering lessons behind building it at scale: multi-tenant RAG pipelines, orchestrator simplification, circuit-breaker gateways, and why manual error analysis beats aggregate metrics every single time.
