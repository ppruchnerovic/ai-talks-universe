# The Architecture of Developer Experience: Where Product, Platform, and Operations Meet

**Ran Isenberg, Garima Bajpai, Stephane DiCesare, Martin Reynolds, Renato Losio**

`QCon / InfoQ Dev Summit` · `InfoQ Live - November 2025` · `2025` · `44 min`

[Watch the recording](https://www.infoq.com/presentations/developer-experience-load-autonomy/) · [Conference site](https://qconferences.com/)

## Description

The panelists discuss designing platform architecture where product, platform, and operations meet. Experts share best practices for reducing cognitive load, balancing core ops vs. innovation, measuring success (lead time, cost avoidance), and enabling developers through self-service and golden path deviations.

Ran Isenberg is AWS Serverless Hero, a Principal Software Architect at CyberArk. Garima Bajpai is Founder of DevOps Community of Practice, Canada. Stephane DiCesare is Senior Platform Engineer, Platform Experience @DKB. Martin Reynolds is Field CTO @Harness. Renato Losio is Moderator, Cloud Expert, AWS Data Hero and InfoQ editor.
