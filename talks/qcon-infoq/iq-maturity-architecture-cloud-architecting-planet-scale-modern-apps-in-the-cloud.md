# Architecting Planet Scale, Modern Apps in the Cloud

**George Mao**

`QCon / InfoQ Dev Summit` · `InfoQ Dev Summit Boston 2025` · `2025` · `47 min`

[Watch the recording](https://www.infoq.com/presentations/maturity-architecture-cloud/) · [Conference site](https://qconferences.com/)

## Description

George Mao shares a deep dive into evolving a basic web application to a planet-scale, global architecture. He walks through five stages of maturity, focusing on adding enterprise-grade security, achieving global high availability and disaster recovery, optimizing content delivery costs with CDNs, and implementing globally consistent persistence using serverless technologies.

George Mao currently serves as the Head of Specialists Architects at Google Cloud. He is responsible for helping customers build and modernize large scale applications using cloud native technologies, such as AI, Serverless, and Analytics. Before joining Google, George was the Tech leader for AWS Serverless and a Distinguished Engineer at Capital One.
