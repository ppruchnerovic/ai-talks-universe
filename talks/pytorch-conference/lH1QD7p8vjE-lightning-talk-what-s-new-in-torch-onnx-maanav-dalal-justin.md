## Description

Lightning Talk: What's New in Torch.onnx - Maanav Dalal & Justin Chu, Microsoft

In this talk, you will learn about the `dynamo=True` option in the torch.onnx exporter which leverages torch.export and ExportedProgram to produce performant, accurate and context rich ONNX models.

You will also understand:

1. How to use torch.onnx.verification tools to diagnose model accuracy issues,
2. How to use torch.onnx.ops to instruct the exporter to produce custom and ONNX operators for complex export scenarios
3. Support for the Attention operator with ONNX opset 23
4. How you can customize and extend the exporter for your needs.
