## Description

Sponsored Session: Fine Tune Your AI Toolbox with GitHub Copilot, Azure AI Foundry, & MCP - Sarah Kaiser, Microsoft

There is an increasingly wide range of AI tools that developers have access to, it can sometimes be overwhelming to understand how to best leverage them. In this session, you'll see a real-life example showing how these three tools can work together to enhance data workflows. All in VS Code, we'll use Copilot to start our project with Jupyter Notebooks, clean up the data, use MCP servers to provide tools for our Agents, and Azure AI Foundry to build and deploy models. This session is for everyone who is interested in leveraging AI developer tools at all stages of the development process.
