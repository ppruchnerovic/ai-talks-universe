## Description

The CUDA platform is the foundation of the GPU computing ecosystem. Every application and framework that uses the GPU does so through CUDA's libraries, compilers, runtimes and language — which means CUDA is growing as fast as its ecosystem is evolving.

At this engineering-focused talk by one of the architects of CUDA, you'll learn what's new and what's coming next for both CUDA and GPU computing as a whole.
