## Description

Learn how to scale your application across multiple GPUs without writing message-passing code. This GTC 2025 session introduces task-based runtime systems that let you write multi-GPU libraries more easily and scale transparently—no explicit communication or coordination required. Plus, see how to integrate your code with domain libraries in the same program.
