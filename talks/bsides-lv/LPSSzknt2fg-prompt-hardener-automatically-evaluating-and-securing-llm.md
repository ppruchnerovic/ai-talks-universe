## Description

Identifier: BHMKYS
Description:
- “Prompt Hardener – Automatically Evaluating and Securing LLM System Prompts”
- Presents Prompt Hardener, an open-source toolkit for securing LLM prompts.
- Automates evaluation, hardening, and adversarial testing using LLMs.
- Applies techniques like spotlighting, random sequence enclosure, instruction defense, and role consistency.
- Performs injection testing with categorized payloads based on OWASP Top 10 for LLM Applications 2025.
- Includes live demo of CLI and Web UI for strengthening prompts.
