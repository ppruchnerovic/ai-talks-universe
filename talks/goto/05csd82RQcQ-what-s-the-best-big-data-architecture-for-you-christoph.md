ABSTRACT
To implement Big Data use cases like Analytics, Machine Learning or GenAI, having the right data architecture is essential. And data architectures have come a long way from the first data warehouses to modern cloud-based data and compute platforms. In this talk, we will look into the history, present and future of big data architectures.

We will shed light on competing big data architecture patterns like Data Mesh, Data Lakehouse, Data Fabric and Data Vault. What are the differences, what are the main challenges to implement them in an organization? And what will the future of big data architectures look like? [...]
