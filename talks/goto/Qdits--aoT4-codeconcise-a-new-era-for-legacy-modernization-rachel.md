ABSTRACT
So far, most attention to GenAI in software development is on generating code. But there is as much, if not more, value in understanding existing code - particularly long-lived, large, and complex legacy systems.

At Thoughtworks we have been experimenting with using this technology with our clients, embodied in a tool called CodeConcise, which combines an LLM with a knowledge graph derived from the abstract syntax trees of a codebase. We have found this useful both to draw out low-level requirements and to build a high-level explanation of a system.

This talk will show what we have learned and how it could change the age old challenge of wrangling legacy at speed, iteratively and with zero downtime. [...]
