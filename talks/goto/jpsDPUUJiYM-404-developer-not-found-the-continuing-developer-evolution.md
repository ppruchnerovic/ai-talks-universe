ABSTRACT
The developer landscape is undergoing a profound transformation. What began with coding assistants has rapidly evolved into AI agents and autonomous systems that are reshaping how we build software. However, this evolution isn't slowing down—it's accelerating.

In this forward-looking session, we'll examine the current state of the developer ecosystem and how AI is fundamentally changing what it means to be a developer. With the use of real practical demos and examples we will explore :
• The trajectory from coding assistants to AI agents.
• How modern developer workflows are being reimagined
• The shifting balance between human creativity and machine capabilities
• Critical skills developers need to thrive in this new paradigm
• Practical strategies for navigating this rapidly evolving landscape

Whether you're concerned about keeping pace with change or excited about the possibilities ahead, this session is for you. [...]
