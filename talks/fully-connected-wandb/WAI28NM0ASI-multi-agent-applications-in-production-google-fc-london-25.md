## Description

As AI agents move from experimental notebooks to production, the core challenge shifts from building to operating them reliably. In this session from Fully Connected London, Heiko Hotz, Generative AI Global Blackbelt at Google, draws from two real-world customer projects to present a production-centric framework for managing Multi-Agent Systems. Learn best-practice architectural patterns for robust orchestration, practical approaches to analyzing user-agent interactions for actionable metrics, and how to build security guardrails against prompt injections.
