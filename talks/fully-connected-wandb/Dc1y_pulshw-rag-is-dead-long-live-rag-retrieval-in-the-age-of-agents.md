## Description

In 2023, RAG was the solution to everything. By 2024, it had been declared dead multiple times—killed by exploding context windows, agentic frameworks, and code tools using grep. So is RAG actually dead? In this talk from Fully Connected London, Amélie Chatelain, Head of Knowledge & Search at LightOn, traces RAG's evolution from default pipeline to conditional tool that agents call when it makes sense. She explores why more context doesn't fix issues with cost, latency, or accuracy, and why grep fails with visual content. The 2023 mantra "everything can be solved with RAG" is dead—but intelligent retrieval as a tool? Alive, essential, and more interesting than ever.
