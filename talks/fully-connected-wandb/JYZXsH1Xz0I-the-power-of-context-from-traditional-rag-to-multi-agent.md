## Description

Whether you're building a traditional RAG system or designing a multi-agent architecture, one constant remains: context. In this session from Fully Connected London, Rajiv Shah, Chief Angelist at Contextual AI, explores how advances in context engineering—smarter retrieval, filtering, and orchestration—have paved the way for agentic RAG systems that use iterative, multi-step refinement to improve responses. He then looks ahead to the next frontier: multi-agent systems that collaborate using shared contextual knowledge to solve more complex tasks.
