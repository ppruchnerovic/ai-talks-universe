## Description

This talk explores local agentic AI, from full agent harnesses running capable 27-billion-parameter models to micro-agentic systems that accomplish useful work with remarkably little computing power. It covers practical hardware, model compression, inference runtimes, context management, privacy, cost, and what useful autonomous computing can do on modest machines.
