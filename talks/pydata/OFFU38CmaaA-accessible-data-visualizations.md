🎓 Making data visualizations accessible isn't optional anymore—learn how to comply with new EU and US regulations while reaching all users.

Speakers:
Maris Nieuwenhuis

Description:
Data visualizations often exclude users with visual impairments, but new regulations like the European Accessibility Act and American Disabilities Act now mandate inclusive digital content. Maris Nieuwenhuis presents practical solutions for creating accessible visualizations that comply with WCAG standards. The talk covers optimized color palettes with verified contrast ratios, pattern implementations for secondary encoding, and SVG accessibility features. Learn how to use the open-source cusy Design System to implement these techniques in popular libraries like Bokeh and Vega-Altair. The presentation demonstrates how to meet contrast requirements (≥3:1 for visual elements), support users with color vision deficiencies, and provide alternative data formats like semantic HTML tables. Attendees will gain ready-to-use resources including eight distinct colors with CIEDE2000 perceptual differences, unique patterns paired with each color, and implementation examples for immediate use.
