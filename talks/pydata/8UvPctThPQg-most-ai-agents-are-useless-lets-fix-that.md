Description:
AI agents are everywhere in 2025, but most fail in production. Bilge Yücel from deepset reveals why most agentic systems are brittle prototypes and shares practical engineering principles to fix them. Learn how to find the optimal level of autonomy by blending deterministic workflows with agent-based reasoning, avoiding the trap of over-relying on LLMs. Discover the importance of modularity, observability, and guardrails using Haystack, an open-source Python framework. Through real examples like a GitHub issue resolver and travel itinerary planner, see how to build production-ready agents with proper tool management, error handling, and human oversight. Whether you're deploying your first agent or taming an unruly prototype, this talk provides actionable patterns for building reliable AI systems that go beyond flashy demos.
