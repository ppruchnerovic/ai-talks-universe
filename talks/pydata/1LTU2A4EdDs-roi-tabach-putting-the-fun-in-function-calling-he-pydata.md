## Description

We'll cover the basic idea - how we lived before the LLM vendors let us expclicitly pass the signature of the function (we did prompt engineering) ; how it's implemented under the hood (it's prompt engineering all the way down) ; what should someone know when approaching this (use function calling it's the best way to force an LLM to do something, better than threatning to shoot an intern if the LLM fails to provide the required schema) ; if we have time we'll dive shallow into the world of evaluating tool use, which is useful also for evaluating the most hype-y thing of all - Agents and MCP.
