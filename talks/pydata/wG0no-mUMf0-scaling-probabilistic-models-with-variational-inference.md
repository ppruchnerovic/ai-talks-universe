Description:
Dr. Juan Orduz presents a practical guide to scaling probabilistic models using variational inference. Moving beyond heavy mathematics, this talk focuses on real-world implementation using NumPyro and the JAX ecosystem. Through concrete examples—from simple parameter recovery to Bayesian neural networks—viewers learn how to transform sampling problems into optimization problems, enabling GPU-accelerated inference on massive datasets. The presentation covers essential diagnostics, custom optimizers with learning rate schedulers, early stopping techniques, and mini-batch optimization. Dr. Orduz shares hard-won lessons from production applications in demand forecasting and cohort modeling, including when to choose variational inference over MCMC, how to handle uncertainty estimation, and practical tips for avoiding common pitfalls. The talk bridges theory and practice, demonstrating how to leverage deep learning optimization techniques for Bayesian inference at scale.
