Speakers:
Veit Schiele

Description:
Digital mapping has long been dominated by commercial providers with high costs, usage quotas, and privacy concerns. This talk introduces Protomaps, an innovative open-source project that revolutionizes web map delivery through the PMTiles format—a single-file approach to vector tiles that eliminates complex server infrastructure.

Veit Schiele demonstrates how Protomaps reduces bandwidth usage, improves performance, and makes self-hosted maps accessible without API keys or recurring costs. The presentation covers practical implementations with Leaflet, MapLibre, and OpenLayers, showcasing how developers can integrate Protomaps with just a few lines of code. Real-world use cases include privacy-conscious healthcare applications, offline mapping for crisis areas, and custom municipal infrastructure visualization.

Viewers will learn the complete Protomaps toolstack—from OpenStreetMap data processing to deployment on S3, Caddy, or NGINX—and understand when Protomaps is the right choice versus alternatives like GeoJSON or PostGIS. This technology puts mapping control back in developers' hands while maintaining rich, interactive experiences.
