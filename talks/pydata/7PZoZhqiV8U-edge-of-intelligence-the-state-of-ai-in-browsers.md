## Description

🔊 Recorded at PyData Berlin 2025,

🎓 Break free from API dependencies: Learn how to run AI models directly in browsers using WebAssembly, WebGPU, and modern web technologies.

Speakers:
Johannes Kolbe

Description:
Tired of relying on expensive API calls for AI features? This talk explores the cutting edge of WebAI, showing how to run machine learning models directly in users' browsers. Johannes Kolbe takes you on a creative journey through 2025's web technologies, explaining how WebAssembly, WebGPU, ONNX, and frameworks like Transformers.js enable privacy-focused, zero-latency AI applications. Learn about the benefits of browser-based AI including offline capability, reduced costs, and enhanced privacy. The talk covers practical frameworks like TensorFlow.js and Web LLM, real-world compatibility challenges across browsers, and live demonstrations of building AI applications that run entirely client-side. Perfect for developers looking to make AI more accessible and independent from cloud infrastructure.
