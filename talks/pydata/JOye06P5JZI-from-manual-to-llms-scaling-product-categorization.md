## Description

🔊 Recorded at PyData Berlin 2025,

🎓 From manual curation to LLMs: How GetYourGuide scaled product categorization to 250K products across 600 categories with 1.3% conversion lift

Speakers:
Ansgar Grüne, Giampaolo Casolla

Description:
GetYourGuide's data scientists share their journey from manual product categorization to a sophisticated LLM-based system that classifies 250,000 travel experiences across 600+ categories. Starting with rule-based approaches and semantic models, they evolved to a hybrid solution combining OpenAI embeddings for candidate ranking with GPT-4o-mini for final classification. The talk covers critical lessons in prompt engineering, including the evolution from unreliable free-text outputs to structured responses using function calling. Key innovations include using OpenAI's Batch API for 50% cost savings, implementing smart early-stopping mechanisms, and parallelizing category processing. The system now handles 1,500 product updates daily with full automation via Airflow. Results showed significant quality improvements (better precision and recall), enabled 295 new niche categories, and delivered measurable business impact: +1.3% conversion rate, improved quote rate, and reduced bounce rate in A/B testing.
