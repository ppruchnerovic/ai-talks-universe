Speakers:
Christian Geier

Description:
Learn how to build end-to-end machine learning pipelines for anomaly detection in International Space Station telemetry data using only Python. Christian Geier demonstrates how Kubeflow Pipelines, MLFlow, Dask, and other open-source tools enable seamless orchestration of distributed preprocessing, hyperparameter optimization with Katib, multi-GPU training with PyTorch Operator, and scalable model serving with KServe. This Python-first approach eliminates the need for extensive Kubernetes knowledge, making scalable ML workflows accessible to data scientists. The talk covers real-world challenges from the KISS project, which developed anomaly detection and reconfiguration systems for the ISS Columbus module's life support system. All code and configurations are publicly available on GitHub, allowing attendees to replicate and adapt the workflow for their own use cases.
