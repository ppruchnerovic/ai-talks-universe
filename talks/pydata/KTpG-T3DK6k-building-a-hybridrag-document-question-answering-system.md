## Description

🎓 This technical deep-dive explores how combining vector-based retrieval with knowledge graphs can enhance document question-answering systems through hybrid RAG architecture.

Speakers:
Darya Petrashka

Description:
In this technical presentation, Darya Petrashka explores the architecture and implementation of HybridRAG systems for document question-answering. The talk examines how combining traditional vector-based retrieval augmented generation (RAG) with knowledge graph approaches can enhance context understanding and query responses. Petrashka demonstrates how knowledge graphs can capture explicit relationships between entities in documents, complementing the semantic similarity searches of vector RAG systems. The presentation addresses key challenges in building hybrid systems, including knowledge graph construction, domain-specific entity extraction, and the computational overhead of parallel retrieval mechanisms. Through examples in legal document analysis and other domains, Petrashka illustrates how HybridRAG can improve answer quality by providing both broad context from vector retrieval and precise relationship information from graph traversal. The talk concludes with a practical examination of implementation approaches, from custom solutions to cloud-based offerings, discussing their respective trade-offs in terms of control, complexity, and cost. The central thesis emphasizes that while HybridRAG systems can significantly enhance question-answering capabilities for complex domains, the optimal implementation approach depends heavily on specific use case requirements and organizational constraints.
