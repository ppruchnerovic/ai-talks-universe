## Description

This talk presents Scaling Visual Document Retrieval with Training-Free Spatial Pooling - a practical system (Visual RAG Toolkit) that makes state-of-the-art multi-vector visual search an order of magnitude faster without requiring any model retraining.

This work has been accepted at SIGIR 2026, the top venue worldwide in the field of Information Retrieval, held July 20–24 in Melbourne, Australia.
