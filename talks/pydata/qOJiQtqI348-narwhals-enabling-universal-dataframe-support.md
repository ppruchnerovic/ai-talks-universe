Description:
Narwhals is revolutionizing the Python data science ecosystem by providing a lightweight compatibility layer between dataframe libraries. Marco Gorelli explains how this zero-dependency library enables tool builders to write code once that works seamlessly across Pandas, Polars, PyArrow, DuckDB, PySpark, and more. With 30 million monthly downloads and adoption by major libraries like Altair, Plotly, Bokeh, and Marimo, Narwhals is solving the fragmentation problem that has plagued the dataframe ecosystem. The talk covers the technical architecture, including how Narwhals handles lazy vs eager execution, row ordering, indexing challenges, and SQL compatibility. Gorelli also shares valuable insights on community building, static typing benefits, and the philosophy behind creating a sustainable open-source project. Learn why converting everything to Pandas is a missed opportunity and how meeting users where they are with their preferred dataframe library leads to better performance and fewer bugs.
