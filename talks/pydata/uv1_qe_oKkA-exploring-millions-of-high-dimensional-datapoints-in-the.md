## Description

🔊 Recorded at PyData Berlin 2025,

🎓 How Bayer engineers visualize 5 million high-dimensional data points in the browser to accelerate drug discovery from 4 weeks to 1 day.

Speakers:
Matthias Orlowski, Tim Tenckhoff

Description:
Developing new drugs takes over a decade, with early-stage compound identification being a major bottleneck. This talk reveals how Bayer's engineering team built Phenomorph, a system that visualizes millions of high-dimensional cell painting data points directly in the browser. Starting with microscopy images generating 11 terabytes per day, they automated a previously four-week manual workflow into a one-day process. Using Apache Airflow, GraphQL/REST APIs, React, and Next.js, they overcame massive performance challenges in data processing and rendering. The team shares innovative solutions including DOM virtualization with AGGrid for tables, GPU-accelerated 3D rendering with Three.js for scatter plots handling 5 million points, and canvas-based image rendering for 25 million-point similarity heatmaps. Attendees learn practical techniques for building performant data visualizations, optimizing API design, and creating user-friendly tools for scientists to explore complex datasets and accelerate the journey from discovery to life-saving treatments.
