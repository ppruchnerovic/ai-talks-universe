Description:
Vinayak Nair from LiveEO shares how his team built an end-to-end system to transform raw satellite imagery into analysis-ready datasets for vegetation monitoring, deforestation detection, and infrastructure monitoring. The talk covers their cloud-native pipeline that automates satellite data acquisition, storage, and preprocessing while handling various sensors and formats. Using Prefect for workflow orchestration and Anyscale Ray for distributed processing, they reduced processing times from days to near real-time. The system leverages the open-source STAC (SpatioTemporal Asset Catalog) standard for metadata indexing, enabling fast querying and long-term interoperability. Nair discusses practical challenges like inconsistent metadata, diverse sensor types, and provider API drift, while sharing lessons learned from processing 45.5 terabytes and 5.2 million items in production. The talk provides valuable insights into building flexible, scalable geospatial analytics systems that support AI workloads.
