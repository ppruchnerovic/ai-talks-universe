## Description

🔊 Recorded at PyData Berlin 2025,

🎓 Scraping carsharing data reveals hidden urban mobility patterns and opportunities to optimize fleet distribution through user incentives.

Speakers:
Florian König

Description:
Free-floating carsharing systems face a critical challenge: roughly half of vehicles sit idle for three or more hours, contradicting the core purpose of shared mobility. This talk explores how data scraping from Berlin's carsharing operators can reveal hidden patterns in urban mobility and enable smarter fleet management.

Florian König presents findings from analyzing over one million trips across 6,500 vehicles, combining carsharing data with points of interest, traffic conditions, and weather information. Using geospatial analysis techniques like Getis-Ord Gi* and geographically weighted regression, the research demonstrates that contextual factors like POI categories can explain nearly 50% of demand variations on weekdays.

The presentation examines whether low-friction discounts could incentivize users to naturally rebalance vehicle distribution, potentially saving operators significant relocation costs (approximately €10 per manual relocation). While predicting exact destinations proved challenging without user identifiers, the research reveals a theoretical 45% prediction accuracy ceiling if user history were incorporated. The talk offers valuable insights for data scientists interested in urban analytics, transportation modeling, and practical applications of machine learning in mobility systems.
