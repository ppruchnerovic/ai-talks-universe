Speakers:
Alina Dallmann

Description:
Alina Dallmann shares practical insights from implementing LiteLLM in a production RAG system for a university chatbot. LiteLLM promises a unified interface across multiple LLM providers, but how does it perform in real-world scenarios?

This talk covers the implementation of LiteLLM's proxy server for a privacy-preserving chatbot serving students and employees. Alina walks through key features including automatic cost tracking, budget management, and load balancing across multiple models. She demonstrates how LiteLLM simplifies provider switching and handles token budgets through PostgreSQL integration.

However, the talk also addresses significant challenges: limitations in custom budgeting requirements, delays in new model support, occasional bugs in new features, and the trade-offs of abstraction layers. Alina provides honest assessments of when LiteLLM excels—multi-provider setups with governance needs—and when alternatives like OpenRouter or TensorZero might be better choices. Essential viewing for developers considering LiteLLM beyond simple prototypes.
