## Description

🔊 Recorded at PyData Berlin 2025,

🎓 Move beyond generic benchmarks: Learn practical strategies for evaluating LLM systems with human-in-the-loop feedback and automated testing.

Speakers:
Iryna Kondrashchenko, Oleh Kostromin

Description:
As LLMs become integral to business operations, evaluation becomes critical. This talk presents a practical framework for evaluating compound AI systems that goes beyond generic benchmarks. Iryna Kondrashchenko and Oleh Kostromin demonstrate how to combine subject matter expert (SME) feedback with automated testing to continuously improve LLM-powered applications. The framework includes automatic tracing to capture pipeline steps, expert feedback collection, iterative improvement cycles, and degradation tests using LLM-as-a-judge approaches. Learn how to structure domain-specific evaluations using binary pass/fail metrics, create meaningful assertions, build representative datasets across features, scenarios, and personas, and monitor production systems effectively. The speakers emphasize that SMEs are essential for domain-specific evaluation and show how to balance manual assessment with automation as systems scale.
