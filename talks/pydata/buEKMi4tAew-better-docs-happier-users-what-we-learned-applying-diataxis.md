Speakers:
Maxime Liquet

Description:
Good documentation can make or break an open-source project, but achieving it is challenging. This talk shares practical lessons from applying the Diataxis framework to improve documentation for two HoloViz libraries: Panel and hvPlot. Maxime Liquet walks through the journey from messy user guides to structured documentation organized into four content types: tutorials, how-to guides, explanations, and references. Learn about the real challenges faced, including the difficulty of writing tutorials, handling content migration, and convincing stakeholders to prioritize documentation work. The talk covers what worked well (starting with reference documentation, creating focused how-to guides) and what didn't (attempting complete overhauls, removing content too quickly). Whether you're maintaining a small library or a large framework, you'll gain actionable insights on improving your documentation and making it easier for both users and contributors.
