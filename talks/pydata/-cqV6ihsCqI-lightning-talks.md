## Description

🔊 Recorded at PyData Berlin 2025,

🎓 Five lightning talks covering handwriting recognition, community building, workplace visibility, cron expressions, and the importance of documentation

Description:
This lightning talk session features five diverse presentations from the Python community. Martin introduces an open-source handwriting recognition tool for Xournal++ notes using PyTorch, making millions of handwritten documents searchable. Sarah reflects on nine years of community involvement, emphasizing the importance of supporting local tech communities. Nastia shares practical tips on workplace visibility, from tracking daily work to effective stand-ups and feedback. Fabrizio demonstrates a NeoVim plugin for parsing cron expressions with asynchronous rendering. Marco reveals surprising pandas scoping bugs and introduces pd.col as a solution. Adrian warns about Python .pth files and potential security risks. Stephen closes with an impassioned plea for better code documentation, advocating for literate programming practices.
