Speakers:
Orell Garten

Description:
Many industrial systems still rely on TCP streams for critical data transmission. This talk demonstrates how to build efficient, on-premise batch pipelines using Python and DuckDB without cloud complexity. Orell Garten covers the complete pipeline architecture: ingesting raw TCP streams with async Python servers, validating data with Pydantic, compacting JSON to Parquet with DuckDB, and preparing data for analytics. Learn practical patterns for handling sensor data, logs, and telemetry from manufacturing, logistics, and energy systems. The approach scales to process over 1TB daily while maintaining simplicity and control. Perfect for teams working with legacy systems, resource-constrained environments, or those processing under 100GB per day who want pragmatic alternatives to heavyweight cloud platforms.
