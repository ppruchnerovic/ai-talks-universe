Description:
Tired of deciphering complex SQL queries with nested subqueries and sprawling CTEs? This talk introduces Pipelined SQL, an alternative syntax that lets you write queries as a clear, sequential flow of transformations. Tobias Lampert, an analytics engineer at Lotum, demonstrates how this approach—inspired by data frame APIs like Pandas and Polars—brings top-to-bottom readability to SQL.

Learn how Pipelined SQL eliminates the inside-out data flow of traditional SQL by allowing you to chain operators in any order, apply the same transformation multiple times, and debug queries by running them step-by-step. The talk covers which platforms currently support pipe syntax natively (BigQuery, Databricks, Spark 4.0) and how to use SQL transpilers like SQLGlot to convert pipe syntax to any SQL dialect.

Through practical examples comparing traditional and pipelined syntax side-by-side, you'll see how this approach reduces code complexity, improves maintainability, and makes SQL queries genuinely understandable. Perfect for data analysts, engineers, and scientists who want to write cleaner, more robust SQL code.
