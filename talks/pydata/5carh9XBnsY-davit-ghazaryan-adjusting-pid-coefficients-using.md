## Description

Davit Ghazaryan, Adjunct Lecturer at the American University of Armenia, presents a talk on
“Adjusting PID Coefficients Using Reinforcement Learning for UAV Control.”

How can Reinforcement Learning be used to improve classical control systems? This talk explores an applied approach to tuning PID coefficients for Unmanned Aerial Vehicle (UAV) control, using realistic simulation and autopilot interaction.

In this session, Davit discusses:
🔹 The fundamentals of Reinforcement Learning and PID control
🔹 How learning-based methods can be combined with classical control systems
🔹 Training agents to tune PID parameters in simulation
🔹 Using RLDroneSim with ArduPilot Software-In-The-Loop (SITL) and the Gazebo physics engine

📌 The research presented is conducted as part of a project supported by the Afeyan Family Foundation.

This talk was recorded during the PyData Yerevan February Meetup, held on February 19, 2026, at the American University of Armenia.
