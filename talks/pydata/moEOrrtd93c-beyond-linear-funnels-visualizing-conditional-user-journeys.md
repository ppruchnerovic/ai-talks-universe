Yaseen Esmaeelpour

Description:
Traditional funnel analysis assumes linear user journeys, but real-world applications often involve conditional paths where the next step depends on previous user actions. Yaseen Esmaeelpour introduces funnelius, an open-source Python library that addresses this challenge by analyzing and visualizing non-linear, conditional funnels.

The library processes event logs with user_id, action, and timestamp data to generate interactive graphs using Graphviz and Streamlit. It automatically calculates key metrics including conversion rates, drop-offs, time spent per step, and highlights bottlenecks through color-coding. Users can filter low-quality data, compare different datasets, analyze user answers, and customize visualizations through an interactive UI.

The talk demonstrates real-world applications like vehicle pricing tools where questions branch based on previous answers (e.g., battery capacity only for electric vehicles). Attendees learn why traditional solutions like Sankey diagrams or milestone-based funnels fall short, and how funnelius provides a more effective approach for data analysts and scientists working with complex user journeys.
