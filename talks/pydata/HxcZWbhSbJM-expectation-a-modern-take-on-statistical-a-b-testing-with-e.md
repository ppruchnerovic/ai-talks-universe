Description:
In this presentation, Jako Rostami introduces 'expectation', a Python library implementing modern statistical hypothesis testing using e-values and martingales. The framework offers an alternative approach to traditional A/B testing, based on game-theoretic probability theory. Rostami demonstrates how e-values can be interpreted through a betting/wealth accumulation metaphor, where evidence against a null hypothesis is viewed as accumulated wealth under sequential testing conditions. The framework allows for flexible stopping rules and continuous monitoring without invalidating results, addressing common challenges in practical A/B testing scenarios. Through live code demonstrations, Rostami illustrates the library's application in sequential testing, change point detection, and confidence sequences. The approach maintains statistical validity while offering practitioners more flexibility than traditional p-value methods. A key advantage is the framework's ability to handle sequential testing scenarios while maintaining type-1 error guarantees through Ville's inequality. The library implements these concepts in a modular, object-oriented design with comprehensive documentation and research-based implementations. While positioned as complementary to existing statistical methods rather than a replacement, the framework offers particular value in sequential testing scenarios common in industrial monitoring, finance, and clinical trials.
