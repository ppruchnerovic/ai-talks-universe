Speakers:
Gergely Daroczi

Description:
Spare Cores is an open-source, vendor-independent ecosystem that benchmarks cloud server performance across multiple providers. This talk presents results from testing over 2,000 server types across AWS, GCP, Azure, Hetzner, and other vendors to evaluate their suitability for serving Large Language Models from 135M to 70B parameters. The project measures inference speed for both prompt processing and text generation across varying token lengths, helping users identify the optimal instance type for their specific LLM serving needs. All data, tools, and benchmarks are openly published, including database dumps, APIs, and SDKs. The presentation covers the methodology, challenges in data collection, and surprising insights—such as how modern AMD CPUs can sometimes outperform GPU instances on a cost-efficiency basis for certain workloads. Future plans include expanding benchmarks to include GBM model training across popular frameworks like XGBoost and LightGBM.
