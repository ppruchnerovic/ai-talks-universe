## Description

[`jupyter-fs`](https://github.com/jpmorganchase/jupyter-fs) provides an interface between [PyFilesystem](https://www.pyfilesystem.org) and [fsspec](https://filesystem-spec.readthedocs.io/en/latest/) file systems, the JupyterLab user interface, and the Jupyter notebooks you run. Connect and browse your local filesystem, S3, Samba, WebDAV, and more, interacting with data seamlessly from both the JupyterLab UI and your notebook's kernel.
