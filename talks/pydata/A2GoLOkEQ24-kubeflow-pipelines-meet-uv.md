Speakers:
Fabrizio Damicelli

Description:
Fabrizio Damicelli demonstrates how to combine Kubeflow pipelines with uv, the modern Python dependency management tool, to create more maintainable machine learning workflows. This practical talk addresses a common pain point: managing dependencies across pipeline components while adhering to Python best practices like pyproject.toml and lockfiles. Through live coding, Damicelli shows how to build a simple ML pipeline that runs locally, explaining how Kubeflow orchestrates containerized components on Kubernetes. The key innovation presented is a wrapper solution that dynamically resolves dependencies from uv at pipeline generation time, enabling tools like Dependabot to work while maintaining Kubeflow's flexible API. Viewers learn about component decoration, artifact passing between pipeline steps, and how to structure production-ready ML workflows that avoid dependency conflicts.
