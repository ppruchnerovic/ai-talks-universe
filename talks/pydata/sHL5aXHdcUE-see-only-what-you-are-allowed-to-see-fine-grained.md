Description:
This hands-on tutorial introduces Fine-Grained Authorization (FGA) using OpenFGA, an open-source authorization engine inspired by Google's Zanzibar. Maria Knorps demonstrates how to move beyond traditional role-based access control (RBAC) to implement Relationship-Based Access Control (ReBAC) for data-intensive applications. Participants learn to set up OpenFGA locally, define authorization models using domain-specific language, write relationship tuples, and integrate authorization checks using the Python SDK. The workshop covers practical scenarios like document access management with different permission levels (viewers, editors) across teams and folders. Real-world use cases from highly regulated industries illustrate how FGA enables row-level permissions, handles complex inheritance patterns, and maintains separation of concerns by running as a dedicated authorization service. The tutorial includes live coding exercises, testing strategies, and best practices for synchronizing authorization data with application databases.
