## Description

🔊 Recorded at PyData Berlin 2025,

🎓 Learn how to shrink data science container images from 12GB to 1.5GB while optimizing build times and managing GPU dependencies.

Speakers:
Jérôme Petazzoni

Description:
Docker expert Jérôme Petazzoni shares practical techniques for containerizing data science workloads using the Whisper speech-to-text model as a case study. Starting with basic Dockerfiles, he demonstrates how to optimize both image size and build time through BuildKit cache mounts, multi-stage builds, and dependency management. The talk covers reducing image size from 12GB to 1.5GB, handling GPU vs CPU builds, managing model weights, and avoiding common pitfalls like using Alpine with Python. Petazzoni also evaluates alternatives to Dockerfiles including build packs and language-specific tools, explaining why traditional Dockerfiles remain the most practical choice for data science containers. Perfect for data scientists and ML engineers deploying models on Kubernetes or building reproducible development environments.
