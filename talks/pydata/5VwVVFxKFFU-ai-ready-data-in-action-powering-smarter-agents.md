## Description

🔊 Recorded at PyData Berlin 2025,

🎓 Learn to build production-ready AI agents by mastering data ingestion, vector search, and hybrid retrieval with dltHub and LanceDB.

Speakers:
Violetta Mishechkina, Chang She

Description:
This hands-on workshop demonstrates the complete workflow for building AI-ready data pipelines and intelligent agents. Violetta Mishechkina from dltHub and Chang She from LanceDB guide participants through ingesting real-world GitHub issues data, creating embeddings, optimizing search strategies, and building a functional AI agent.

The tutorial covers practical data engineering with dltHub's open-source Python library, which handles schema evolution, incremental loading, and data normalization automatically. Participants learn to implement vector search, full-text search, and hybrid retrieval in LanceDB, experimenting with different re-ranking techniques including cross-encoders and ColBERT models.

The workshop culminates in building an AI agent that searches GitHub issues, retrieves relevant comments, and generates summaries using GPT-4. Attendees gain hands-on experience moving from messy raw data to production-ready AI applications, with guidance on deploying to LanceDB Cloud for scalable, serverless infrastructure.
