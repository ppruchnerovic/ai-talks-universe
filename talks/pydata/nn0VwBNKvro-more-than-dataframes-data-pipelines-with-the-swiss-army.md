Description:
This hands-on tutorial explores DuckDB as more than just a DataFrame alternative—it's a powerful in-process analytical database that runs anywhere Python does. Mehdi Ouazza demonstrates how to build data pipelines using SQL without managing servers, reading directly from CSV, Parquet, JSON, APIs, and even PostgreSQL databases. The session covers DuckDB's extension ecosystem, cloud storage integration (S3, HTTP), and seamless interoperability with Pandas and Polars via Apache Arrow. Attendees learn when to choose DuckDB over traditional tools, how to cache intermediate results, and techniques for serving analytics at scale. Real-world examples include analyzing Netflix viewing patterns during COVID, GitHub repository statistics, and Hacker News trends. The tutorial also touches on advanced topics like WebAssembly deployment, MotherDuck cloud integration, and vector search capabilities. Perfect for data engineers, analysts, and scientists working with medium-scale datasets who want lightweight, SQL-based workflows without the overhead of distributed systems.
