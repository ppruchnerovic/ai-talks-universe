🎓 Build production-ready AI agents that translate natural language to SQL queries with validation, safety checks, and human-in-the-loop approval.

Speakers:
Cainã Max Couto da Silva

Description:
This hands-on tutorial demonstrates how to build an end-to-end AI agent system that translates natural language questions into SQL queries and executes them on live databases. Using the Brazilian E-Commerce dataset from Kaggle, participants learn to implement intelligent routing between specialized SQL agents and ReAct chat agents, RAG for query similarity matching, comprehensive safety validation, and human-in-the-loop confirmation. The session covers multiple frameworks including LangChain, LangGraph, LangSmith, Llama Index, and Vanna AI, with deep dives into production-grade implementations. Key topics include schema ingestion with domain knowledge, vector similarity for context retrieval, SQL generation with validation guardrails, cost tracking, and session-based memory management. The tutorial provides practical code examples and addresses real-world challenges like handling complex multi-table queries, preventing hallucinations through prompt engineering and examples, and ensuring query accuracy for business-critical applications.
