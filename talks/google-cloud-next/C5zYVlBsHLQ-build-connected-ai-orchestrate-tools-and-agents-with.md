# Build connected AI: Orchestrate tools and agents with registries and ADK

**Michael Vakoc, Mak Ahmad, Min Zu**

`Google Cloud Next` · `Next 2026` · `2026` · `30 min`

[Watch the recording](https://www.youtube.com/watch?v=C5zYVlBsHLQ) · [Conference site](https://cloud.withgoogle.com/next/)

## Description

Move beyond simple prototypes and build agents that can access your organization’s most critical data – whether it lives in third-party SaaS or legacy on-premises systems. In this session, learn how to use the Agent Development Kit (ADK) with Agent Registry to securely connect your agent to other agents and tools. We’ll cover the full builder’s journey – from discovering and integrating with existing Google and partner Model Context Protocol (MCP) servers to building custom MCP servers from scratch using the specification boost add-on to instantly transform any API into agent-ready tools.

Speakers: Michael Vakoc, Mak Ahmad, Min Zu
