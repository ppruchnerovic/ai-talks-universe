# Scale AI agents in production

**Elia Secchi, Ryan Ismert, Tejul Pandit, Praveen Dhas**

`Google Cloud Next` · `Next 2026` · `2026` · `35 min`

[Watch the recording](https://www.youtube.com/watch?v=LHcjN11nNPU) · [Conference site](https://cloud.withgoogle.com/next/)

## Description

Take agents from prototype to scaled production with Google’s modular, generally available agent platform services. Join this session to learn how to scale agents using our newly revamped runtime, which now offers fast cold starts and provisioning, personalization with memory bank and sessions services, and secure sandboxes to safely execute complex tasks like code execution and computer use. We’ll cover best practices like production observability and how to choose the deployment option that best fits your needs. Learn from customers who have crossed the generative AI divide and are running agents in production.
