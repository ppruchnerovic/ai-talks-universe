# Generative UI for any agent, anywhere: A2UI, AG-UI, MCP Apps, and more

**Alan Blount, Atai Barkai, Ido Salomon, Nicolas Le Pallec**

`Google Cloud Next` · `Next 2026` · `2026` · `41 min`

## Description

The future of the web isn’t just interactive – it’s adaptive. Break the “chat wall” with agents that customize UIs for any context. Join the core teams behind A2UI, a native-first standard that treats UI as declarative data for ultimate security and performance, establishing your design system as the “trust catalog.” This session also features CopilotKit’s CEO discussing AG-UI, which connects all frontends and agent backends, and one of MCP Apps’ co-creators promoting agent UI standardization everywhere. Learn when to choose which approach for brand-consistent, agent-driven, and agent-generated design. Discover how this powers Gemini Enterprise, Google Search, and the future of the agentic web.

Speakers: Alan Blount, Atai Barkai, Ido Salomon, Nicolas Le Pallec
