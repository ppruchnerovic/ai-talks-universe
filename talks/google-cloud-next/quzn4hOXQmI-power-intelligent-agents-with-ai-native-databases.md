# Power intelligent agents with AI-native databases

**Amit Ganesh, Yannis Papakonstantinou, David Soria Parra**

`Google Cloud Next` · `Next 2026` · `2026` · `50 min`

## Description

AI-native databases are essential for powering agents with enterprise data. Learn how they enable highly relevant context, automate operations, and manage risk. In this session, we’ll examine AI-powered search, natural language interfaces, multimodal queries, and graph retrieval-augmented generation (RAG). These move beyond simple retrieval, providing agents with high-fidelity, interconnected context. Discover how open standards like Model Context Protocol (MCP) and agentic IDEs streamline workflows for rapid, reliable deployment of agents.

Speakers: Amit Ganesh, Yannis Papakonstantinou, David Soria Parra
