## Description

This session maps a complete critical user journey that unites the vibe coding of early ideation with the rigor of production engineering. We’ll demonstrate how to use Gemini Enterprise Agent Platform and Model Context Protocol (MCP) to create a workflow where different stakeholders can contribute to an app’s life cycle without friction. Follow the journey of a Gemini Enterprise Agent Platform-powered application from its initial prototype through development, deployment, and ongoing post-launch management of updates. And learn how MCP allows you to inject changes, tune models, and manage versions directly from your preferred environment – whether that’s a design tool or an IDE like VS Code – ensuring continuous improvement for your production agents.
