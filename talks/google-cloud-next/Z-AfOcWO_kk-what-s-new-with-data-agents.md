## Description

Discover the latest in data analytics agents. In this session, we’ll explore enhanced built-in capabilities designed to streamline workflows across data engineering, data science, and conversational analytics. Learn to build custom agents grounded in your enterprise data using new developer tools, including the Agent Development Kit (ADK) and Model Context Protocol (MCP) integrations. Find out how to access these powerful features seamlessly via the Gemini CLI, Claude Code, Codex, and IDEs like VSCode to supercharge your productivity.
