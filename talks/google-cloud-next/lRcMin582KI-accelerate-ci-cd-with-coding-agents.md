# Accelerate CI/CD with coding agents

**Haroon Chaudhry, Yeshwanth Gunasekaran**

`Google Cloud Next` · `Next 2026` · `2026` · `28 min`

[Watch the recording](https://www.youtube.com/watch?v=lRcMin582KI) · [Conference site](https://cloud.withgoogle.com/next/)

## Description

Learn how generative AI transforms platform engineering through a zero-to-hero workflow. In this session, we’ll demonstrate how to use natural language to scaffold continuous integration and deployment (CI/CD) pipelines, manage Artifact Registry repositories, and streamline Identity and Access Management (IAM) authentication – all from the developer tools you already know and love. Discover how to automate containerization with Cloud Build and how to define promotion strategies in Cloud Deploy. Join us to learn how to trigger vulnerability scanning with simple prompts, and explore the architecture for translating prompts into Terraform.

Speakers: Haroon Chaudhry, Yeshwanth Gunasekaran
