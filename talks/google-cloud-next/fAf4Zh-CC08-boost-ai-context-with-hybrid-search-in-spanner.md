## Description

Go beyond keyword search to get the most out of your operational data. In this session, learn to build sophisticated, AI-powered experiences with Spanner. Discover how to combine full-text and vector search into powerful multi-model queries that deeply understand user intent. We’ll unveil new AI innovations that simplify contextual search and retrieval-augmented generation (RAG) applications. Explore seamless integrations with Gemini Enterprise Agent Platform to create the next generation of contextual, intelligent, multi-model search.
