## Description

Enterprise data is often trapped behind fragmented APIs and complex models, hindering AI agents from extracting insights. In this session, learn to build a production-grade Autonomous Data agent that bridges the gap between LLM reasoning and enterprise data. We’ll showcase an agent on Cloud Run using the new BigQuery Model Context Protocol (MCP) server to interact with data as a native tool.
