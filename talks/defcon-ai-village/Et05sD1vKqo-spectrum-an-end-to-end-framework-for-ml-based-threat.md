## Description

Author: Nahid Farhady, Vincent Pham

Machine Learning is gaining popularity in the area of cyber security with the growth of connected network devices that leads to an increase in the amount of data being handled for security monitoring. This paper proposes a framework that facilitates security monitoring on different entities at large scale, the so- called Spectrum. We address the production issues and challenges of Spectrum.
