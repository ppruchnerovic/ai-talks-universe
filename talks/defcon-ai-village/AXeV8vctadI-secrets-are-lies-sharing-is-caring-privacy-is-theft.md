## Description

SECRETS ARE LIES, SHARING IS CARING, PRIVACY IS THEFT A Dive into Privacy Preserving Machine Learning

Author: Nahid Farhady

Machine Learning is considered a strong tool for many sensitive applications. As a result, security of ML is also an important factor. In this workshop, we cover an overview of several adversarial attacks and defences. As a result, the model developer is able to identify points of vulnerability in the model and apply an appropriate defense technique.
