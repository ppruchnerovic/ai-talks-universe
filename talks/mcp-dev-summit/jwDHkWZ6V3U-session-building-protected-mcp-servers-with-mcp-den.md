## Description

Building Protected MCP Servers With MCP C#
🎤 Den Delimarsky, Principal Product Manager - Microsoft

Want to build secure Model Context Protocol servers with the MCP C# SDK? This talk will show you how! Learn practical skills like setting up authorization, integrating with MCP clients, and ensuring proper controls to keep your MCP server safe.

Along the way, we work through real examples that demonstrate the SDK's features - from support of the new authorization spec to token validation and proper error handling. You'll come away with the insights needed to build and deploy MCP servers that not only connect data to models effectively but also keep sensitive data locked down tight.
