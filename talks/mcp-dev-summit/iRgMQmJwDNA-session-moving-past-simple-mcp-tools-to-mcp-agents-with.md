## Description

[Session] Moving Past Simple MCP Tools to MCP Agents
🎤 Darren Shepherd, Chief Architect and Co-Founder - Obot AI

Most developers think of MCP servers as simple tool providers—wrapping APIs so AI systems can call them. But does it always make sense for a company to expose all of its functionality and data as tools? If I'm a bank, how much raw data and functionality do I want to share without an agent sitting in front of it? But what if an MCP server could bebe the agent?

In this talk, we introduce Nanobot, an open-source framework for turning any MCP server into a full-featured agent with reasoning, system prompts, access to MCP tools, and rich MCP-UI support.

We’ll demo a “Bank Agent” built entirely as an MCP: it manages authentication, guides conversations, and calls specialized service MCPs for actions like transfers or statements. Nanobot makes this possible while staying fully protocol-compatible, enabling rich, interactive experiences.

Attendees will see how to move beyond tool wrappers to true MCP agents—plug-and-play, stateful, and ready to run anywhere.
