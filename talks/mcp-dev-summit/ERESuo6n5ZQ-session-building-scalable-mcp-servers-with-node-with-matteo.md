## Description

[Session] Building Scalable MCP Servers with Node.js, Fastify and @platformatic/mcp
🎤 Matteo Colina, Co-Founder & CTO - Platformatic.dev

Building production-ready MCP servers that handle thousands of concurrent connections presents unique scaling challenges. This talk explores `@platformatic/mcp`, a battle-tested plugin for Fastify (the high-performance Node.js web framework) that transforms MCP development from prototype to enterprise scale.

We'll journey through the complete development cycle: starting with type-safe tool definitions using TypeBox schemas, implementing Server-Sent Events for real-time communication, and ultimately achieving horizontal scalability through Redis-backed session management and message broadcasting. You'll discover how to maintain session persistence across server restarts, broadcast messages across multiple instances, and handle complex scenarios like load balancing and failover.

Through live coding demonstrations, we'll build an MCP server that evolves from handling a single connection to supporting 10,000+ concurrent SSE streams. Attendees will learn production patterns including authentication, monitoring, circuit breakers, and deployment strategies that enable MCP servers to power everything from developer tools to financial trading platforms.
