## Description

[Session] Scaling MCP Observability: How Natoma Monitors Thousands of MCP Servers
🎤 Kapil Duraphe, Software Engineer - Natoma

At Natoma, we host thousands of MCP servers serving clients from Claude Desktop to Cursor and custom applications. This talk shares production lessons from building comprehensive observability for MCP infrastructure at enterprise scale.

What We'll Cover:

Production-Scale Challenges:
Monitoring MCP servers across multiple tenants and environments
Debugging protocol issues between diverse clients and hosted servers
Handling connection spikes and resource optimization
Natoma's Observability Platform:
Live demonstration of our MCP monitoring dashboard in production
Real-time tracing of tool execution across thousands of concurrent sessions
Performance analytics and incident response strategies
Operational Insights:
Common failure patterns and debugging strategies at scale
SLA monitoring and capacity planning for large MCP deployments
Hard-won lessons from operating MCP infrastructure in production

Attendees will see real production data and traces from Natoma's platform, plus practical patterns learned from hosting MCP servers at scale.

Essential for platform teams, enterprises running large MCP deployments, or anyone interested in production-grade MCP observability.
