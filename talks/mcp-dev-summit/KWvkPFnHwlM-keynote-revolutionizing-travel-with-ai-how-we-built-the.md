## Description

Revolutionizing Travel with AI  How We Built the Turkish Airlines MCP
🎤 Mustafa Ekrem Kenter, Head of Digital Lab - Turkish Airlines Technology

At Turkish Technology Digital Lab, we're exploring how we can enhance travel experiences using technology. With the introduction of the Model Context Protocol (MCP) by Anthropic in late 2024, we saw an opportunity to integrate AI assistants directly with our airline systems.

The result is the Turkish Airlines MCP Server—a functional implementation that allows AI models to access live airline data and services securely and efficiently.

We will present how we implemented that, which challenges we faced and how did we address those issues.
