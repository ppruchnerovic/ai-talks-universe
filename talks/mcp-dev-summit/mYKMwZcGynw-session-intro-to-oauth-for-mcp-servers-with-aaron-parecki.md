## Description

Intro to OAuth for MCP Servers
🎤 Aaron Parecki, Director of Identity Standards - Okta
🔗 Blog post https://bit.ly/4kPzo1G

OAuth 2 has become the standard framework for securing APIs across the web, enabling secure access to data without sharing passwords. In this session you'll get a practical introduction to OAuth and understand its core concepts, including authorization flows, tokens, and scopes. We'll then explore how OAuth applies specifically to MCP Servers, highlighting common implementation strategies, usage with upstream APIs, and integration with existing identity providers. Whether you're new to OAuth or just starting with MCP, this talk will give you the essential knowledge to confidently approach securing your MCP Server.
