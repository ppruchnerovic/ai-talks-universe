## Description

[Session] Let's dream big for MCP Auth
🎤 Tobin South, Head of MCP - WorkOS

OAuth implementation remains one of the most significant challenges for MCP developers. Without proper planning for increasingly complex agent interactions, these pain points will only intensify. We'll explore the state of play with OAuth and the current use cases, map out the near-term opportunities, and then venture through future levels of agent autonomy to explore how auth and access controls will need to adapt to new agent use cases as they're unlocked. This talk will cover the present challenges, the future plans, and the dreams of an MCP future we all want to see.
