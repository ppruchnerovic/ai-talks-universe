## Description

Effortless User Onboarding with MCP
🎤 Pedro Rodrigues, Software Engineer - SingleStore (former MemSQL)

Onboarding users to new features is often an afterthought—buried in documentation, blog posts, or support tickets. But what if your product could explain itself? In this talk, I’ll share how we used the Model Context Protocol (MCP) at SingleStore to onboard users to a brand-new product without relying on traditional documentation.With the correct mix of tools, resources, and prompts, we were able to guide users through setup, integration, and advanced usage—delivering a frictionless experience that met them where they already were. I’ll walk through how we structured our MCP server, designed meaningful context, and shipped a smooth onboarding flow that scaled from early adopters to general availability. Whether you’re building a new feature or launching an entirely new product, this session will show how MCP can help your users get started faster and more intuitively.
