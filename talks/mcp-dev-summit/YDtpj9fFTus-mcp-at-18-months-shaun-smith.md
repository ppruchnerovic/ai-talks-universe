## Description

Shaun Smith — MCP server maintainer at Hugging Face, transport working group contributor, and creator of the open-source fast-agent framework — takes the stage at the Agentic AI Foundation to ask the uncomfortable question: did MCP die? Eighteen months after Anthropic launched the Model Context Protocol, the agent ecosystem looks nothing like it did at launch. Shaun walks through what changed, what stuck, and what's quietly powering the next wave of agentic infrastructure.

- Reinforcement learning rewrote the rules — Why post-training with reward functions unlocked 80-100+ tool-call agent runs and changed harness design forever
- The single-shell-token revolution — How a 100-line minimal harness with one free-form shell tool now scores 76% on SWE-bench, closing in on state-of-the-art
- Skills as the missing primitive — Why skills land somewhere between deterministic programs and flexible guidelines, and why they fail with the wrong model
- Dynamic tool calling at scale — How Hugging Face exposes thousands of ML models through a 45-token surface by letting the model write its own tool descriptions
- Code execution as the new tool surface — Why models shipping with native interpreters is blurring the line between generation and execution environments
- Sidestepping JSON post-processing — Generative UI components (via libraries like Prefect) that render results directly to users instead of burning expensive output tokens
- Agent Client Protocol (ACP) — How Zed's normative protocol bundles inference engines, tools, shells, skills, and sub-agents for editor-native agents
- Open Responses API — OpenAI's now-open-sourced inference API and what its handling of internal vs external resources unlocks
- Why MCP won the consumer and enterprise battle — Authentication, remote transport, and resource URIs as the foundation Apps SDK is riding into thousands of clients
- The MCP CLI pattern — Using progressive disclosure tools like MCPorter to deploy MCP servers inside agent execution environments

For agent builders, MCP server authors, AI infrastructure engineers, and anyone trying to make sense of the protocol stack heading into 2026.
