## Description

From Experiment to Enterprise: How Block Operationalized MCP at Scale
🎤 Angie Jones, VP Developer Relations - Block

This talk explores Block's journey from initial adoption to company-wide deployment, highlighting how we've leveraged MCP to build Goose, an open source MCP client, and how it's been configured to connect with an array of MCP servers while meeting our security and compliance requirements. Gain insights into practical strategies for deploying MCP in enterprise environments, including server curation, access control, and user adoption.
