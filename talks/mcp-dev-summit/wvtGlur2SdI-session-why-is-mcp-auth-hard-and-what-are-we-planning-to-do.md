## Description

[Session] Why is MCP Auth Hard and What Are We Planning to Do About It
🎤 Paul Carleton, Member of Technical Staff - Anthropic

MCP strives for UPnP for AI applications – any client can connect to any server without prior coordination. But this cuts against the grain of traditional OAuth patterns: users pick servers their client developer has never heard of, creating unique security challenges.

In this talk, I'll explore why MCP's user-driven model fundamentally changes authentication and how we're adapting OAuth to fit. I'll walk through the specific threats we face (phishing, MITM attacks), the practical pain points (Dynamic Client Registration), and what we're building to fix them: streamlined client registration, enhanced security mitigations, and conformance testing tools.

Whether you're implementing MCP auth or curious about securing open ecosystems, you'll leave understanding why MCP auth is hard and what the MCP maintainers are doing about it.
