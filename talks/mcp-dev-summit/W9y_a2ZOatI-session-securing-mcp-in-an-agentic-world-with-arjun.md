## Description

Securing MCP in an Agentic World
🎤 Arjun Sambamoorthy, Sr. Director of AI - Cisco Systems

In this talk, we walk through the current security gaps in MCP—like prompt injection, tool poisoning, backdoors and weak validation and auth. We highlight where things can go wrong today, share simple, effective ways to make MCP integrations secure, and focus on practical steps teams can take to build safer AI Agents with MCP.
