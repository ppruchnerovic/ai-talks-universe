## Description

Scaling Commerice Interactivity  Lessons from Shopify's Implementation of MCP UI
🎤 Samuel Path, Software Engineer - Shopify
🎤 Bret Little, Staff Engineer - Shopify

Once you have MCP UI’s abstract model, what does it really take to embed fully interactive commerce flows inside AI agents? In this session, we’ll tell the story of Shopify’s engineering journey building production-grade MCP UI integrations: from dynamic product cards and universal carts to compliance-certified, branded checkout experiences. We’ll share what went right (and wrong) as we rolled out native shopping capabilities into third-party conversational agents — including unique technical and legal challenges, performance concerns, accessibility/compliance features, UX adaptation via custom CSS, and event-driven agent coordination. Alongside live demonstrations and engineering deep-dives, we’ll close with open problems, protocol feedback, and a vision for richer agentic commerce as the MCP ecosystem matures.
