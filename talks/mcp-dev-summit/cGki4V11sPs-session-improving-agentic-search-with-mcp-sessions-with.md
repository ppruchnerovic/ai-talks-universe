[Session] Improving Agentic Search with MCP Sessions
🎤 Matt Dailey, Founder - Ref

Many MCP servers are stateless wrappers around API endpoints but the protocol offers more. At Ref we take advantage of MCP sessions to build a stateful search experience to help agents find exactly what they need. The talk will cover what we explored, rough edges we bumped into and where we landed in the end.
