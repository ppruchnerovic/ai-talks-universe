## Description

[Session] One Test a Day Keeps the Issues Away
🎤 Oleksandr Kotov, Staff Software Engineer - Grafana Labs

When your MCP server slows down or throws strange errors, the magic of your LLM-powered features disappears. Reliability is critical to keep your users happy.In this talk, we’ll cover why testing MCP servers is critical for catching issues before they affect your users. We’ll also get hands-on with Grafana k6, a developer-centric, open-source tool that makes performance testing productive and (even) fun. You’ll learn how to test MCP servers the hard way by crafting SSE/HTTP calls from scratch and the easy way with xk6-mcp, a new k6 extension we developed that speaks MCP natively. No filler, no fluff. You’ll walk out ready to make your MCP servers faster, more reliable, and ready for real-world traffic.
