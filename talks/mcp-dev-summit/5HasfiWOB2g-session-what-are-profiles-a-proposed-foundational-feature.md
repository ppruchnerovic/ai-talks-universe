[Session] What are Profiles?  A Proposed Foundational Feature of MCP Servers
🎤 Atul Tulshibagwale, CTO - SGNL

MCP Servers have prompts, resources, and tools. But enterprises wanting to scale deployments of MCP did not have a means of enforcing policy across all MCP Servers. MCP Clients acting on behalf of consumers might also want to understand a consumer’s relationship with an MCP Server in order to be able to modulate its use of an MCP Server.Profiles are a simple way of describing a collection of behaviors and properties an MCP Server can support together. Organizations or individuals can enforce policies that demand the use of certain profiles in order to meet security or regulation compliance requirements. MCP Servers can also deny connections to MCP Clients that do not select a profile they support.

In this talk, I will give a quick overview of what Profiles are, and walk through specific use cases of how profiles can unlock large scale enterprise deployments and offer better protections to consumers.This work is currently a PR in review with Core Maintainers, expected to be completed before the conference.
