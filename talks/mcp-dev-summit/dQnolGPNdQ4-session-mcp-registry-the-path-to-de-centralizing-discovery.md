## Description

[Session] MCP Registry: The Path To (De-)Centralizing Discovery
🎤 Tadas Antanavicius, Co-Founder - PulseMCP
🎤 Toby Padilla, Principal Product Manager - GitHub

The MCP Registry is a centralized effort by the OSS MCP community to create a single source of truth for MCP server (and also eventually MCP client) implementations. But we know that centralization of what will be an enormous ecosystem is not the end of the road: so we've worked to design the registry in such a way that it supports, not sidesteps, a decentralized discovery process as well.

The Registry team's work on defining a `server.json` file paves the way to notions of server identity, .well-known schemes, and more. In this talk, we will cover some of the pivotal decisions and designs we made along the way, including server name scheming; installation instructions (and relation to DXT); all the various JSON and API schemas we are proposing.We will also demo the exact tools and workflows we expect MCP server maintainers to use to interact with the registry to maintain their metadata, and show examples of MCP client architectures that take advantage of this published metadata.We hope to have, at minimum, a technical preview ready for initial users by the time of this talk.
