## Description

The value of the voice-enabled internet represents a huge interaction paradigm shift but it's currently biased towards the western and developed world. Customers' lifetime value is much lower in emerging markets because these don't immediately represent a high return value for adoption. In addition any kind of voice agent is only as good as its training data. Katharina Borchert will show how in a few short months Mozilla was able to create the second largest publicly available voice data set through an open source decentralised approach and discuss the ways it is already being used by others.
