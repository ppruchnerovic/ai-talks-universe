## Description

Slides: https://drive.google.com/file/d/1bCoi2YsS_pnGRETQbi2TKU1rVDML8HOd/view?usp=sharing

At Ray Summit 2025, Nikita Vemuri and Mengjin Yan from Anyscale share the latest advancements in observability for Ray—designed to help developers debug, optimize, and understand distributed AI workloads with far greater clarity.

They begin by highlighting why contextual observability is critical: as Ray becomes the standard framework for distributed AI applications, users increasingly face the inherent complexity of large-scale, multi-node systems. Purpose-built tooling is essential for diagnosing issues such as resource bottlenecks, task failures, and memory pressure.

The speakers then introduce major new improvements to observability on Anyscale, including scalable and persistent dashboard views for Ray Core, Ray Train, and Ray Data. They walk through the architecture behind these dashboards and explain how they operate securely while keeping all data within the customer’s cloud environment.

Additionally, Nikita and Mengjin unveil the open-source Ray Export API, which allows users to persist, analyze, and integrate the same events shown in the Ray dashboard into their own monitoring or analytics systems.

A live demo showcases how these tools can be used to debug real-world issues—from out-of-memory errors to inefficient resource utilization—making Ray workloads more transparent, reliable, and easier to optimize than ever before.
