## Description

A cross-platform, cross-tool Ray on Kubernetes deployment

Ray recently added M1 ARM wheels, but building a heterogeneous Ray cluster on Kubernetes still has some rough edges, especially when you add the JVM to the mix. This talk will walk through how to cross-build different arch specific containers into combined images, deal with mixed Ubuntu versions, glibc versioning, and other things one generally hopes to avoid. At the end of this talk you will be able to deploy end-to-end Ray + Spark + Dask + Jupyter on a mixed architecture Kubernetes cluster, plus understand why you might not want to.
