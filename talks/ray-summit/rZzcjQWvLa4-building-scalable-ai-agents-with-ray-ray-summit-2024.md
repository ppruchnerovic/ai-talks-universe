## Description

In this Ray Summit 2024 presentation, Guyang Song and Qixiang Chen from Ant Group introduce Ragent, a novel framework for developing scalable AI agents. As AI agents gain traction in the developer community, the speakers address the crucial need for scalability, distribution, and production-ready solutions in agent applications.

Song and Chen argue that AI agents are fundamentally compute-type applications, requiring both rich functionality and reliable production capabilities, especially in multi-agent scenarios. They demonstrate how Ray's distributed computing strengths provide an ideal foundation for AI agent applications.

The talk showcases Ant Group's unified agent framework built on Ray, highlighting its key features:
- Distributed workflows and agents powered by Ray Core
- Agent deployment and real-time computing via Ray Serve
- Framework-agnostic ecosystem integration with popular tools like Langchain, AutoGen, and MetaGPT

This session offers valuable insights for developers and organizations looking to harness the power of AI agents at scale, presenting Ragent as a robust solution for the evolving landscape of AI applications.
