## Description

Scaling agentic reinforcement learning requires thousands of scheduling decisions per second, which creates unique infrastructure challenges.

At Ray Summit 2026, Poonam Lamba and Nisha Johnson from Google present a reference architecture using Ray, Kubernetes, and Google TPUs: how Ray enables sub-second scheduling and fault tolerance, how GKE time-slicing and smart inference scheduling maximize accelerator utilization, and how PyTorch and JAX stacks run on TPUs, closing with RL performance benchmarks and Google's product roadmap.

You'll leave with a reference architecture for RL at scale.
