## Description

Princeton University is pioneering a new approach to campus computational science, leveraging Ray to bridge the gap between traditional High Performance Computing (HPC) and the surging demand for Machine Learning (ML) capabilities. This session showcases how Ray is transforming academic research computing, offering a unified solution to the challenges of diverse workloads and expanding user bases.

Jack Brassil will guide attendees through Princeton's innovative pilot program, demonstrating Ray's versatility across three distinct computing environments: a shared campus research cluster, a federated multi-institutional infrastructure, and a hybrid campus-cloud setup using Google Cloud Platform. The lightning session highlights how Ray's unified framework is simplifying the computational landscape, reducing the learning curve for researchers, and optimizing IT resources.
