## Description

City Storage Systems (CSS) has revolutionized machine learning development with a cutting-edge platform built on Ray and Kubernetes. This session exposes the architecture behind CSS's accelerated ML capabilities, showcasing a system that redefines speed and efficiency in ML operations.

CSS engineers Santosh Jha and Ammar Alrashed reveal the core of their ML infrastructure: a seamless integration of Ray clusters, Metaflow, Daft, and Argo Workflows. Learn how this powerful combination tackles complex scaling challenges and streamlines development processes. For ML engineers and architects seeking to elevate their infrastructure, this session delivers crucial insights into building a next-generation ML platform.
