## Description

GammaLake is an open-source Point72 project that takes the functionality of Delta tables, adds more structure for timeseries data representations, and leverages Ray for efficient reads and writes.

At Ray Summit 2026, Todd Gaugler, Quant Developer at Point72 / Cubist, covers how the team implemented the project and how they use it on Anyscale at Cubist.
