## Description

At Ray Summit 2025, Benjamin Wagner from Firebolt Analytics shares a forward-looking exploration of how data infrastructure and model infrastructure are rapidly converging—and what this means for the next generation of GenAI-first data systems.

He begins by examining a core trend in modern AI workloads: training, retrieval, transformation, and serving are no longer separate phases. As GenAI applications demand tighter integration between these components, the same distributed compute patterns are emerging across traditionally distinct systems.

Benjamin dives into whether Pythonic distributed data frameworks and SQL engines are now on a path toward convergence. He highlights:

What SQL engines bring to GenAI-era pipelines—strong query optimization, predictable performance, and mature relational abstractions

What Python-native data frameworks contribute—flexibility, developer-friendly APIs, native integration with ML ecosystems, and seamless scaling on distributed compute platforms

Where the architectural boundaries are blurring, especially as teams use the same cluster to run ETL, vector search, training-adjacent processing, and model-serving workloads

The talk offers a balanced look at how ideas from both worlds are influencing the emerging class of AI-driven data systems—and what principles are likely to shape their future.

Attendees will gain a clear understanding of how distributed SQL engines and Python data frameworks may ultimately converge, and how to prepare for the unified data + ML infrastructure era ahead.
