## Description

Yi Wang from Motional presents how Ray has transformed their end-to-end machine learning pipeline for autonomous driving at Ray Summit 2024. The talk focuses on Motional's use of Ray to scale two critical workflows: training data preparation and model evaluation.

Wang discusses how Motional reduced data delivery latency from weeks to hours by scaling their training data preparation with Ray. This process involves refining data from multiple sensors, joining features, and performing data optimizations.

The presentation also covers Motional's achievement of a 100X speedup in model evaluation using Ray. Wang explains their in-house metric computation library built on Ray Data, which maximizes vectorization and allows for GPU deployment on heterogeneous Ray clusters.

Additionally, Wang introduces Motional's ML-based data curation solution, which dynamically selects the most valuable training data for each epoch. This approach integrates seamlessly with their training process, potentially improving model quality.

This session provides insights into practical applications of Ray in the autonomous driving industry, demonstrating its impact on large-scale ML workflows.
