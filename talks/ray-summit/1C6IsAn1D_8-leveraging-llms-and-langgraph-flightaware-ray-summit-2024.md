## Description

The fusion of large language models with structured workflows is revolutionizing how we interact with complex data systems. This lightning talk dives into FlightAware's innovative prototype that harnesses the power of LLMs and LangGraph to transform flight data retrieval.

Patrick Dolan takes attendees on a technical journey through the creation of an intelligent chatbot interface for flight searches. He explores the intricacies of using LangGraph to orchestrate LLM-powered workflows, demonstrating how this approach abstracts API calls and creates a more intuitive user experience. The presentation includes practical code samples, configuration insights, and a live demo, offering developers a blueprint for building sophisticated, AI-driven search interfaces in their own domains.
