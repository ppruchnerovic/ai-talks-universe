The Self-Healing Pipeline: How Dagger + LLMs Are Making Traditional CI/CD Obsolete - Vikram Vaswani, Independent

CI/CD pipelines are stuck in the past - static, fragile, and demanding constant upkeep. But what if your pipeline could think for itself? Imagine a system that diagnoses failures, suggests fixes, and continuously evolves with your codebase!

This talk discusses an innovative approach to building agentic software for CI/CD: combining Dagger’s programmable open source container engine with LLMs to create self-healing pipelines. It also demonstrates a live example of this approach in action, showing how an LLM can analyze pipeline failures and automatically generate fixes.

Whether you're a DevOps engineer tired of late night emergencies or a developer craving a seamless workflow, this session will show you how to build powerful, autonomous CI agents on an open ecosystem with complete visibility and cross-language capabilities.

Note: This talk includes a live demo of a self-healing pipeline in action!
