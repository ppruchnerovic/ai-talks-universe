Sponsored Session: OpenSearch and the Path to a Trillion-scale Vector Database - Vamshi Vijay Nakkirtha & Navneet Verma, OpenSearch Project

This presentation explores the evolution of OpenSearch to enable trillion-scale vector workloads. As organizations increasingly rely on vector search to deliver more powerful AI and machine learning applications, OpenSearch has achieved technological leaps to support these rapidly accelerating requirements. The talk will reveal the advancements that unlocked massive performance breakthroughs—including 3x increases in search throughput, 3x better disk storage utilization, and 10x faster index builds with Nvidia GPUs—to offer true trillion-scale operations and make it possible to manage massive vector datasets while maintaining fast response times.

The talk will also explore OpenSearch’s implementation of advanced quantization techniques that efficiently process high-dimensional vectors without loss of accuracy, and the cost optimizations they can provide. We’ll demonstrate how these efficiency gains make large-scale vector operations more economically viable for organizations of all sizes. Join us to learn how OpenSearch can help you deliver the next generation of AI-powered search applications.

Attendees will learn:
· Architecting trillion-scale vector search solutions
· Optimizing performance and storage efficiency
· Leveraging GPU acceleration and quantization
· Reducing infrastructure costs
· Avoiding common scaling pitfalls
