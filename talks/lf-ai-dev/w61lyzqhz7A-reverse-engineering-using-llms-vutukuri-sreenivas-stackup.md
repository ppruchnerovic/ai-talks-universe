Reverse Engineering Using LLMs - Vutukuri Sreenivas, Stackup

Modernizing legacy systems, often built on languages like COBOL,Fortran, orC, poses significant challenges due to their complexity and lack of documentation.Traditional reverse engineering methods are labor-intensive and frequently impractical, burdening enterprises with outdated, costly infrastructure. This session introduces an innovative approach using LLMs to streamline the analysis and translation of legacy code into contemporary languages such as Python or Java. Leveraging open-source tools like CodeLlama and Hugging Face’s Transformers, this method delivers rapid, accurate code conversion, significantly reducing modernization timelines. However, this capability introduces notable risks, including the potential exposure of proprietary logic, generation of undetected errors, and facilitating unauthorized code reuse. Through a practical demonstration converting a COBOL banking module to Python, we showcase the efficiency and precision of LLM-driven reverse engineering alongside its vulnerabilities. This session proposes open-source mechanisms to enforce ethical usage, ensuring that the transformative potential of LLMs is harnessed responsibly within the modernization process.
