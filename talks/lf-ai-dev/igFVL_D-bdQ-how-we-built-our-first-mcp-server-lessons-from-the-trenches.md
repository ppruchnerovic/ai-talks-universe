How We Built Our First MCP Server: Lessons From the Trenches at Hud - May Walter, Hud

Building a protocol-based server from scratch is never just about code—it’s about discovery, mistakes, iteration, and ultimately, crafting something meaningful from raw ideas. In this talk, we’ll share the behind-the-scenes story of how we at Hud built our first MCP (Model Context Protocol) server—what MCP is (and what it’s not), why we needed it, and how we got from an idea to a working production system.

You’ll hear the real-world challenges we faced, how we leaned on tools like Anthropic's SDK and debugger, the principles that guided our server design, and the hard-earned lessons about context, security, and rule-based execution. If you’re hungry to build, or just curious what it takes to turn a protocol into a usable infrastructure, this session is for you. Come for the architecture, stay for the battle stories.
