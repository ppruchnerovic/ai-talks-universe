Arctic Inference: Open-Source LLM Inference Optimizations at Snowflake - Aurick Qiao, Snowflake

Arctic Inference is an open-source vLLM plugin from Snowflake AI Research, offering a comprehensive set of optimizations that accelerate large language model (LLM) inference. It introduces novel techniques such as SwiftKV, Ulysses, Shift Parallelism, Suffix Decoding, and Arctic Speculator to deliver substantial improvements in key performance metrics. For practical workloads, Arctic Inference achieves up to 3.4x faster time-to-first-token (TTFT), 1.7x higher throughput, and 1.75x faster time-per-output-token (TPOT) compared to existing open-source solutions. Its pluggable design ensures seamless integration into existing vLLM deployments, equipping the open-source community with powerful tools to enhance inference efficiency and resource utilization. This talk will delve into the technical innovations, performance gains, and open-source usage of the Arctic Inference stack.
