## Description

Keynote: Build Accelerated LLM Applications with Open Source Tools from NVIDIA - Ankit Patel, Sr. Director of Developer Marketing, NVIDIA

NVIDIA has released nearly 500 open-source projects under a permissive license and actively participates in over a dozen consortiums and foundations like the Linux Foundation and PyTorch Foundation. Generative AI is transforming industries, but many developers struggle to find tools to help them adopt state-of-the-art language models. In this talk, Ankit Patel, Senior Director at NVIDIA will share open-source tools and cutting-edge research from NVIDIA that developers can leverage in their own AI projects.
