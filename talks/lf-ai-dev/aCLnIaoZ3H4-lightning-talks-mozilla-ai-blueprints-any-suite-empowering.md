Lightning Talks: Mozilla.ai Blueprints & any-suite - Empowering Devs to Build with Open-Source AI - Stefan French, Mozilla.ai

In this presentation, we would like to introduce our open-source AI projects:  Blueprints and the any-suite.

Blueprints are customizable workflows for building AI applications using open-source tools and models. They help developers, especially those new to AI or without advanced expertise, adopt open-source AI with confidence.
In this session, we will introduce the motivations for starting this project, what Blueprints are, and the Blueprints we've been developing with the community.
To find out more about Blueprints, visit: https://blueprints.mozilla.ai/

The any-suite is an open-source initiative that aims to help you innovate faster and avoid vendor lock-in. We'll present two open-source libraries:
- any-agent (https://github.com/mozilla-ai/any-agent): A single interface to use and evaluate different agent frameworks.
- any-llm (https://github.com/mozilla-ai/any-llm): A single interface to use different llm providers
