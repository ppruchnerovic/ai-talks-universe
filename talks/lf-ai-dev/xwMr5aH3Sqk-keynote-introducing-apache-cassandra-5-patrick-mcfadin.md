## Description

Keynote: Introducing Apache Cassandra® 5! - Patrick McFadin, VP, Apache Cassandra and Developer Relations, DataStax; Scott Andreas, Engineering Manager, Apple, Inc. & Ekaterina Dimitrova, Apache Cassandra Committer & Software Engineer, DataStax

Cassandra 4 set the bar for how databases measure stability and reliability. Cassandra 5 builds on that foundation with some of the most important changes ever introduced to Cassandra. Join us as we introduce the next version of Apache Cassandra that will radically change the way you use it. The coming years will be some of the most exciting for Cassandra users and we’ll tell you all about why.
