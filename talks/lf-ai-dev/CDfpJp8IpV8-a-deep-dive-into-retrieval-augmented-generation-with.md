## Description

A Deep Dive Into Retrieval-Augmented Generation with LlamaIndex - Laurie Voss, LlamaIndex

LlamaIndex is a python and JavaScript framework for loading your data from any data source, indexing it for semantic retrieval, and delivering it to LLMs to answer questions about your data, extract insights from your knowledge base, bring structure to unstructured data and more. In this session we'll dive into how to use LlamaIndex from first principles to advanced RAG techniques.
