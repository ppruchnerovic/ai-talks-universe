Using Generative AI to Develop Open Source Code - Practical Guidance for Managing Legal, Copyright, & Licensing Risks - Joanna Lee, Cloud Native Computing Foundation

Using Generative AI to develop open source code - practical guidance for managing legal, copyright, & licensing risks

How can open source software projects responsibly allow contributions generated using AI, and what do developers need to know about contributing AI-generated content to an OSS project? Join us for this talk to learn about legal risks and challenges associated with AI, including pending lawsuits and legislation, and how this impacts use of AI in software development. We'll provide practical guidance and a set of best practices for navigating this complex and ever-changing landscape.
