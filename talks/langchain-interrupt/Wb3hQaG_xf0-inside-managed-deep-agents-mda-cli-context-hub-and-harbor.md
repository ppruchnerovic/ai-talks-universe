## Description

Victor Moreira, Product Manager at LangChain, explains what it takes to move a deep agent from a local prototype into production, and how Managed Deep Agents, now in public beta, couples the Deep Agents harness with LangSmith infrastructure so your team can focus on the business logic. Using LangChain's internal GTM agent as the example, he shows how an agent is scaffolded into one project structure with the mda CLI, run locally in LangSmith Studio, and deployed on LangSmith Deployment, then covers who can call the agent, when it should use user or agent-scoped credentials, how a run can wait for a user to authorize access and pick up where it left off, which memories and credentials it can use in a Slack DM versus a shared channel, versioned context in LangSmith Context Hub, and Harbor evals that a coding agent helps you set up. He also shares how Madrigal built a domain-specific harness by breaking its researchers' expertise into skills, built-in web search through a partnership with Parallel, the design partners Kyth and Consensus, and recent additions including HTTP channels, agent-created schedules, and per-run config for dynamic agents.

This session was captured at Interrupt London, the agent conference by LangChain.
