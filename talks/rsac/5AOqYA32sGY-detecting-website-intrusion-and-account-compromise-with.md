## Description

Presenter: Robin Franklin Guha, Security Engineer, Meta

As more applications become externalized to open environments, the need for a system capable of detecting anomalous activities pre and post-login has become imperative. This session will discuss the approach to detecting misuse or intrusions through machine learning. Covering data, feature engineering, ensemble modeling approach, and integration in a real-time environment.
