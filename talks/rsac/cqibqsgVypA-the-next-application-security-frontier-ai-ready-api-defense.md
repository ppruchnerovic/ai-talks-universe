## Description

Presenters:
Charles Herrin, F5
Byron McNaught, F5

App modernization efforts have led to the rise of API-based systems and a plethora of interconnections across data center, multicloud, and edge environments. Learn how Generative AI will further API complexity and enhance attack sophistication and democratization—necessitating end-to-end protection from code to runtime and the use of LLM-based security by defenders.
