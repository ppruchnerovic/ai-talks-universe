## Description

Session 1: A Checklist for CISOs

This session will cover where to start and discuss the guidance for CISOs published in the OWASP for LLMs CISO Checklist, which includes contributions from a cross-section of security experts.

Speaker:
Sandy Dunn, Serial CISO, Adjunct Professor, Boise State

Session 2: Introducing a Solutions Framework for LLMs, GenAI Security

This session will introduce a new draft framework, published by the project, to help decision makers with categories for security solutions aligned to secure against the LLMs Top 10 Across the LLM application lifecycle.

Speaker:
Scott Clinton, OWASP T10 for LLM Industry Lead

Session 3: Creating and Detecting Machine Learning Model Serialization Attacks

Machine Learning (ML) model hubs are making supply chain attacks possible through ML models. This session will demonstrate how ML models can have malicious code embedded in them during serialization (saving), called Model Serialization Attack (MSA). Attendees will see the step-by-step process to become proficient at both crafting their own MSA and safeguarding against MSA.

Speakers:
Mehrin Kiani, Machine Learning Scientist, Protect AI and Sam Washko, Software Engineer, Protect AI
