## Description

Speaker: Kyler Middleton, Sr Principal Software Engineer, Veradigm

Learn how to develop and implement a secure generative Al Slack bot while maintaining strict privacy standards and security requirements. We'll explore the evolution from a basic bot architecture to a fully featured solution, while applying data protection controls that enable secure innovation. We will demonstrate how Retrieval Augmented Generation (RAG) enhances both functionality and security by constraining responses to approved, segregated knowledge bases. We will also dive into protecting the data in the RAG engines. Through live demos, we'll showcase progressive feature additions and security controls. We will conclude with practical insights from our experience deploying generative Al in healthcare's regulated environment.
