## Description

Presenter: Prasad Purnaye, Assistant Professor, Dr Vishwanath Karad MIT World Peace University, India

Increasing security incidences in cloud demands vigilant cloud platforms. We propose a novel approach in cloud implementation for detection of potential evidence data using machine learning and AI agent. The proposed AI agent is hypervisor-implementation agnostic and helps to detect and preserve evidence in the form of memory dumps which then can then be analyzed for malwares and other evidences.
