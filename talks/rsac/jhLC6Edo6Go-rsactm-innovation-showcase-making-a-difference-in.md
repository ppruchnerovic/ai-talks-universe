## Description

Presenters:
Jenny Brock, Sr. Manager Innovation Programs, RSAC
Mark Kraynak, Partner, Acrew Capital
Jim Manico, Founder, Manicode Security
Elad Menahem, VP of Research, Cato Networks

Join us at the RSAC Innovation Showcase – a virtual program designed to highlight innovation in cybersecurity. On March 27, we focus on application security.

The last mile of protection, actually remediating issues, has always been the hardest in application security. This showcase will focus on innovative approaches to remediation in application security. Experts from Manicode Security and Cato Networks will explore four key topics:

The limitations of traditional application security approaches and the need for solutions that can do more than find issues
How AI and machine learning are transforming vulnerability detection and code remediation
How runtime-based detection and remediation enhance application security
The benefits and challenges of using automated code remediation to address security vulnerabilities

The panel then hears from two up and coming companies in the application security space.
