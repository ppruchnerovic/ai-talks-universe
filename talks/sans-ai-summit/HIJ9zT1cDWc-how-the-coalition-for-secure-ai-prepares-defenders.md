## Description

How the Coalition for Secure AI (CoSAI) prepares defenders for AI (and how you can contribute)

🎙️ Jason Garman, Principal Security Solutions Architect, AWS
📍 Presented at SANS AI Cybersecurity Summit 2026

The Coalition for Secure AI (CoSAI) brings together industry and security experts to improve how AI systems are built and deployed. This talk outlines CoSAI’s focus areas, including software supply chain security for AI, secure design patterns, and guidance for applying security best practices across the AI lifecycle.

Learn how these efforts translate into real-world collaboration—and how practitioners can contribute to advancing secure AI development.
