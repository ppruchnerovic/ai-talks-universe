## Description

Prototyping an AI agent is faster than ever, but transitioning that prototype into a secure, scalable, and observable production application is where the real engineering begins. In this interactive workshop, Lisa Shen moves beyond “Day 1” demos to enterprise-grade AI deployment on Google Cloud’s serverless platform.

The hands-on labs cover building and orchestrating an AI assistant with Google’s Agent Development Kit and Firestore, safely executing untrusted agent-generated code in Cloud Run Sandboxes, and running low-latency open-model inference on Cloud Run GPUs.
