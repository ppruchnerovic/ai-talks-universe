## Description

AI is not just changing how fast software is written. It is changing how software is produced.  Engineering organizations are assembling agent-powered systems that write code, review pull requests, validate releases, deploy changes, and continuously improve production software around the clock, without human hands on every step. The promise of faster software delivery and continuous optimization is real. But as delivery becomes more autonomous, a new and more urgent problem surfaces: how do you stay in control of systems that never stop evolving? In this session, Jonathan Nolen, Chief Product Officer at LaunchDarkly, makes the case that the defining challenge of the AI era is not generating code — it is controlling autonomous systems in production. Traditional pre-production controls and the standard playbook of detect, fix, redeploy break down for agents that don't fail like traditional software. They drift. You can no longer catch issues before production. You have to control production. Jonathan will share what LaunchDarkly has learned building its own AI software factory — including what happened when coding agents met its oldest, most complex production code — and why every autonomous delivery system requires a closed control loop: observation, decision-making, intervention, and feedback, all running at runtime without a deploy cycle. Attendees will leave with a practical framework for building AI software factories that are genuinely fast and safe, and a clear answer to the question every engineering leader is now facing: when agents are doing the work, who stays in charge?
