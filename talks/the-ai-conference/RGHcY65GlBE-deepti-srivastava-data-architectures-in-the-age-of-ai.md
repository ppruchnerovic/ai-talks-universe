## Description

Every major computing shift has reshaped the software stack, but one assumption held across all of them: humans were the primary consumers of software and software-generated artifacts. AI agents break this assumption. An autonomous agent determines at runtime what data it needs, interprets it, and takes actions, with no human in the loop to catch misinterpretations. In this new era, bolting AI features onto existing app-centric, or warehouse- and lakehouse-centric stacks just isn't enough to meet the requirements of these agents. The data layer must be rethought from first principles to enable agents to run critical decision-making workflows using structured operational data, reliably and with confidence. In this talk, I’ll discuss three imperative changes – automatically generated and maintained business semantics, federation as the default retrieval path, and governance – and show how our new agent-native data platform incorporates these principles.
