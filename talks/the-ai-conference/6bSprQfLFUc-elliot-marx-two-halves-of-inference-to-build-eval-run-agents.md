## Description

The AI stack is changing, but whether you’re building an agent or fine-tuning an LLM, the same problem remains: you need the right context to build, evaluate, and deploy reliable AI systems. Many failures that look like model or prompt problems are actually context problems, with agents making confident decisions that are inaccurate or based on stale data. Evals have the same context problem. If you evaluate an agent or fine-tuned LLM against non-realistic or incomplete context, you can’t know how it will perform on the tasks and data it will encounter in production. In this hands-on presentation, Chalk Co-Founder Elliot Marx will show how a unified context layer solves both. A context layer is the missing decision infrastructure to give live, governed data to agents and models at inference time - querying your data where it already lives, so every AI decision gets the real-time context it needs. The same system powers testing and evals, so you can prove that your agent is production-ready. With a context layer, you turn data that helps AI understand the world it’s acting on into agent context at the moment of inference - and run the full AI decision system. He’ll demonstrate the full workflow across use cases, from fine-tuning an open-weight LLM and serving it in your own cloud to testing an agent in a simulated time-bound environment with knowledge-cutoff data and tool access, evaluating against real-world tasks, and deploying in a sandbox. Finally, Elliot will share practical lessons from building context and infrastructure for ML and agentic systems used by companies like Whatnot, Turo, and Mission Lane, and a framework for making context and evals a core part of how you build AI.
