## Description

Computer-use agents, AI systems that interact directly with browsers and graphical user interfaces, have rapidly moved from impressive demos to early production deployments. However, operating these agents reliably in real environments introduces a class of challenges that are often underestimated or ignored in early implementations. This talk presents a practical, experience-driven examination of computer-use agents deployed in live business workflows. It traces the evolution from low-level browser control approaches (e.g., DOM- and vision-based interaction) to higher-level abstractions and orchestration layers, highlighting the architectural tradeoffs that emerged only under real-world load, UI drift, and partial system failures. Key topics include: Common failure modes in computer-use agents, including UI volatility, non-deterministic model behavior, timing and synchronization issues, and brittle task decomposition Reliability strategies such as constrained action spaces, verification loops, retries and recovery, fallback paths, and human-in-the-loop controls Observability gaps unique to UI-driven agents and practical techniques for debugging, monitoring, and post-incident analysis Latency, cost, and throughput tradeoffs when scaling computer-use agents beyond isolated tasks Security, compliance, and blast-radius considerations when agents operate on live systems The talk also challenges the assumption that increased autonomy always leads to better outcomes, and proposes a more pragmatic model for deploying computer-use agents as constrained, inspectable systems rather than fully autonomous actors. Attendees will leave with a concrete mental model for evaluating when computer-use agents are appropriate, architectural patterns that improve reliability, and a set of anti-patterns to avoid when moving from demo to production.
