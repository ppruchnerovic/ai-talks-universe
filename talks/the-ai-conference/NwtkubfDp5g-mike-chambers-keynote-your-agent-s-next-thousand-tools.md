## Description

Every agent framework gives you a loop. What actually matters is what's on the other end of the tool call. In this keynote, Mike Chambers traces the line from software agents to physical ones, same code, same patterns, and shows why the developers who build the next thousand tools will matter more than those who build the next agent framework.
