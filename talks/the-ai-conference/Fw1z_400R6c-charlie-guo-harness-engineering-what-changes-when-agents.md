## Description

As coding agents get better, the limiting factor is no longer just model capability. It is whether your team has built the right harness around the model: the codebase structure, task boundaries, feedback loops, evals, tests, review processes, and operational guardrails that let agents work effectively over longer time horizons. This talk will cover the emerging shift from pair programming with AI to agentic delegation. It will examine what kinds of engineering work agents handle well today, where they still break down, and what changes teams are making to get useful results in practice. Topics will include how to make a codebase more agent-friendly, how to scope tasks so agents do not thrash, how to use tests and evals as control systems, and how human review changes when the AI is doing more of the implementation work. Attendees will leave with a practical framework for thinking about “harness engineering,” along with concrete patterns they can apply to code review, task design, evals, and team workflows as AI systems take on a larger share of software development.
