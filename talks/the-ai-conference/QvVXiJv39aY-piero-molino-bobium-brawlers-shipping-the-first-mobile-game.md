## Description

Most AI applications today rely on cloud inference, which introduces latency, privacy concerns, operational cost, and limits real-time interactivity. In games, these constraints are especially problematic: player experiences must respond instantly and scale to millions of users without bankrupting developers. In this talk, we present the architecture and production lessons behind Bobium Brawlers, the first mobile game that runs generative AI entirely on device. The system powers real-time creature and gameplay content generation without a deluge of cloud API calls. We will walk through the design of a production system capable of running generative models locally on consumer devices, including: Designing gameplay systems around local LLM and generative model inference Techniques for model compression, optimization, and quality Integrating AI generation directly into core gameplay loops rather than cosmetic features Handling latency, guardrails and reliability when inference happens inside the game Lessons learned from deploying the system to real players and observing emergent gameplay We will also discuss how AI-native design changes traditional game development workflows, including content pipelines, player creativity systems, and balancing mechanics when AI becomes part of the game itself. Attendees will walk away with practical insights into shipping AI-first interactive systems on constrained devices, including architectural patterns, optimization strategies, and lessons from deploying generative AI in a live product.
