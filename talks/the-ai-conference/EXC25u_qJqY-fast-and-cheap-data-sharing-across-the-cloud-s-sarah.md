## Description

Fast And Cheap Data Sharing Across The Cloud(S)

We present Skyplane, an open-source project from UC Berkeley for blazing fast object store transfers within and between clouds.

Skyplane is faster and lower-cost than existing data transfer systems with universal support across clouds. Using research into overlay networking, Skyplane transfers data up to 110x faster than comparable systems while reducing egress costs by up to 6x. For a typical user, this reduces the time to move large datasets from a night to a single coffee break.
