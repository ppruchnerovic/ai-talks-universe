## Description

Tillman Elser, Senior Engineering Manager, Sentry

You’re Not Using Embeddings Enough

Text embeddings had their moment in the sun when RAG was first popularized, but they’ve (rightfully) fallen by the wayside as developers have identified more efficient ways to retrieve context for AI agents. However, there are so many opportunities to use this magical data structure to improve the quality of your products in more direct ways!  Ideal for practitioners interested to learn how they can apply embeddings in an actual production setting, this session will include a technical overview of the system that Sentry has developed to dramatically improve the quality and accuracy of its Issue Feed.
