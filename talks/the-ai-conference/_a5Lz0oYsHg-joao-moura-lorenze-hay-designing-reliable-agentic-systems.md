## Description

Most agents don’t fail in production because the model is bad. They fail because the system around the model has no guardrails, no structure, and no way to see what’s happening. In this session, João Moura and Lorenze Hay make the case that reliability is an engineering problem, not a prompting one.

They walk through the harness every production agent needs: control flow, a plan-execute-observe-replan design, and observability teams can act on. The session uses real production failures and a benchmark where the same model improved from 20% to more than 60% by changing the surrounding system, then closes with a pre-deployment checklist.
