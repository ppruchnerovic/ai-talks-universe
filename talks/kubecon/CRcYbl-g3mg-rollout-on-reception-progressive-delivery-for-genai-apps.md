Rollout on Reception: Progressive Delivery for GenAI Apps Using Real-Time User Feedback - Thomas Vitale, Systemic & Whitney Lee, Data Dog

When AI-generated text goes straight to users, how do you know whether it's good? Not error rate, not latency, not health checks, but a new dimension: user feedback. So what if that feedback could directly control how new app versions roll out? Not through A/B test dashboards, but through real-time GenAI evaluation?

In this session, Whitney and Thomas demo a cloud-native platform where Knative Services and Flagger drive progressive delivery using live GenAI evaluation results to route traffic. They show how to integrate cloud native apps with inference services and how to instrument everything with OpenTelemetry following the Generative AI Semantic Conventions. Then user satisfaction controls whether a new version of an app gets rolled out.
And for this talk, YOU'RE the user. You'll evaluate competing app versions live, upvote the best responses, and watch as your feedback directly shifts traffic to the winner in real time.

Join and learn how to pit prompt against prompt or model against model and let your users decide what outcome they truly like best.
