Dapr in the AI Era: Orchestrating Complex Multi-agent Workflows With Automatic Recovery - Yaron Schneider, Diagrid

In this session we'll learn how Dapr enables agent frameworks like OpenAI agents, AWS Strands, CrewAI and LangGraph to run reliably in the face of network errors, full cluster shutdowns and even complete cloud outages. Dapr's workflow, pub/sub and state APIs can be integrated as first-class primitives into the agent runtime of your choice, enabling Ops teams to make their AI systems ready for production and multi-cloud architectures.
