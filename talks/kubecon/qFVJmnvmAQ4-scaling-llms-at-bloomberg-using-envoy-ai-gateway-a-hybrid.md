Scaling LLMs at Bloomberg Using Envoy AI Gateway: A Hybrid Cloud Approach - Xiaolin Lin & Aaron Choo, Bloomberg

The rapid rise of Generative AI (GenAI) and large language models (LLMs) is transforming industries - but financial services face unique challenges when deploying these technologies. Strict data governance, stringent security requirements, and the need to balance on-prem models and cloud-based LLMs demand an infrastructure that is both performant and resilient.

In this talk, we’ll share how Bloomberg has taken Envoy AI Gateway - a CNCF-hosted open source project - from concept to production as a central piece of our GenAI platform’s tech stack. We’ll walk through how we utilized Envoy AI Gateway’s features, highlighting the performance improvements, scalability benefits, and security enhancements we gained as a result. We’ll also discuss how we’re using advanced features such as secure authentication, intelligent model routing, and token-based rate limiting to safely and efficiently serve real-time GenAI traffic for financial applications.
