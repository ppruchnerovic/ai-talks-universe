## Description

🛠️🛡️ Securing Agentic Applications: Practical Mitigations + Interactive Guide Launch
This session from the OWASP GenAI Security Project Virtual Summit (October 2025) introduces the Securing Agentic Applications workstream—created in response to community demand for guidance that goes beyond theory. Venita Narajala (OWASP contributor) and Idan Abler (AI security researcher) walk through a hands-on, actionable guide that complements the OWASP Agentic AI Threat & Mitigation Guide, using the same threat landscape but adding real tools, implementation steps, and deployable countermeasures.

The methodology is built around four dimensions:

Development lifecycle (design → build → runtime controls)

Key components (LLM, memory, planning, tools/MCP)

Architectures (single agent, orchestrated multi-agent, peer-to-peer/A2A & ACP)

Skills/operational environment (RAG, web/PC use, IoT, sensors)

Includes concrete case studies (Slack agent; orchestrator assistant across calendar/drive/slack; peer-to-peer agent trust) with mitigations like schema enforcement, prompt hardening, memory validation, tool governance, and anomaly detection with logging/traceability into SIEM/SOC workflows.

🎉 Surprise: they launch an interactive Agentic Security App to explore threats, architectures, and mitigations—plus mappings to OWASP AISVS and NIST AI RMF (open source and community-contributable).
