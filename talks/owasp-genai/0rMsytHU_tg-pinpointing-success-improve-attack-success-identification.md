## Description

🧪 Evaluating AI Red Teaming Success for GenAI Systems
This session from the OWASP GenAI Security Project Virtual Summit (October 2025) dives into one of the hardest problems in GenAI security: how to accurately measure attack success during AI red teaming.

Researchers from Palo Alto Networks explain why flawed evaluators lead to flawed red teaming, and introduce a practical framework using ground truth, ensemble “expert” judges, and meta-evaluators to assess jailbreaks, prompt injection, misinformation, and dual-use attacks. Learn how better evaluation improves detection accuracy, refines safety guidelines, and strengthens scalable AI security testing.
