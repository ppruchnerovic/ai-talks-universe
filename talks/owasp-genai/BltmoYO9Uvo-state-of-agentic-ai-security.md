## Description

🔐 The State of Agentic AI Security:
This session from the OWASP GenAI Security Project Virtual Summit (October 2025) explores real-world security risks already emerging from Agentic AI in enterprise environments. OWASP contributors share firsthand examples from Fortune 500 companies, covering prompt injection, context poisoning, insider data exposure, non-deterministic AI behavior, and multi-agent system risk.

Learn why traditional security models fail for AI agents, how internal and client-facing agents expand the attack surface, and what evolving global regulations mean for AI governance and compliance.
