## Description

🧨🛡️ Words as Weapons: Defending GenAI Agents & Apps from Prompt Injection
This session from the OWASP GenAI Security Project Virtual Summit (October 2025) dives deep into prompt injection attacks—why they’re the #1 GenAI risk and how to defend agentic apps in practice. Rob Trusell (Pangia, now CrowdStrike) shares lessons learned from large-scale prompt injection research (including a community “escape room” challenge) and explains how architecture choices (RAG, tools/MCP, internal vs customer-facing) shape your threat model.

You’ll learn the major prompt injection vectors—direct vs indirect (hidden text in PDFs, poisoned web pages), plus supply chain, API/interface, training data, resource abuse, and insider threats. The talk covers a taxonomy of 180+ techniques grouped into overt, indirect, social-cognitive, and evasive attacks (e.g., multi-step “deceptive delight,” Base64/Unicode evasion, role-play, “legal” coercion).

Mitigations focus on input/output guardrails, data sanitization, source/tool trust mapping, robust system prompts, monitoring + immutable audit logs, and least-privilege agent access. Also covers deployment options: SDK/API guardrails, AI gateways, and MCP proxies/servers for tool-level protection.
