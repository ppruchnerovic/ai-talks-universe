# Malicious AI Agent Skills Exposed: Don't Tell The User | Ep 19

## Description

What happens when the skills that make AI agents useful become the way attackers get in?
Rachel James & Dr. Bryan Nakayama talk with Yi Liu (Common Defense, Nanyang Technological University) about his research on malicious agent skills in the wild.

What we cover:
• How the team gathered nearly 100,000 skills and confirmed 157 as malicious
• The email skill that secretly copied an attacker and told the agent not to tell the user
• Why prompt injection shows up in at least a third of malicious skills
• How benign scripts and benign instructions combine into a harmful whole
• Second-order attacks that plant triggers in agent memory
• The skills factory: tracing malicious skills back to a single GitHub account
• Why vibe coding makes these skills easy to build
• Whether the landscape is getting better or worse
• No-click root access through agent harness configuration
• How to vet a skill before you install it
Key Takeaway: A skill runs with the same permissions as the user, and the combination of script
and natural language is hard to detect. Stick to official sources and stay skeptical of everything
else.
