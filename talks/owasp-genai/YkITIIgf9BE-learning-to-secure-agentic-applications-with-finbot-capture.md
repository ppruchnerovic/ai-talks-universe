## Description

🎯🛡️ OWASP Finnbot CTF: Hacking Agentic AI with Goal Manipulation (and How to Defend It)
This session from the OWASP GenAI Security Project Virtual Summit (October 2025) introduces the OWASP Finnbot Capture the Flag—a new hands-on workstream under the Agentic AI Security Initiative. Helen and Alli present Finnbot, a realistic finance assistant agent that processes invoices and executes business workflows using an LLM plus tools (approve/reject/request review/detect fraud/get invoice details).

The first challenge set focuses on goal manipulation—a core threat from the OWASP Agentic AI Threats & Mitigations Guide. Players learn how conflicting objectives (e.g., “pay vendors fast” vs “prevent fraud / enforce approval thresholds”) create exploitable gray areas, especially under non-determinism, limited traceability, and intent-breaking via untrusted inputs/tools.

The demo walks through three CTF tiers (easy → hard): crafting invoice text to push Finnbot to approve payments—even above a manual-review threshold—while avoiding prompt-injection detection. The session closes with practical defenses: decision trace logging, boundary/threshold enforcement, goal-alignment checks, continuous evals, and behavioral auditing, plus a roadmap for upcoming modules around tools/execution and MCP-connected scenarios.
