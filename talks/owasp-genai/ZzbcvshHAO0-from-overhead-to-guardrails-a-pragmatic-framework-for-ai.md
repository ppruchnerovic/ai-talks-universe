## Description

🛡️ From Overhead to Guardrails: Pragmatic AI Security at Scale
This session from the OWASP GenAI Security Project Virtual Summit (October 2025) delivers a practical framework for securing AI across many enterprise systems—not just one “hero” model. Klaus (Security Architect, AXA Switzerland) explains how AI risk has shifted from classic ML concerns (compute hijacking, training data theft) to modern LLM/agent risks like prompt injection, data exfiltration, non-deterministic actions, and workflow/fraud impact (including document-based injections).

Instead of drowning engineers in papers, the talk advocates clear implementation roads by scenario:
✅ ML pipelines • ✅ RAG/LLM chatbots • ✅ AI coding tools • 🔴 multi-agent/planning (emerging)
Plus sourcing risks: supply chain, SaaS integration, identity/API controls, sharing/exfiltration features, and 4th-party tool/MCP connections.

Key takeaway: design for scalability—centralize guardrails, define risk appetite per scenario, and apply consistent controls (block, mitigate, or govern/monitor).
