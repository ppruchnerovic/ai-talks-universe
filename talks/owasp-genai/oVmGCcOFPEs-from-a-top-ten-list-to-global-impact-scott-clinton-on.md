## Description

Welcome to the Gen AI Security Inside Track Podcast—the show diving deep into the world-leading resource for generative AI security.
In this inaugural episode, Scott Clinton, co-founder and co-chair, shares how the OWASP Gen AI Security Project went from a single "Top 10 LLM Risks" list in 2023 to a community of 30,000+ members shaping the future of AI security.

In This Episode:
■ The "happy accident" that sparked a global movement
■ Why community-driven security matters more than ever
■ 10 working initiatives covering the entire AI security landscape
■Partnerships with NIST, Turing Institute, Stanford, Oxford & more
■ Practitioner-focused guidance: incident response, red teaming, agent security
■ What's launching next: Red Teaming Guide v2, Agent Security deep-dives, Council for Agent Security

Key Takeaway:
When AI moves this fast, traditional standards bodies can't keep pace. The answer is rapid execution, shared knowledge, and community effort.

Hosted by Project Co-Founder Scott Clinton
