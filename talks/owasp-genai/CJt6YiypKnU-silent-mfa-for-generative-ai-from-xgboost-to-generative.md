## Description

🔐🤖 Silent MFA with Generative AI: Frictionless, Continuous Authentication
This session from the OWASP GenAI Security Project Virtual Summit (October 2025) features Dr. Benjamin Manning (Georgia Tech) presenting a new approach to MFA that reduces user friction while improving security: Silent MFA—passive, “in-the-background” authentication using behavioral signals and GenAI.

Building on years of research in behavioral biometrics (e.g., keystroke dynamics), the talk explains why traditional MFA is painful and often a single checkpoint (“front door” only). Silent MFA aims to verify identity more continuously using signals like typing patterns, device metadata, context, and writing style, with GenAI generating synthetic behavior profiles and adversarial user simulations to stress-test the framework.

Ben walks through the end-to-end pipeline (synthetic data generation → embeddings → LoRA fine-tuning on foundational models → decision layer) and evaluation metrics (accuracy, FAR/FRR, user friction index, adversarial robustness). Early results are promising: ~97% accuracy on the Silent MFA approach with low friction, but adversarial robustness remains the hardest challenge—highlighting the need for stronger defenses and real-world deployment testing.
