# GenAI Project | Insights from the GenAI Security Project - Threats & Adoption

**Scott Clinton**

`OWASP GenAI Security Project` · `OWASP GenAI Security` · `2026` · `30 min`

[Watch the recording](https://www.youtube.com/watch?v=sfpZm6lXU5E) · [Conference site](https://genai.owasp.org/)

## Description

This session will explore the latest threats impacting generative AI systems, autonomous agents, and enterprise AI adoption — including prompt injection, data leakage, insecure agent orchestration, model abuse, and emerging governance challenges. This will also highlight the newest research, frameworks, and guidance published by the project, providing actionable insights security practitioners can apply immediately and how they can become contributors to the project.
Attendees will gain a clearer understanding of how organizations are securing GenAI deployments today, where the threat landscape is heading, and how the OWASP community is helping define practical security standards for the next generation of AI-enabled applications and agents.

Key Takeaways
• Understand the latest GenAI and agentic AI security threats
• Learn practical approaches for securing AI-enabled applications and workflows
• Explore recent research and guidance from the OWASP GenAI Security Project
• Identify actionable controls and best practices organizations can implement today
• Gain insight into the future of AI security governance and adoption strategies
• Learn how to contribute and become a member of the community.
