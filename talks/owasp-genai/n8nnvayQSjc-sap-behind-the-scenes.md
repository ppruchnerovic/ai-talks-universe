## Description

🏗️🛡️ Building AI Security Capabilities in the Enterprise: SAP’s Practical Journey with OWASP
This session from the OWASP GenAI Security Project Virtual Summit (October 2025) features SAP security leaders Manishia (Principal Security Architect), Jim Roan (Head of AppSec & Automation), and Aay (Principal Security Architect) sharing how they turned AI security from theory into repeatable engineering practice—and how OWASP guidance helped accelerate it.

They walk through SAP’s path from consolidating fragmented security telemetry into a security data lake (ingesting logs from CSPM, vuln scanners, AppSec tools, and internal enrichment sources) to adding dashboards and LLM-powered natural-language querying for executives and engineers. Key challenges: data quality, schema normalization across tools, prioritization, and making findings actionable for developer teams.

The panel covers how SAP operationalized guardrails using internal platforms (model onboarding/vetting, secure access patterns, AI posture management) and how OWASP resources—Top 10 for LLMs, AIVSS, and emerging agentic risks (MCP, A2A, tool calling)—informed threat modeling, secure development checklists, and internal enablement for developers. They close with a clear theme: AI can both expand the attack surface and scale security workflows (IR log analysis, DLP, AppSec automation)—but only if governance, authZ/authN, and continuous monitoring keep pace.
