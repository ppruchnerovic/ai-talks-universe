## Description

🛡️📊 Data Defense in the Age of AI: Securing LLMs in Agentic Applications
This session from the OWASP GenAI Security Project Virtual Summit (October 2025) features Scott Clinton (GenAI Security Project co-chair) and Emanuel Glam Jr. (Data Security Initiative Lead) on why data security is the core battleground for GenAI—especially as LLMs move into agentic workflows.

They explain how AI breaks traditional DSPM assumptions: it’s no longer just data at rest, but data in motion, in context, in memory, and in reasoning—flowing through RAG pipelines, vector stores/embeddings, model logs, agent toolchains, and new protocols like MCP / A2A / ACP. This creates governance gaps where data leaves its boundary via untrusted prompt ingress (e.g., hidden text in documents), poisoning, model memory leakage, over-permissioned tools, and sensitive output regurgitation.

Real-world incidents (e.g., Copilot “EchoLeak,” Samsung IP exposure, Meta AI IDOR) illustrate how weak boundaries, missing inventories, and lack of enforcement in orchestration frameworks translate into material risk and higher breach impact.

The OWASP Data Security Initiative focuses on practical, implementable guidance: defense-in-depth for AI data, zero trust for LLM pipelines, lifecycle security (ingestion→training→inference→sharing), and dynamic governance with continuous auditability and lineage. They also highlight emerging trends: privacy-enhancing tech (DP/SMPC/federated learning), AI-native DSPM → “data posture intelligence,” confidential computing, and early planning for quantum-resilient cryptography. The session closes with a call to join the initiative, contribute data, and help shape the 2026 updates.
