## Description

Richmond Alake was talking about agent memory before most people had heard of it, and now he argues the next layer after the control plane is an intelligence plane: what an agent knows, what it remembers, what it's allowed to see, and how it gets better. Using the WWII codebreakers who worked out that "AF" meant Midway, he shows why having the same information as everyone else isn't the same as intelligence. He then demos an agent built with an ontology and semantic layer that gets answers right 99% of the time using 32K tokens, versus 200K for a naive agent, and covers Oracle's agent memory package, deep data security, private inference, and fine-tuning small decision models for memory routing.
