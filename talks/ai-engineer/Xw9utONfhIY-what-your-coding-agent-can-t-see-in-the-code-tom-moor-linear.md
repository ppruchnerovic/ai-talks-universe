## Description

Tom Moor of Linear argues that writing code is no longer the bottleneck. The harder problem is keeping a product coherent as agents ship more and more of it. He walks through how Linear carries context from intake to merge: a triage agent that enriches each issue with customer and incident context, a review agent that checks changes against past decisions, reverts and regressions, and a daily automation that turns review feedback into lessons in the codebase. He shares real examples where that history caught problems a standard code reviewer would have missed.
