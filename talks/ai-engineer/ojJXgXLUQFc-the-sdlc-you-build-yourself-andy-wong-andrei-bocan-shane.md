## Description

An engineering standard becomes a reusable code review rule, applied across selected repositories instead of enforced by hand on every pull request. Andy Wong demonstrates that workflow with a design token standard while Andrei Bocan and Shane Wolf explain the context and orchestration underneath it. The workshop moves beyond a coding assistant in an editor to work that begins with a Jira item, draws on organizational knowledge and produces a change for a human to review. Code, documents and past decisions all matter, but they do not carry the same authority or stay current in the same way.

The presenters introduce Jira's coding agent, AI review, planning and autonomous development, then explore how those pieces fit into a team's existing process. Questions about the context engine lead into code search, relationships between Jira and Confluence, conflicting information and ways to favor verified sources. A live standards demo shows how to choose the repositories where a rule applies. Bocan describes selecting suitable backlog work, limiting cost and review volume, and asking people to clarify underspecified tickets before an agent proceeds. Wolf connects current source code with the historical reasoning behind it. Network interruptions shift much of the session into discussion, including sandbox verification, model selection, deterministic checks and breaking epics into smaller tasks. The through line is an SDLC that teams can shape around their own standards, context and capacity.
