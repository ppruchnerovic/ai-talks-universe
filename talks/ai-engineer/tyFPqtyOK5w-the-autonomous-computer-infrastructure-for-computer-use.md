## Description

A computer agent finds a speaker on Tuesday's conference schedule, saves the successful steps as a skill, and tries to replay them for Wednesday. A hiccup pushes it back into model driven exploration before the workflow completes. Ang Li uses that demonstration to explain Simular's approach to autonomous computers: combine adaptable vision agents with reusable automation code, then check the environment as each step runs. The workshop traces Agent S from accessibility based control to visual grounding, multiple models, and parallel attempts. It also asks a different reliability question from getting one successful result: can the same agent complete the task repeatedly when prompts and environments vary?

Li demonstrates a coding agent opening the AI Engineer website, reading an accessibility snapshot, and producing a summary. He then connects code replay and recovery to the tension between stability and adaptation, showing where a fixed script can break and where a model can help repair it. The infrastructure discussion moves from an agent occupying a personal desktop to fleets of cloud computers controlled through an interface or API. Recorded examples include legacy form entry and Android interactions. Audience questions examine screen understanding, verification loops, irreversible actions, operating system restrictions, and workflows built from internal procedures. The session presents an experimental direction with visible limitations: benchmark progress and successful demos still leave substantial work in making everyday computer use reliable.
