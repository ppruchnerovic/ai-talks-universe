## Description

A scanned NDA becomes a redacted Markdown document before a coding agent uses its contents. Filip Makraduli builds that workflow around an Obsidian vault, an MCP integration and Superlinked's inference engine, with small open models doing document processing on infrastructure the team controls. The starting problem combines sensitive files, expensive context and the need to adapt models to a particular task. Rather than send every page and image directly to a large model, the demo offloads OCR and other document work, then returns a smaller artifact the agent can use.

Makraduli walks through the host, MCP server and GPU worker pools that make the workflow possible. Tools support extraction, summarization, question answering and redaction, while the inference layer handles model loading, batching and different workloads sharing the cluster. He connects those infrastructure choices to embeddings, reranking, task specific LoRAs and the possibility of routing work between models already warm on a GPU. The live exercise starts from an inbox of files and asks the agent to process a document through the configured tools. The final discussion tests the privacy claim: if the agent can access raw files before calling the tool, instructions alone may leave a gap. Questions explore separating file access and processing, running a private cluster and evaluating whether the intended boundary actually holds. The workshop leaves both a working integration and a clear set of constraints to check before using it with sensitive material.
