## Description

A product intelligence agent checks an Amazon listing, searches Reddit for discussion of the same tumbler and turns both sources into a purchase recommendation. Yohan Raju builds that workflow with Bright Data APIs and Gemini, showing why an agent needs fresh, structured evidence rather than relying entirely on information already stored in a model or retrieval system. The demo collects prices, ratings and product details, adds customer sentiment, then asks the model to explain its recommendation. The result is a small example of a wider problem: getting reliable web data into an agent at the moment it needs it.

Before the notebook exercise, Raju walks through the work behind a scraping pipeline: discovering pages, handling changing selectors, managing browser and proxy infrastructure, validating returned fields and delivering clean records downstream. He compares that process with agent driven collection and introduces Bright Data's MCP server as an interface to search, page extraction and browser tools. A side by side Glassdoor example shows the access problem that can interrupt a seemingly simple request. Job data provides another use case, where changes in openings, salaries and locations require continuous updates alongside historical records. The workshop closes with the live notebook results and a discussion of how the same collection and analysis pattern can extend beyond ecommerce.
