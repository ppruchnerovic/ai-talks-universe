## Description

An agent keeps the code changes that improve a language model's score and discards the rest. Weco AI turns that research loop into a workshop, using Mini Parameter Golf to make training experiments small enough to inspect as they run. Zhengyao Jiang introduces autoresearch as repeated proposals and evaluations, and Dixing Xu explains the team's Aiden system and its contributions to OpenAI's Parameter Golf challenge. Vayum Arora and Dhruv Srikanth then connect those results to a practical setup that combines a modifiable source file, a fixed evaluation command and a measurable goal.

The walkthrough focuses on what determines whether the search is useful: fast and stable evaluations, a clear direction for the metric, time limits, initial guidance and protection against reward hacking. Weco's experiment tree makes each attempt inspectable, with its code changes and score visible in the dashboard. The presenters show how to branch from promising work and steer a running search toward a different idea instead of simply letting it continue. Internet problems lead to a guided setup demonstration, followed by questions about reinforcement learning and combining multiple objectives. The final exercise swaps model training for a Flappy Bird controller scored across normal play, moving gaps, wind and mixed conditions. A hidden validation set and limits on what the controller can edit make the competition another lesson in designing an evaluation that rewards the behavior you want.
