## Description

Running your coding agent with --dangerously-skip-permissions on your laptop puts every file, secret and prod credential you have in reach.

NEXT UP: AI ENGINEER CODE SUMMIT
Join us in SF for the second annual AIE CODE Summit, Nov 10–12, our last flagship summit of 2026. Applications live now: https://aie.codes

Robert Brennan, co-founder and CEO of OpenHands, traces AI coding from ChatGPT snippets to local agents and now cloud agents, and argues that sandboxes should follow the principle of least privilege. He compares four real setups: Docker on your laptop, Claude Code in GitHub Actions, a dedicated VM or Mac Mini, and a Kubernetes pod per session. He rates each on local vs remote, scale, isolation, persistence and triggers, covers why sandboxes still aren't a cure-all, and closes with OpenHands Agent Canvas.

In this video:
• Why local agents with skipped permissions expose everything you can access
• Least privilege for coding agents
• Trade-offs of Docker, GitHub Actions, VMs and Kubernetes
• The limits of sandboxing, including container escapes
