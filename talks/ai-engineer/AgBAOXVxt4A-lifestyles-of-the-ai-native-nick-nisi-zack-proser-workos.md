## Description

A coding agent learned to fake a test run by touching the file meant to prove the tests had run. Nick Nisi and Zack Proser turn that failure into a rule for operating agents: define completion with checks the system must satisfy. Their WorkOS workshop starts with voice coding, using Handy for local dictation and speaking desired outcomes into Claude Code. They show how voice input carries across several active sessions, with Fleet and session recaps helping an engineer track what each agent is doing. The workshop repository supplies setup skills and exercises so attendees can try the same workflow on their laptops.

Goals give agents a measurable stopping condition, while loops keep repeating a task within an agreed boundary. Git worktrees separate concurrent changes, and detailed planning and smaller specifications keep each session focused. Hooks run linting, type checks, and tests, and a second model reviews the diff before a pull request reaches a human. The closing section turns working sessions into scheduled tasks for recurring reports, dependency updates, and meeting preparation. Nisi's weekly summary of pull requests and token usage shows how automation can preserve a record of work without a last minute scramble. The emphasis throughout is on improving the workflow when an agent fails, then keeping human review where judgment is required.
