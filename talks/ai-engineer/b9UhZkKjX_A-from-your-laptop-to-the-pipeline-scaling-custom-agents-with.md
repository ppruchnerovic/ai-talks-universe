## Description

Most teams build an agent once, on one laptop, and never share it. Here's how to take it from local to the whole org to the CI pipeline.

Jose Palafox, who has spent six and a half years at GitHub and now works with companies on Copilot adoption, walks through the path from a local custom agent to agents that run unattended in your pipeline. He explains how Copilot works under the hood, the built-in agents in the Copilot CLI, and how to generate and edit a custom agent with the agent builder. Then he shows how to share agents across an organization with a marketplace, run agents across repositories with Orchestrate, and move them into CI with GitHub Agentic Workflows: headless Copilot CLI runs in GitHub Actions, triggered by slash commands in issues, plus a repo with about 200 agents running different parts of the pipeline and agents that investigate their own cost overruns.

In this talk:
• Local vs autonomous agents, and how Copilot works under the hood
• Building custom agents and choosing models for them
• Sharing agents across a company with a marketplace
• Running agents in CI with GitHub Agentic Workflows
