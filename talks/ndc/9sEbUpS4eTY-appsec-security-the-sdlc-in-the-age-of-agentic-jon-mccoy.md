As autonomous agents become increasingly prevalent in modern systems, ensuring their security is crucial to preventing potential threats and vulnerabilities.

This presentation will discuss the development of a comprehensive security framework for agentic systems, focusing on key areas such as reference architecture, common security risks, and prioritization of security controls. Specifically, we will explore the Delta security controls between non-agentic and agentic system security designs, highlighting the unique challenges and considerations that arise when integrating autonomous agents into existing systems. By providing a thorough understanding of these concepts, attendees will gain valuable insights into securing agentic systems and mitigating potential risks.
