## Description

This talk was recorded at NDC Copenhagen in Copenhagen, Denmark. #ndccopenhagen #ndcconferences #developer #softwaredeveloper

Attend the next NDC conference near you:

/        @NDC

Follow our Social Media!

AI Agents have been a fast-growing pattern among AI devs but have since become more relevant and attainable to every developer!

This session aims to equip you with both the theory and the practical knowledge required for getting started with building AI Agents on Azure. We will cover the fundamentals of AI agents, their applications, and how they can work together in multi-agent systems to solve complex problems. Then, we build some AI Agents using the open-source framework Semantic Kernel and test them live.

At the end of the session, you will be able to answer these questions:
Why is agentic AI becoming a trend?
What are popular frameworks for building AI Agents?
Why have more than one agent?
How to actually get started?

This session is designed for developers and AI enthusiasts who are eager to dive into the world of intelligent agents and their collaborative capabilities. We will use code in Python but equivalent code is available for .NET and Java as well.
