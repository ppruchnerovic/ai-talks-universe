Microsoft.Extensions.AI is an exciting new library that makes it easier than ever to integrate AI models into our .NET apps! By providing an abstraction that integrates with any AI service, we can easily leverage any AI model in our code, easily write unit tests, and easily upgrade to a newer model, all with just one line of code!

In this session, we'll introduce Microsoft.Extensions.AI and dive deep into its abstractions like IChatClient. We'll also highlight its integration with Microsoft's Semantic Kernel as its foundational layer.

Then, we'll jump into the code where we'll build our own custom chat client together! We'll quickly write code to use various models from OpenAI, and then we'll use that same code to jump to other providers like Amazon Bedrock and Ollama.

Join me as we learn about the best way for adding AI to any .NET app!
