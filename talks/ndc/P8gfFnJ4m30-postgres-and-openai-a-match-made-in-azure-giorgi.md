PostgreSQL on Azure is evolving beyond a traditional relational database—it's now a platform where advanced AI meets robust data management.

Whether you need to perform sentiment analysis, summarize documents, translate text, or identify personally identifiable information (PII), PostgreSQL on Azure has you covered.

In this session, you'll explore how to leverage the power of Azure's PostgreSQL Flexible Server combined with OpenAI’s generative capabilities. You will see how to use Azure OpenAI service directly from PostgreSQL with the azure_ai extension to generate vector embeddings, implement semantic search, build recommendation systems or summarize documents.

Join me for a demo-rich session and learn how to build AI solutions using PostgreSQL and OpenAI in Azure.
