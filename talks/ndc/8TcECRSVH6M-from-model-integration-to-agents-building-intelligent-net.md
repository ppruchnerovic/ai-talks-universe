There are multiple ways to add AI to a .NET application. Depending on the problem you’re solving, you may choose anything from direct model integration to higher-level abstractions and frameworks.

In this session, we’ll explore the different options available to .NET developers when building AI-enabled applications. We’ll start with direct model access using APIs and SDKs, move on to using managed services such as Azure AI Services, and then look at higher-level composition approaches using libraries like Semantic Kernel.

Finally, we’ll look at agent-based frameworks and how they build on these foundations to make it easy to add agents to your applications.

This session is aimed at understanding the trade-offs between these options and when each one makes sense in a real-world application. All examples are demonstrated using a Blazor application, but the concepts apply to any .NET platform.

You’ll leave with a clear overview of the AI integration options available in .NET, along with practical guidance to choose the right level of abstraction for your application.
