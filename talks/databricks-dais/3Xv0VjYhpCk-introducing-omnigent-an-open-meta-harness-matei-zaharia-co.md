## Description

Introducing Omnigent: A Meta-Harness for AI Agents

Omnigent makes AI agents interoperable, so sessions, policies, and skills stay with users regardless of where the agent or model is running.

Learn more about Omnigent: https://www.databricks.com/blog/introducing-omnigent-meta-harness-combine-control-and-share-your-agents
