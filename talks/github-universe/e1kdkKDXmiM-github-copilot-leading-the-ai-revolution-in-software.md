## Description

Developers and enterprises adopting AI coding assistants expect these tools to be increasingly accurate and personalized to their needs. GitHub Copilot is leading the charge, delivering major improvements in code suggestion quality, enhanced customization via fine-tuned models, and building a growing ecosystem with extensions. Join our partner Adobe and GitHub's Shuyin Zhao, VP of product management, and Simina Pasat, senior director of product management, to see all the latest Copilot innovations. You'll also learn how collaboration in GitHub.com is getting better with the power of AI agents and how you can use new, optimized workflows in the age of AI.
