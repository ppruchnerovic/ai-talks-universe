## Description

Celebrating our 10th GitHub Universe, GitHub CEO, Thomas Dohmke, took the stage to reflect on GitHub’s incredible journey and share our bold aspiration to empower 1 billion developers. We announced Anthropic’s Claude 3.5 Sonnet, Google’s Gemini 1.5 Pro, and OpenAI’s o1-preview and o1-mini are coming to GitHub Copilot—bringing a new level of choice to every developer. From Copilot Workspace to multi-file editing to code review, Copilot Autofix, and the CLI, we will bring multi-model choice across many of GitHub Copilot’s surface areas and functions soon.
