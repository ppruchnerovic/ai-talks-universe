## Description

With our vision for AI clear, we’ve set our sights on another generation-defining aspiration: making GitHub the future of 1 billion developers. But this aspiration isn’t just about GitHub—it’s about the millions (and soon billion) developers changing the world with software for the sake of humanity. Join GitHub COO, Kyle Daigle, together with our community, will showcase how every developer, from the enterprise to open source developer, student to professional, plays a critical role in this journey, making our aspiration one that’s shared by all who create with code—wherever they are, whoever they are.
