## Description

Introducing GitHub Copilot as an AI pair programming tool is helping SAP, the world’s largest provider of enterprise application software, in reimagining the developer experience for more than 18,000 software developers.

Hear from SAP's Sumeet Shetty, head of Tools India, and Tobias Schimmer, head of Developer Experience, about how SAP kickstarted the adoption of generative AI at scale within development using Copilot. Learn how Copilot helped create trust in the ease-of-use and output of AI tools. Experience data and telemetry data from SAP indicates that Copilot is widely accepted as an AI pair programming tool that brings flow, creativity, and fun into software development at SAP!
