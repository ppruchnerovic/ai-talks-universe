## Description

GitHub Copilot was the first at-scale AI assistant for code completion in software development. Join our moderator, Matthew Masarik, director of applied science, and panelists, Cooper Nederhood, machine learning engineer, Joe Bourne, staff product manager, and Mitch Naylor, senior applied machine learning researcher, all from GitHub, to learn how our Applied Science team is enhancing the quality of Copilot's code completion. Together, they'll discuss how GitHub uses LLM fine-tuning, RAG, prompt engineering, and other techniques to increase accuracy and supercharge productivity.
