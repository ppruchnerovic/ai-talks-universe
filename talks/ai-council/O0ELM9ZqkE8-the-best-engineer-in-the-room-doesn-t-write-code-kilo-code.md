## Description

[2026 - DAY 2 - CODING AGENTS] They build systems of agents. In this talk, we explore the shift from session-based AI tools to always-on agents that act, follow up, and own outcomes without waiting to be asked. We'll cover what OpenClaw got right, where it falls short, and how we're closing the gap with KiloClaw—and what all of this means for the future of how software gets built.
