## Description

[2025 - Day 2 - Foundation Models] Nikunj Handa shares insights from building OpenAI's Responses API, exploring how this programmatic agent API radically simplifies integration by transforming hundreds of lines of code into just a few. This talk offers valuable perspectives on the design decisions and engineering challenges behind creating an API uniquely engineered for agent-like use cases with built-in state management and semantic streaming, particularly relevant for developers building AI applications or integrating advanced reasoning capabilities.
