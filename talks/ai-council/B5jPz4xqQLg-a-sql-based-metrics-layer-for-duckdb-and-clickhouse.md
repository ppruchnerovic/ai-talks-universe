## Description

[2025 - Day 2 - Analytics & BI] Mike Driscoll shares insights from building Rill's SQL-based metrics layer using DuckDB, exploring how to aggregate raw data into summarized metrics and enable dimensional slicing through declarative SQL expressions. This talk offers valuable perspectives on implementing fast OLAP engines for real-time data access with sub-second response times, essential for analytics teams seeking to define metrics using familiar SQL dialect as part of a BI-as-code philosophy.
