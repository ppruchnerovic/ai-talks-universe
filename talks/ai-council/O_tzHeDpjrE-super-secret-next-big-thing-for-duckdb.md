## Description

[2026 - DAY 1 - DATA ENG & DATABASES] DuckDB has been quietly working on something big. At AI Council 2026, co-creator Hannes Mühleisen finally reveals it.

For years, DuckDB has taken a deliberately embedded, in-process approach to analytical data — powerful, but with one persistent limitation: multiple processes can't write to the same database at once. Until now.

Hannes takes the stage to unveil Quack — a new remote protocol that gives DuckDB client-server capabilities for the first time. With a single extension, any two DuckDB instances on a network can become client and server over HTTP, with the full DuckDB feature set over the wire.
