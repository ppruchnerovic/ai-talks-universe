## Description

This hands-on session gives you the golden opportunity to gain firsthand experience of working and writing plugins in Golang & Python for the open source project CloudQuery. With a thorough introduction to the architecture of CloudQuery, the session will also walk you through some astounding performance benchmarks. The highlight of the workshop is the practical application of these plugins to extract data from different sources and synchronize them to any desired location effectively.
