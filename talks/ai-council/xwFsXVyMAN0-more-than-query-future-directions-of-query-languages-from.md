[2025 - Day 2 - Analytics & BI] Julian Hyde shares insights from the evolution of query languages, exploring what we want from modern data languages and introducing Morel, which combines functional programming's type system with declarative query efficiency. This talk offers valuable perspectives on extending SQL and replacing today's data frameworks, particularly relevant for engineers working across data engineering, data science, analytics, and mathematical optimization domains.
