## Description

Are you grappling with a myriad of data services? Frustrated by frequent boiler-plating and maintenance? Concerned about performance? If you answered yes to any of these, then this workshop is for you.

GoodData unpacks their latest project — "FlexQuery", a solution that can revolutionize your data service landscape. With just a few lines of easy-to-understand Python code and no boiler-plating, you can create a new high-performance data service that integrates flawlessly into the Arrow and Arrow Flight powered ecosystem.

A key feature of FlexQuery is its suite of data services including Data Source Connectors that connect data sources to your analytics environment seamlessly, Multi-Tier Cache Storage for high-speed cache storage across memory, disk, and object stores, Cache Enabled Query Execution for real-time insights from cached data aided by DuckDB, and Post-SQL Transformations that offer precise data shaping with the versatility of Pandas or Polars.

FlexQuery provides complete deployment flexibility for extreme scalability, from bare metal to VMs to Kubernetes. Looking ahead, the team has exciting plans to utilize a Large Language Model to fine-tune our cache design. Best of all, they're making FlexQuery open-source, to democratize powerful data services for all.
