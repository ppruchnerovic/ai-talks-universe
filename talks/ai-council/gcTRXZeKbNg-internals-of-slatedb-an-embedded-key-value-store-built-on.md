## Description

[2025 - Day 2 - MLOps & Platforms] Vignesh Chadramohan shares insights from building SlateDB, an embeddable storage engine built on object storage, exploring how to leverage properties like conditional writes for stream processing and durable execution. Whether you're working with disaggregated data systems or building on S3-like storage, this talk offers valuable perspectives on implementing features like checkpoints, writeable clones, and remote compaction in Rust-based storage engines.
