## Description

Delve into the intriguing world of Data Reliability Engineering with insights borrowed from Site Reliability Engineering (SRE) in this conference talk. Explore real-world reliability scenarios and essential topics including data downtime, data service level metrics and data monitoring. Plus, learn to minimize data downtime, leverage metadata for preventive practices and identify system failures efficiently. Ideal for Data Scientists, Data Engineers and AI practitioners, this enlightening session offers valuable tools and practices to build robust data systems.
