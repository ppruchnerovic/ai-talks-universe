## Description

Discover the challenge and solution in data management for multi-modal AI in this technical talk. Chang She delves into the complexities of managing various unstructured data types like images, audio and video. The sheer size of these data types coupled with the intricacies of AI datasets and varied workloads necessitate an optimal data infrastructure, something the current data stack generation can't provide.

This talk explores real-world use-cases that shine a spotlight on the limitations of today's data infrastructure for AI. Watch the talk to discover the Lance columnar format, the open-source powerhouse poised to supercharge the next generation of data infrastructure for AI.
