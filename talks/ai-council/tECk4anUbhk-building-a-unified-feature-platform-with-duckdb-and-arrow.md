## Description

Explore the world of Machine Learning in this session by Mike Eastham, Chief Architect at Tecton, who has immense experience in the ML industry.

In this technical talk, Mike dives into the making of Tecton's innovative Feature Platform, built to address the challenges in data transformation for Machine Learning models. Witness the power of DuckDB and Arrow in action, as the latest additions to the platform, designed to provide a faster and more integrated local development experience.

Key takeaways from this session include:
- Effective strategies for scaling up to bigger datasets without a distributed query engine.
- Techniques for implementing and distributing DuckDB extensions.
- Insights into creating interoperability with DeltaLake, outside of the Spark ecosystem.
- An in-depth comparison of performance with Spark.
- How Tecton leverages cloud resources to handle larger-than-laptop datasets without compromising the laptop developer experience.
