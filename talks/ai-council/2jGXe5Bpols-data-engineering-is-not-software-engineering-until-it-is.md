## Description

[2025 - Day 3 - Lightning Talks] Karen Hsieh shares insights from distinguishing between software engineering and data engineering disciplines, exploring unique data challenges like managing test environments and verifying change intents through real-world examples from dbt and SQLMesh projects. For practitioners navigating the intersection of these fields, this talk offers valuable perspectives on feedback loop latency differences and how the future of software development will draw learnings from today's data-centric systems and AI building blocks.
