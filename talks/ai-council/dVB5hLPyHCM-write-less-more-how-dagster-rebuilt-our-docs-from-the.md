[2025 - Day 3 - Lightning Talks] Pedram Navid shares insights from rebuilding Dagster's documentation from the ground up using Docusaurus, exploring how to tackle documentation challenges that incremental improvements couldn't solve. For teams struggling with maintaining technical documentation, this talk offers valuable perspectives on when and how to undertake complete rewrites, presented in the style of a Fresh Prince narrative about flipping docs upside down.
