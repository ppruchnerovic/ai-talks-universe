## Description

LLMs can summarize and autocomplete code—but often fail at code review, showing overconfidence, repetition, and poor judgment. This talk unpacks why transformer models struggle with intent and impact, and how reasoning phases, memory, and reflection can improve precision and trust. With real examples from Baz’s code review agent, we’ll explore what it takes to move beyond prompt engineering to reliable developer tools.
