## Description

Christian Liebel joins the show to discuss the evolution of the web, marking JavaScript's 30th anniversary and the rise of TypeScript for building maintainable, large-scale applications. The conversation explores the ongoing tension between relying on frameworks like React and Angular versus mastering the underlying web platform. A key insight is that while frameworks accelerate development, job descriptions demanding specific framework knowledge can act as gatekeepers, whereas a solid foundation in platform standards like HTML, CSS, and JavaScript is more transferable.
