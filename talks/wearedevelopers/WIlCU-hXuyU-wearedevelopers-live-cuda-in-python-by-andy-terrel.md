## Description

CUDA has been available to the Pythonista for over a decade, but often through 3rd party abstractions that are behind the CUDA releases. Over the next year, NVIDIA is releasing Python as a native CUDA language. In this presentation we talk about the ways a Python programmer can access the CUDA Platform today and how Python exposure is coming to each level of the CUDA stack.
