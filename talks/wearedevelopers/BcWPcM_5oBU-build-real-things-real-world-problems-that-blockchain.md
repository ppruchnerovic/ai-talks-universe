## Description

Join Marco Podien from the Algorand Foundation as he bridges the gap between Web2 and Web3 in this hands-on developer session. Learn how blockchain is solving real-world problems—from humanitarian aid in Afghanistan to luxury real estate tokenization in the U.S.—and see live coding demos that show just how easy it is to start building on Algorand with Python and TypeScript.

Whether you're a curious Web2 developer or an experienced blockchain enthusiast, this session delivers actionable insights, live coding, and a deep dive into the developer tooling behind Algorand.
