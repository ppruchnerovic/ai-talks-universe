## Description

In this episode of Coffee with Developers, William Lyon from Neo4j breaks down what AI agents really are and why agent memory is the next big challenge. He explains how agents work as “loops with tools,” why fully autonomous agents aren’t practical yet, and why keeping humans in the loop is crucial.

The conversation dives into how Neo4j’s graph technology helps agents remember context, learn from past actions, and become more efficient—reducing token usage and improving accuracy. William also highlights real-world use cases, common mistakes teams make when adopting agents, and why shared memory across multiple agents could be a game changer.

If you're building with AI, this is a must-watch on the future of smarter, more context-aware agents.
