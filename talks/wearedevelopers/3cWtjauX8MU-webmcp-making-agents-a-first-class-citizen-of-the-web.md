## Description

Web agents are booming — but today’s web was built for humans, not bots. In this Coffee with Developers episode, we are joined by Andre Cipriani Bandarra & François Beaufort to explore WebMCP (Web Model Context Protocol): a proposal (now in Chrome Canary preview) that lets websites expose structured tools to browser agents instead of forcing them to “click like a human.”

We cover what MCP is, how WebMCP works, the declarative form-annotation API vs the imperative JavaScript API, and why this can make automation faster, more reliable, and less token-hungry. Plus: a live demo using a Chrome extension tool inspector and a reservation form that agents can complete with just a couple HTML attributes.
