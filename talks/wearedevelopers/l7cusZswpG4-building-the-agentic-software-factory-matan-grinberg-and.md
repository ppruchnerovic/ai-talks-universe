## Description

What does building a software factory for the era of agents look like? Join Thomas Dohmke (CEO and founder, Entire) and Matan Grinberg (CEO and cofounder, Factory) to discuss how the software development lifecycle must change to adapt to a world where agents are the primary producers of code. Drawing on their respective experience across the industry building independent, model agnostic platforms, the pair will lay out a shared vision for the future: From Git hosting, to multi-agent reviews, to the end of human code review altogether.
