## Description

Bastian Heist talks about rendering in Neos first and how it's flexible server side rendering system already allows for some interesting integrations, like embedding JSON into the rendered markup or declaratively building a small API just with the tools available. He continues talking about the GraphQL package that we provide as a playground which allows full read and write access to the content and is therefore suited for a fully headless approach on using Neos.
