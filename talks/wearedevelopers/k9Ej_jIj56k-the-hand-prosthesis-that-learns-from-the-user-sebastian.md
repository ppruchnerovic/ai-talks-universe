## Description

It is no wonder that modern hand prostheses are highly sophisticated mechatronic devices: The human hand is a complex tool for manipulation, interaction, and gesticulation. However, to control so many degrees of freedom is a highly challenging task. In this talk, a machine learning approach will be presented to provide a solution: The hand prosthesis that learns from the user!
