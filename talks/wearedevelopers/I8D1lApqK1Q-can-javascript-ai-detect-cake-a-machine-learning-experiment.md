## Description

Join us for another episode of Coffee with Developers, where we chat with Cari Richmond, Principal Developer Advocate at Elastic. 🚀 In this fun and insightful conversation, Cari shares how she combined machine learning and JavaScript to create a model that detects... Is it cake or not? 🎂

We dive into:
- The challenges of building ML models with TensorFlow.js
- Why transfer learning improved her results
- The importance of curiosity in development
- How AI tools are shaping (or limiting?) how we code

If you're a developer who loves experimenting and tinkering with tech, this episode is for you!
