## Description

Luke Hinds (Always Further) explores the security risks behind the AI “gold rush,” where powerful AI agents are given direct system access without proper safeguards.

He introduces nono, an open-source CLI tool that sandboxes AI agents using low-level Linux security features, enforcing a deny-by-default policy to protect files, credentials, and systems.

The goal: make AI security simple and practical for developers without slowing innovation.
