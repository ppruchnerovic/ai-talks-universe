## Description

Looking to modernize your .NET applications? Learn how Grupo Tress Internacional used AWS Transform to reduce modernization effort by 70% while migrating from .NET Framework to .NET 8. This session demonstrates practical strategies for containerization and serverless using Amazon ECS, AWS Fargate and AWS Lambda, implementing DevOps methodologies, and empowering developers with generative AI tools to accelerate innovation.
