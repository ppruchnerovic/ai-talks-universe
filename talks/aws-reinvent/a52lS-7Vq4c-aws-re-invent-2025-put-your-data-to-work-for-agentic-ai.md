## Description

Agentic AI systems require storage that delivers persistent memory, real-time decisions, and seamless multi-agent collaboration. AWS offers the most comprehensive storage portfolio to support these needs, including high-speed services like S3 Express One Zone, storage for compute intensive agent workflows using FSx for Lustre, and scalable vector storage and query with S3 Vectors. With the new MCP Server for S3, agents can query context-rich data using natural language without complex code. This session explores how to architect agentic AI with purpose-built AWS storage and integrations with Amazon Bedrock and OpenSearch Service, enabling intelligent agents to operate continuously while simplifying infrastructure and accelerating production deployment.
