## Description

Discover how Robinhood enhanced their AI performance using Amazon SageMaker and Amazon Bedrock to optimize large language models (LLMs). This solution achieved 80% lower latency on key agentic tasks while scaling to millions of tokens per minute. Learn practical techniques for fine-tuning foundation models with Amazon SageMaker and implementing high-performing inference on Amazon Bedrock. This session covers model selection, optimization strategies, and deployment best practices for teams looking to improve their AI applications on AWS.
