## Description

Caching has evolved beyond key-value lookups. Modern applications demand flexibility and extreme performance. Redis 8 introduces two major innovations: Client-side caching, which solves the “hot keys” problem by storing frequently accessed data near the application and cascading invalidations for scalability under load; and the Redis Query Engine, enabling search across nested JSON and complex data types. Redis 8.4 further reduces JSON memory usage and adds new commands. Combined with Redis Data Integration (RDI), Redis now serves as a high-speed data layer for real-time apps in e-commerce, healthcare, fintech, and AI. iFood is joining this session to share their Redis journey.
