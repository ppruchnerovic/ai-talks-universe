## Description

AI and AI-based workloads are the new transformational effort and securing these modern web applications in the cloud requires a lot more than security gates.  In this session, Adobe and Fortinet share strategies and experience protecting AI-enabled applications, web APIs, and data.  Attendees will learn from Adobe’s cloud security experience, explore practical examples, and receive actionable guidance to strengthen their own cloud security posture. The session combines co-presented insights with audience Q&A for an engaging, interactive experience. This presentation is brought to you by Fortinet, an AWS Partner.
