## Description

In the fast-paced world of music and entertainment, data is a critical asset. This session explores how Warner Music Group is using an open-source data format to drive innovation. Join Michael Jones, Director of Software Engineering at Warner Music Group, to learn how Apache Iceberg tables enable an interoperable data ecosystem that unifies first- and third-party sources. By pairing Iceberg with Snowflake’s innovations, Warner Music is unlocking deeper analytics today while also setting the stage for advanced machine learning and AI initiatives on AWS. This presentation is brought to you by Snowflake, an AWS Partner.
