## Description

GenAI-powered development tools are changing how teams build multi-tenant agentic SaaS software. It's time to see how these tools can be used to accelerate the creation of entire SaaS environments. This session will walk through the end-to-end creation of a SaaS environment, using the AWS stack of GenAI services (such as Kiro and Strands) to construct an agentic-enabled SaaS environment. We'll build out the services of the control plane, create a sample agent-enabled multi-tenant application, and apply SaaS foundational principles to the solution (using best practices from the SaaS Builder Toolkit and the AWS Well-Architected SaaS Lens). The goal to provide a first-hand look at how a GenAI-powered experience can automate and streamline the creation of entire agentic SaaS environments.
