## Description

Explore how enterprises are adopting and scaling multi-agent systems with Amazon Bedrock and AgentCore for advanced data analysis and research applications. In this session, Dipen Rughwani from Yahoo Finance will share his journey on designing and implementing multi-agent systems for financial question answering. This work investigates methods for orchestrating agents, integrating with Yahoo Finance web services that deliver structured and unstructured data to web and mobile applications. We discuss approaches for enabling coordinated tool/API calling for heterogeneous sources and evaluating performance trade-offs in multi-agent architectures. The session provides practical guidance for architects and data scientists building enterprise-scale agent-based solutions.
