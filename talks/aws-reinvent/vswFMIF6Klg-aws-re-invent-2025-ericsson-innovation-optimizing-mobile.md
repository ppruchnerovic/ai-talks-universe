## Description

Discover how Ericsson leverages AWS AI solutions to revolutionize mobile networks through two groundbreaking use cases. First, explore Ericsson's journey toward Autonomous Network AI multi-agents and reinforcement learning solutions, automating RAN optimization, cutting operational effort by up to 50% while dynamically improving network coverage, capacity, and quality. Second, witness Ericsson's solution to knowledge de-fragmentation in complex telecom development. Using AWS services, including custom SageMaker models and Amazon Q Developer, Ericsson created an AI-native environment that breaks down information silos and accelerates innovation. Learn how Ericsson harnesses Amazon Bedrock, SageMaker, and Q Developer for future innovation in Agentic AI.
