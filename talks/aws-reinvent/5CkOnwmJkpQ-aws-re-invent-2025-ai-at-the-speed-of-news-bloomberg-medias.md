## Description

Discover Bloomberg’s vision for an AI-driven content pipeline designed to transform natural-language queries and multimodal inputs into video content. This session outlines how Bloomberg aims to unify high-speed discovery and content assembly across audio, video, and text using semantic search patterns, OpenSearch, and Amazon Neptune. Learn how Bloomberg is shaping an approach that balances AI acceleration with human oversight — preserving accuracy and integrity while enabling more dynamic, real-time news experiences. The discussion will explore dynamically weighting data sources, tuning vector types, and using LLM-powered user intent analysis to achieve scalable, precise multimodal retrieval and content recommendations in workflows.
