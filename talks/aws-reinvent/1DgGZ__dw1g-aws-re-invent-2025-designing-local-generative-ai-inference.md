## Description

While running inference in the cloud is a common and effective approach for Generative AI, some use cases demand local execution. This session explores how to design and operate local inference architectures using AWS IoT Greengrass. Through a live demo using a robotic arm, attendees compare cloud-based and local inference in practice, examining trade-offs in latency, connectivity, and model update frequency. The talk also presents a practical approach for delivering and updating models at the edge to support the reliable, ongoing use of Generative AI in real-world environments.
