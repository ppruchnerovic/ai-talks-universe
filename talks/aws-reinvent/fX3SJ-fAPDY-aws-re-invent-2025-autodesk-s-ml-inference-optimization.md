## Description

Learn how Autodesk partnered with AWS Generative AI Innovation Center to optimize spatial GenAI models using Inferentia and Trainium chips. This collaboration reduced latency by 45% and improved price-per-inference by 62% across workflows generating 3D objects and CAD sketch constraints. Explore Autodesk's migration journey, including strategies for implementing custom kernels via the Neuron Kernel Interface. Discover the sustainability benefits and economic advantages of adopting custom silicon, from reduced carbon emissions to optimized infrastructure costs.
