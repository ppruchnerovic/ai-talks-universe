## Description

Model Context Protocol (MCP) is an open protocol that standardizes how AI models can, in a secure and structured way, access external tools, data sources, and APIs. Join this session to  learn best practices on how to securely implement MCP server-based tools to enhance development workflows with richer context in order to help developers complete coding tasks efficiently. We'll also cover relevant use cases and discuss the tradeoffs between using RAG verus MCP.
