## Description

This session explores transforming legacy workflows into intelligent agent-based systems. Learn to assess, design, build, and run autonomous agents that modernize rigid, siloed processes into adaptive, AI-powered solutions. Understand essential design considerations and frameworks for scaling agentic implementations. Through demonstrations, discover practical strategies using Model Context Protocol (MCP) and specialized domain agents, including a comprehensive reference architecture leveraging AWS Gen AI services and Strands SDK for enterprise-grade agentic systems. Learn how AWS partners can build agentic offerings using structured frameworks to accelerate customers' modernization journeys through innovative solutions that deliver business value.
