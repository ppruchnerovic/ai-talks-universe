## Description

This session demonstrates building Generative AI agents that operate fully offline using the AWS Strands Agents SDK. The presentation covers deploying lightweight local models with Ollama and integrating custom tools for remote manufacturing, field operations, and data sovereignty scenarios. Explore how these edge-deployed agents seamlessly scale to leverage cloud capabilities, transitioning to powerful models like Claude on Amazon Bedrock when connectivity is available. The session provides practical patterns for combining local processing with cloud AI to create resilient, location-independent solutions.
