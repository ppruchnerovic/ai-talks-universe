## Description

Large language models and agentic tools have reached enterprise viability, with Service Oriented Architecture (SOA) principles providing the foundation for robust agentic systems. This session examines which SOA design principles translate directly to generative AI implementations and which require rethinking for agent orchestration and nondeterministic behaviors. Learn architectural patterns for secure AI service integration, tools for enterprise-scale agent deployment, and techniques for building agents that work seamlessly with existing ecosystems. WEX demonstrates how extending SOA into the agentic domain enables generative AI solutions to deliver enterprise-grade operational support at scale. Gain practical insights into combining SOA best practices with modern AI architecture requirements.
