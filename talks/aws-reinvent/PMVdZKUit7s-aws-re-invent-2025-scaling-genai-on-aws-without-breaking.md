## Description

Generative AI is transforming industries—and AWS managed services are accelerating that shift—but these workloads can also be some of the most expensive and unpredictable to run. In this session, we’ll break down GenAI into four deployment modes and dive into key AWS services like Amazon Bedrock, SageMaker, and GPU-powered EC2 families, explaining how customers are charged and where the biggest savings lie. Drawing on real-world customer lessons, you’ll learn how to apply FinOps principles to boost GPU utilization, forecast spend, implement chargeback models, and track unit cost metrics—ensuring AWS GenAI workloads remain scalable and financially sustainable This presentation is brought to you by IBM Cloudability, an AWS Partner.
