## Description

Learn how Amazon CloudFront powers high-profile streaming events with low-latency, scalable delivery. Discover how to optimize caching using embedded POPs, reduce origin load with Origin Shield, and fine-tune streaming performance. We will dive into Common Media Server Data (CMSD) techniques that dynamically adjust to network conditions, maintaining high-quality viewing experiences for global audiences. We’ll also explore integrations with AWS Elemental Media services for personalized ad delivery and multi-region origin usage. Hear from NESN on how they've leveraged these capabilities to deliver great viewing experiences for popular sporting events.
