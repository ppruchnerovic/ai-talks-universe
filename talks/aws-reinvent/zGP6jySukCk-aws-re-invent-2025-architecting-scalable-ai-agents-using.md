## Description

Discover how to build powerful AI agents using Amazon Bedrock's suite of tools, with a focus on Amazon Bedrock AgentCore. This session explores AI agent architectures, from implementing Bedrock Flows to configuring knowledge bases and guardrails. Learn to design dynamic inline agents and understand multi-agent collaboration frameworks. We'll demonstrate how AgentCore's modular components enable you to create secure, enterprise-ready AI solutions that scale.
