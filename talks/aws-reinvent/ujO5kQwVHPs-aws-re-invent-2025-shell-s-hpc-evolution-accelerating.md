## Description

Explore Shell's transformative journey in hybrid HPC computing, combining on-premises systems with AWS GPU capabilities for seismic processing and AI applications. The evolution from CPU-based processing to advanced GPU implementations represents a critical advancement in energy sector computing. Learn how this hybrid approach achieved 3-5x project acceleration while maintaining cost efficiency, including migration of Shell's processing code to AWS, implementation of GPU-based Full-Waveform Inversion workflows, and significant cost reductions in non-EC2 services. Gain insights into the latest developments in capacity block services, transitions to H200 GPUs, and the future of energy sector HPC through Amazon Parallel Computing Service and Energy HPC Orchestrator platforms.
