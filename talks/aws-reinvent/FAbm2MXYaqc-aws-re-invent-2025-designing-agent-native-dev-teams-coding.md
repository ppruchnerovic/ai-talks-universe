## Description

The agentic shift is reshaping how teams build software—and AWS Autonomous Coding Agents are designed to help developers move faster, not work harder. These agents assist with structured tasks like scaffolding, test generation, and documentation, freeing up engineers to focus on design and intent. In this session, we’ll go beyond the launch and explore what it means to build agent-native workflows within existing teams.We’ll cover what emerging best practices look like from teams already exploring this new development paradigm. Whether you're an SDE experimenting with agents or an SDM deciding when to scale usage, this session shows you where vibe coding meets engineering velocity.
