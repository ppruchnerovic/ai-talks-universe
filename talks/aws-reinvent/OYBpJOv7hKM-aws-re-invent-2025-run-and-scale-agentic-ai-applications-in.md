## Description

Scalable, reliable agentic AI applications need infrastructure that can build, deploy, and manage through a single, repeatable workflow. This session demonstrates how to use HashiCorp Cloud Platform (HCP) Terraform chain dependent infrastructure stages, keep post-run automations in Terraform, and bring unmanaged AWS resources under control using Stacks, Actions and Search & Import. We’ll also cover how, when Kubernetes is the application platform, HCP Vault fits seamlessly into workflows to strengthen security. Expect practical patterns you can apply to run agentic AI with confidence, safeguard sensitive data, and scale operations on AWS without unnecessary complexity.
