## Description

Join this technical deep-dive into Cox Communications' Service Health, an AWS-powered solution transforming network management into intelligent, autonomous operations. Discover how Cox achieves point-of-interest event isolation using Amazon Neptune Graph Database, processing sub-second telemetry across 26 million topology nodes and profiling events in seconds. Learn how Cox built network data foundations enabling Agentic AI with Amazon Bedrock and Strands Agents to proactively detect and isolate faults. Explore the AWS stack powering topology hygiene management and Cox's vision for fully autonomous network operations delivering faster outage detection, improved prioritization, and intelligent remediation at scale.
