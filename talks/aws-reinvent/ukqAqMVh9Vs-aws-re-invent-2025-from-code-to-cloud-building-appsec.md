## Description

Building application security programs requires the right tools, processes, and expertise. This session provides a practical roadmap for establishing and scaling AppSec programs using AWS services and AI-powered capabilities. Learn how to define security goals and culture, develop threat models, and find vulnerabilities throughout the SDLC with Kiro and Amazon Inspector. Discover practical strategies for shift-left security, continuous vulnerability management, and building sustainable programs that work for organizations of any size.
