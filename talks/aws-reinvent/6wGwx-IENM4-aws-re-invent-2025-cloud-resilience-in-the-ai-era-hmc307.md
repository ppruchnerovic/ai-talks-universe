## Description

Your AI strategy is only as secure as your cloud foundation. AI-enabled cyberattacks surged 47% in 2025, while AI adoption creates explosive data growth across cloud estates. Organizations face threats moving at machine speed: corrupted training datasets, compromised agent outputs, and rapidly expanding attack surfaces. Traditional cloud snapshots can't keep pace. This session provides a practical framework for cloud resilience when AI amplifies threats. Learn how to gain visibility into AI-driven attack vectors, implement recovery strategies matching the speed of incidents, and protect your data lifecycle from both malicious attacks and agent mistakes while safely operationalizing AI. This presentation is brought to you by Rubrik, an AWS Partner.
