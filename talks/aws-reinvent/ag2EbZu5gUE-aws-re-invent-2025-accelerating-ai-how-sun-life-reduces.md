## Description

Organizations are aiming to deliver responsive generative AI experiences that can seamlessly scale across enterprise use cases. Learn how Sun Life transformed content creation and workflow orchestration by building Content Assist—a content, scoring, and rewriting solution that can be trained on any brand guidelines, tone, or examples. Sun Life will share their journey from an AWS Lambda and Amazon Bedrock solution to an AWS AppSync powered streaming UI solution with Model Context Protocol (MCP) integration to support use cases, from corporate-wide productivity tools to automated content creation and contact center authentication. Explore implementation patterns for reducing perceived latency and orchestrating multi-agent workflows.
