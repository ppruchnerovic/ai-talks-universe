## Description

Dive deep into how Novartis architected their regulated NextGen clinical trial data platform using AWS services including Amazon S3, Databricks on AWS, Amazon Sagemaker, and AWS RDS. Explore their AWS-based clinical landscape, implementation of data lake patterns, and legacy system modernization approach. Learn how they built secure, traceable data backbone powering AI/GenAI innovations in protocol design, trial performance management, and clinical document generation, while maintaining regulatory compliance. Learn how this architecture enables clean data flow and rapid decision-making across drug development workflows.
