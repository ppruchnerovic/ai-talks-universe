## Description

The NBA is launching a new advanced stats program, “Inside The Game, Powered by AWS”  to bring fans closer to the game of basketball. During every NBA game, billions of data points are captured, such as a player’s scoring performance on every shot, to their skeletal pose location on the court 60 times a second. This data is used in Artificial Intelligence (AI) and Machine Learning (ML) models to create advanced stats and insights that go beyond the usual box score. This session will cover the NBA’s advanced stats platform migration from Azure to AWS and how the suite of AI/ML based stats are being developed. It will also cover how the NBA partnered with AWS to build the new “Gravity” Inside The Game stat, which leverages existing NBA advanced stats and a predictive ML model to determine how much a player pulls defense towards them in real-time throughout every offensive possession.
