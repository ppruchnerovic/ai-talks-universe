## Description

Foundation models are able to solve a wide array of tasks, however to solve most tasks effectively, these models require some form of customization. In this session, you’ll learn about how you can get started with advanced customization of foundation models using SageMaker AI, while optimizing cost and performance. You’ll learn how you can use SageMaker AI for advanced techniques such as parameter-efficient fine-tuning, direct preference optimization, and reinforcement fine-tuning, for both proprietary as well as publicly available foundation models. You’ll walk away understanding how to use SageMaker AI to get the most value from your AI investments.
