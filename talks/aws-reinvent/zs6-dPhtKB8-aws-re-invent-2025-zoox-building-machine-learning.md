## Description

Discover how Zoox leverages AWS Machine Learning infrastructure to revolutionize autonomous vehicle development. Learn how we process thousands of multi-modal sequences daily using Amazon SageMaker HyperPod, SLURM, FSx, S3, and EKS in a streamlined machine learning environment that supports both rapid experimentation and production-scale training. We'll share how our integrated monitoring solution reduced manual analysis by 85% while scaling to support thousands of vehicle analysis use cases.
