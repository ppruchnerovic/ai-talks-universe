## Description

In this session, use Amazon Q Developer's transformation capabilities to modernize a Java application. Learn how Amazon Q Developer can leverage generative AI to automate common language upgrade tasks like updating your code, conducting unit tests, and verifying deployment readiness. Save days' or even months' worth of the undifferentiated work involved in moving from older language versions.
