## Description

Financial institutions face challenges analyzing massive log volumes, requiring hours or days of manual review for critical incidents. Learn how Ripple is building an automated, multi-agent system using Amazon Bedrock AgentCore and the Strands Agents framework to process 30-50GB of daily logs in minutes. Explore architectural patterns for integrating Amazon CloudWatch, AWS Lambda, Amazon S3, and Amazon OpenSearch to correlate log entries with codebase sections. Discover approaches for designing specialized agents that create conversational user interfaces for guided investigations. See how this system transforms blockchain operations and walk away with strategies for implementing a scalable foundation for building multi-agent applications.
