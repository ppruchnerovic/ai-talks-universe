## Description

Discover how Amazon improved fulfillment center launches by building a computer vision solution using Amazon Bedrock, Amazon Nova Pro and Anthropic Claude models. In this session, we discuss architectural decisions that enable automated image detection at scale, reducing verification time by over 60%. We explore our journey from concept to deployment, sharing learnings on rapid prototyping, experimentation, and on-site pilot testing. Join this session to learn about practical approaches to optimize performance, resilience, and cost, and how you can apply these practices in building your own operational readiness solution.
