## Description

AI-powered coding agents are one of the most promising applications of generative AI. In this talk we will start from their humble beginnings as inline code completion tools and explain their evolution into sophisticated autonomous coding agents. Throughout the talk, we will ground our discussion in empirical evidence, presenting evaluations from public benchmarks that demonstrate the progressive improvements in each evolutionary stage. By walking through concrete examples and real-world applications, attendees will gain a comprehensive understanding of the current state of AI-powered development tools and insights into future directions in this rapidly advancing field.
