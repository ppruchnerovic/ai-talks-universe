Join this session to explore how telecommunications companies are implementing AWS generative AI services, including AWS Transform and Amazon Bedrock, to automate legacy system migrations. Learn how CSPs are modernizing Mainframe systems and VMware environments using AI-powered assessment tools, automated infrastructure-as-code generation, and intelligent legacy code transformation. AT&T will present their strategic vision and implementation approach for AI-powered Mainframe modernization.
