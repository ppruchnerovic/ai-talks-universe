## Description

Amazon S3 Vectors introduces native support for you to store, retrieve, and query vectors in S3. In this session, explore how S3 Vectors complements high-performance vector databases, reducing storage and querying costs by up to 90%. Learn how to integrate S3 Vectors with Amazon Bedrock Knowledge Bases and OpenSearch Service for RAG and semantic search at reduced cost and complexity. We’ll cover architecture design, performance considerations, and how S3 Vectors supports scalable AI agent memory and search. Also hear from S3 Vectors customer, March Networks, about using the feature to transform operations and power smart video search capabilities.
