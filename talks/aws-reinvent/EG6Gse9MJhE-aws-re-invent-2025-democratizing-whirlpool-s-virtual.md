## Description

Discover how Whirlpool leverages AWS to democratize Virtual Product Development and speed up design decisions. By running cloud-based cost and performance simulations, Whirlpool generates training data to build explainable machine learning models with Amazon SageMaker, deployed through a modular front-end on AWS Elastic Beanstalk. These tools empower enterprise-wide stakeholders to quickly explore trade-offs and perform multi-objective optimizations using Genetic Algorithms. This session highlights the journey from siloed tools to a unified cloud ecosystem, enabling faster, smarter product architecture choices and driving measurable improvements in cost, performance, and time-to-market.
