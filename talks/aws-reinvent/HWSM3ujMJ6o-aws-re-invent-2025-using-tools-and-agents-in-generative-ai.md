## Description

Join us for an engaging session on AI Agents and Tools in AWS, where we’ll explore how to build intelligent, autonomous systems using Amazon Bedrock and open-source frameworks. Learn about function calling, ReAct patterns, and AWS’s comprehensive agent platforms. We’ll dive into practical demonstrations using Strands and CrewAI, and discover how to leverage protocols like MCP and A2A for seamless tool integration and agent collaboration. Perfect for developers looking to create production-ready AI solutions.
