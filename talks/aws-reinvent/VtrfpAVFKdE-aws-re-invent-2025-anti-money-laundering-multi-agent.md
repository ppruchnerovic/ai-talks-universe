## Description

Learn how to build a production-ready, serverless Anti-Money Laundering (AML) system using AWS Strands SDK and Anthropic's Claude model in Amazon Bedrock. The architecture features eight specialized agents (Perception, Context, News, Reasoning, Risk, Action, Audit, Learning) orchestrated for intelligent financial crime detection. Through live demonstrations, see semantic reasoning beyond rule-based detection, real-time API integration, and cost-effective serverless deployment using Amazon Bedrock AgentCore Deployment. Experience high-risk transaction processing, Strands SDK integration with Claude's semantic analysis, and complete multi-agent coordination. Gain realtime understanding on building LLM-powered compliance systems with explainable AI decisions and regulatory compliance.
