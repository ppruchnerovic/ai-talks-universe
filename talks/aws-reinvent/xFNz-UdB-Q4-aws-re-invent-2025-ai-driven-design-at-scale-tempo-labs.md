## Description

Learn how Tempo Labs migrated production generative AI workloads from OpenAI to Amazon Bedrock, improving scalability, model choice, and security. Through AWS's Migration Acceleration Program (MAP) and generative AI Innovation Center, Tempo built a code-first UI/UX collaboration platform that enables product managers, designers, and engineers to collaborate directly in code—replacing image-based design workflows. This session covers the complete migration journey: model selection and prompt re-optimization, implementing guardrails and evaluation frameworks, plus infrastructure modernization with Kubernetes and data migration. Walk away with practical migration patterns, responsible AI implementation strategies, and proven approaches for building enterprise-grade genAI platforms at scale.
