## Description

Join Crane Worldwide, a global logistics and supply chain leader, as they share their cloud transformation journey migrating to AWS within a multi-cloud architecture that includes Azure and OCI. Crane's Chief Technology Officer will detail their strategy for designing and implementing this enterprise-scale migration, including architectural decisions that enable global application scaling across their expanding logistics network. Attendees will gain practical insights into cloud migration strategy, multi-cloud architectural patterns, and how modernizing their cloud infrastructure has created a foundation for AI adoption across the business.
