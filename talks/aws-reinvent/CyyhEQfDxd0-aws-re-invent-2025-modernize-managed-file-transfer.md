## Description

Managing file transfers can come at a high cost as you maintain infrastructure, licensing, resources, and adherence to regulatory and business requirements. In this session, learn how AWS Transfer Family provides fully managed, highly available file transfers over protocols including SFTP, and how to implement this at scale using Infrastructure as Code (IaC) with Terraform. Learn how enterprises have transformed their MFT infrastructure into an event-driven architecture to reduce operational overhead. Additionally, we'll dive into how you can leverage agentic AI to automate intelligent data pipelines to process and deliver incoming data while maintaining security and compliance.
