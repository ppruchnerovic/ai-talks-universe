## Description

Discover how to architect and enhance AI development workflows on AWS with powerful third-party agents and tools from AWS Marketplace using Amazon Bedrock AgentCore Gateway and Runtime. This session walks through real-world use cases for third-party agents and how to efficiently source and deploy AI development tools the moment you need them. Through architecture diagrams and live demonstrations, we'll explore how to import tools via Gateway, establish connections with your IDE and MCP client, and deploy tools in AgentCore Runtime. Learn architectural best practices and see implementation patterns that showcase the power of integrating third-party products into your AWS workflows.
