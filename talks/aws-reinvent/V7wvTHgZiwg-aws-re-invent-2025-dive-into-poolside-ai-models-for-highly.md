## Description

Join poolside and Northrop Grumman Space Systems to explore how poolside’s foundational AI models accelerate enterprise software development efforts—working securely within regulated environments. This session covers poolside's platform architecture and security model, followed by demos of key use cases such as reviewing code, generating tests, and integrating with CI/CD pipelines. Hear directly from Northrop Grumman Space Systems on their perspective in deploying poolside’s foundational AI models for secure, high-velocity software development. Learn how this collaboration improves code quality, productivity, and iteration speed. This presentation is brought to you by poolside, an AWS Partner.
