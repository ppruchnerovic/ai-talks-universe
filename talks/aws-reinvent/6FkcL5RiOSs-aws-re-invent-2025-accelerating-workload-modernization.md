## Description

This session will focus on how AWS is leveraging generative AI tools to accelerate the migration and modernization of workloads either to AWS or running on AWS. This session will explore the latest agentic AI tools from for VMware, .Net, Mainframe, Java, and SQL Server. Additionally, we will cover how these tools are enabling AWS Partners to integrate with AWS tools, and third party ISV tools.
