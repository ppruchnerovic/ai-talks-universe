## Description

In this session, we look at the history of tools for boosting developer productivity from punch cards through IDEs and into AI Pair Programming. GitHub Copilot Code completions started the revolution in 2021, but that already feels like the Stone Age! As autonomous agentic workloads grow in popularity, this session will help guide where Copilot is headed and what should you be doing to prepare yourself for the (imminent) future of Agentic Software Delivery.
